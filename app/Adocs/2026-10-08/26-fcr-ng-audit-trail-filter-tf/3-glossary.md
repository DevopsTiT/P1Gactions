# FCR NG Glossary

| Term | What it means | Why you care |
|---|---|---|
| FCR | Application name in the configuration lookup | Selects the FCR projects |
| group-jobs | Real Time group job | Its result decides OK or NG |
| applications | Functional job | Grouped with the Real Time job |
| tempname | Name in "Building ..." text | Links Real Time to Functional |
| for_each | Terraform way to create one resource per map key | Can merge this family into one block later |
