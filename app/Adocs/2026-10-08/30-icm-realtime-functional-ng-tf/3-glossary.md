# Claims ICM Glossary

| Term | What it means | Why you care |
|---|---|---|
| Claims ICM | Application name in the configuration lookup | Selects the ICM projects |
| group-jobs | Real Time group job | Its result decides OK or NG |
| applications | Functional job | Grouped with the Real Time job |
| Add to Triggered Alerts | Splunk only lists the alert in its UI | Nobody is notified, so no page |
| audit_trail | Jenkins audit log lines with no build result | Dropped early so the query scans less |
