# Compass PB NG Glossary

| Term | What it means | Why you care |
|---|---|---|
| Compass AG | Application name in the configuration lookup | Selects the Compass PB projects |
| OKメンテナンス中 | "OK, under maintenance" remark in the build log | Shown on the problem as remarks |
| Real Time Check | Jenkins job that checks the app often | Its result decides OK or NG |
| Functional job | Jenkins job with detailed test cases | Grouped with the Real Time job |
| pagerduty.enabled | Flag the workflow reads | "1" because PagerDuty is enabled |
