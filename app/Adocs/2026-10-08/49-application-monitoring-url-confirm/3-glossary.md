# URL Confirm Glossary

| Term | What it means | Why you care |
|---|---|---|
| sourcetype | Splunk's label for the log format | If the label doesn't exist, the search returns nothing |
| HTTP Monitor | A Jenkins job that calls an app URL and logs the status code | The source of this alert |
| In-place update | Same Terraform resource name, so apply changes the existing detector | Applying from two folders causes conflicts |
| enabled = false | The detector exists but does not run | A safe first deploy |
