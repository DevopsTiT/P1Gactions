# 中国银行海外App动态口令

## 判断流程

```
App 要求输入"动态口令"
 你手上有哪种认证工具？
  实体口令牌（小卡片或钥匙扣，带屏幕）→ 按按钮 → 屏幕显示 6 位数字 → 在时限内输入
  手机软件令牌（App 内或单独的令牌 App）→ 打开令牌 → 输入 PIN → 读出 6 位数字
  短信验证码 → 看银行发到预留手机号的短信 → 输入
  什么都没有 → 联系开户的海外分行，申请开通或领取口令牌
 输入后报错？
  过期 → 重新生成一次，马上输入
  多次错误被锁 → 停止尝试 → 联系分行解锁
  口令牌丢失或电池没电 → 联系分行挂失或换新
```

## 一句话总结

| 问题 | 回答 |
|---|---|
| 动态口令是什么？ | 一次性的数字密码，用来确认操作的人是账户本人 |
| 和登录密码有什么区别？ | 登录密码长期不变；动态口令每次都不同，用后作废 |
| 一般几位？ | 通常 6 位数字 |
| 从哪里拿到？ | 实体口令牌、手机软件令牌，或短信验证码，取决于分行给你开通的方式 |
| 什么时候要输？ | 登录、转账汇款、新增收款人、修改设置等敏感操作 |
| 最重要的安全规则 | 不告诉任何人；银行职员不会通过电话或短信向你索要动态口令 |

## 说明

动态口令属于"双重认证"的第二道锁。第一道是你记住的登录密码，第二道是只有你手上才有的设备（口令牌或手机）临时生成的数字。两样都对，银行才放行。

具体用哪一种（实体口令牌、手机令牌、短信），要看你开户的海外分行（例如东京分行）当初给你开通的是什么。各分行的叫法和流程可能略有不同，以分行说明为准。

## 三种常见形式

| 形式 | 长什么样 | 怎么用 | 注意 |
|---|---|---|---|
| 实体动态口令牌 | 小卡片或钥匙扣，有液晶屏和按钮 | 按一下按钮，屏幕出现 6 位数字，输入到 App | 数字大约 1 分钟内有效；电池耗尽要去分行换 |
| 手机软件令牌 | App 里的"令牌"功能，或单独的令牌 App | 打开后输入令牌 PIN，显示 6 位数字 | 换手机前要先在旧手机上解绑或联系分行 |
| 短信验证码 | 发到预留手机号的短信 | 收到后在时限内输入 | 海外换了手机号要先到分行更新 |

## 常见问题

| 情况 | 可能原因 | 怎么办 |
|---|---|---|
| 输入后提示错误 | 数字已过期，或看错一位 | 重新生成一个，马上输入 |
| 连续错误后被锁 | 安全机制 | 不要继续试，联系分行解锁 |
| 收不到短信 | 手机号变了，或国际短信被拦截 | 确认预留手机号，联系分行 |
| 口令牌丢了 | 设备遗失 | 立即联系分行挂失，申请新口令牌 |
| 换了新手机 | 软件令牌绑定在旧手机 | 联系分行重新绑定 |

## 安全提醒

| 规则 | 为什么 |
|---|---|
| 不要把动态口令告诉任何人 | 有人拿到它就能以你的身份转账 |
| 银行不会打电话或发短信索要口令 | 这样索要的几乎都是诈骗 |
| 只在官方 App 或官网里输入 | 钓鱼网站会伪装成银行页面骗口令 |
| 口令牌和写着密码的纸不要放在一起 | 两样一起丢，等于两道锁一起失效 |

## 数据流

```
你在 App 发起操作（登录或转账）
 → App 要求动态口令
   → 你的口令牌或手机令牌按时间算出 6 位数字（短信方式则由银行发送）
     → 你输入数字
       → 银行服务器用同样的方法算一遍
         → 一致 → 操作通过
         → 不一致或过期 → 拒绝，多次失败则锁定
```

## 调查

| 检查了什么 | 结论 |
|---|---|
| 动态口令的通用含义 | 银行业通用的一次性密码（OTP），用于双重认证 |
| 中国银行海外业务的常见形式 | 实体口令牌、手机令牌、短信验证码，具体以开户分行为准 |
| 未确认的部分 | 你所在分行开通的是哪一种，以及具体菜单名称；需看分行资料或询问分行 |

## 结论

| 你要做的事 | 说明 |
|---|---|
| 确认自己用的是哪种口令 | 看开户时拿到的口令牌或分行说明 |
| 按对应方式生成 6 位数字并及时输入 | 过期就重新生成 |
| 遇到锁定、丢失、换号、换机 | 联系开户分行处理 |
