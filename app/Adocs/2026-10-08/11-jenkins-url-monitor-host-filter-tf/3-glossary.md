# Glossary

| Term | What it means | Why you care |
|---|---|---|
| `host.name` | Dynatrace field with the server name | Used to read only the Jenkins server's logs |
| `matchesValue` | DQL match with `*` wildcard, case-insensitive | Matches short, full, and upper-case host names |
| ceaa2099 | The Jenkins server | The only source of these URL checks |
