# Compass Update Glossary

| Term | What it means | Why you care |
|---|---|---|
| audit_trail | Jenkins audit lines with no build result | Most of the index, and safe to drop |
| In-place update | Terraform changes the existing resource | No duplicate detector |
| Compass vs Compass AG | Two different applications in the lookup | Compass PB uses "Compass AG" |
| Terraform state | File that tracks what Terraform created | It lives per folder, so apply from one folder |
