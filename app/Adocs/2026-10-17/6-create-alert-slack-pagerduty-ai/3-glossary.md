# Slack PD AI Alert Glossary

| Term | What it means |
|---|---|
| Incident | PagerDuty alert object posted to Slack |
| Service | PD receiver you connect to a channel |
| `/pd connect` | Slash command to bind channel to service |
| Private channel | Needs explicit bot invite |
| PagerDuty AI | Assistant and agents after the incident exists |
| Routing key | Secret that Dynatrace/Events API use to open incidents |
