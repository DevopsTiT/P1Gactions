# Monitoring Rates Glossary

| Term | What it means |
|---|---|
| Error rate | Failed requests divided by all requests |
| Success rate | Successful requests divided by all requests |
| Availability | Share of time or requests that were good enough |
| Request rate | How many requests per second (or per minute) |
| Latency | How long a request takes |
| Percentile (p95, p99) | Threshold that X% of requests beat |
| SLI | The measured indicator |
| SLO | The target for that indicator |
| Error budget | Allowed failure under the SLO |
| Burn rate | How fast the error budget is consumed |
| Saturation | How full a resource is |
| Synthetic probe | Fake user check from outside |
