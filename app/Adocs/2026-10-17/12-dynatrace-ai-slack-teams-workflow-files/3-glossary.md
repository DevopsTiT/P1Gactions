# Workflow Files Glossary

| Term | What it means |
|---|---|
| WF-A | Immediate AI notify workflow template |
| WF-B | 30-minute PagerDuty escalate template |
| DRY_RUN | Preview/build only; no HTTP POST to PagerDuty |
| dedup_key | PagerDuty key to avoid duplicate incidents |
| schemaVersion 3 | Dynatrace Workflow export format used here |
| Connector | Slack or Teams Hub connection bound in the UI |
