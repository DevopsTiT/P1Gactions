# Dynatrace 30m No Ack Glossary

| Term | What it means |
|---|---|
| Minimum duration | Trigger waits until problem open time reaches N minutes |
| Problem trigger | Workflow starts from a Davis problem |
| Acknowledge | Human marked the problem as seen |
| Generative AI task | Workflow step that asks Dynatrace Intelligence for text |
| Preview then post | Build payload, check, then send |
| Events API | PagerDuty API used to trigger an incident |
