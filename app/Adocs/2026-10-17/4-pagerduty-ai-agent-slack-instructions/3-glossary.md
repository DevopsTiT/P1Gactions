# PagerDuty AI Slack Glossary

| Term | What it means |
|---|---|
| PagerDuty AI / Advance | Paid AI capabilities in PagerDuty |
| Paige | SRE Agent name in current docs |
| Scribe | Meeting transcript and summary agent |
| Shift | On-call coverage helper agent |
| Insights | Ops analytics agent |
| Optional scopes | Extra Slack permissions for channel history |
| Side panel | Private Assistant chat in Slack |
| /pd connect | Slash command to bind a channel to a service or team |
| /pd scribe | Slash command to add Scribe to the bridge |
