# Glossary

| Term | What it means |
|---|---|
| Incoming Webhook | Slack URL that accepts POST JSON into one channel |
| `SLACK_WEBHOOK_URL` | Placeholder in scripts — set after import in Dynatrace |
| `DRY_RUN` | When true, build/preview only; no real POST |
| `chat_message` | Text built by `build-chat-message` for Slack `text` |
| `PD_ROUTING_KEY` | PagerDuty Events API v2 key for WF-B |
