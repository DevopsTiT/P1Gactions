# Glossary

| Term | What it means |
|---|---|
| Chat Integrations | PD AI Settings table for Slack / Teams connection status |
| `/pd` | Slack slash command for the PagerDuty app |
| Link Account | Map your PD user to your Slack or Teams user |
| Scribe | PD AI agent that summarizes incident context in chat |
| Hub Slack Connection | Dynatrace workflow Slack path — different from PD AI |
