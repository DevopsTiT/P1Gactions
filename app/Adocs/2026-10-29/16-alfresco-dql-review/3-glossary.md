# Glossary

| Term | What it means |
|---|---|
| `Message` | How many different hosts Splunk found. |
| `total = count()` | How many log lines one name wrote in the screen DQL. |
| `countDistinct` | How many different values a field has. |
| `Total` | The single summary row Splunk appends. |
| PODFrozen | The alert name. It fires when the name count is not 4. |
