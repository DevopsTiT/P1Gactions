The DQL on the screen is not the same check as the Splunk alert.

Splunk counts different hosts. Message is that count. The row is kept only when Message is not 4. Zero statistics means 4 hosts.

The screen DQL does summarize total = count(), by:{ host } and then filter total != 4. total is log lines for each name. The filter keeps names that did not write exactly 4 lines. Four busy pods make Splunk return nothing and make this DQL return four rows.

coalesce(k8s.pod.name, host.name) keeps the pod name whenever that field is filled, even when the app name is only in host.name.

Replacement:

fetch logs
| filter contains(k8s.pod.name, "alfrescoacr-batch", caseSensitive:false)
    or contains(host.name, "alfrescoacr-batch", caseSensitive:false)
    or contains(log.source, "alfrescoacr-batch", caseSensitive:false)
| fieldsAdd from_pod = if(contains(k8s.pod.name, "alfrescoacr-batch", caseSensitive:false), k8s.pod.name, else: null)
| fieldsAdd from_host = if(contains(host.name, "alfrescoacr-batch", caseSensitive:false), host.name, else: null)
| fieldsAdd unit = coalesce(from_pod, from_host)
| filter isNotNull(unit)
| summarize Message = countDistinct(unit)
| fieldsAdd host = "Total"
| filter Message != 4
| fields host, Message

0 records means Message is 4.
