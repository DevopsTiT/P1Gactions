The Splunk search counts different host names. It returns a row only when that count is not 4.

The DQL on the screen uses count() by name. That number is log lines per name, then it keeps names whose line count is not 4. Message in Splunk is the number of names.

Use the pod name when k8s.pod.name contains alfrescoacr-batch. Otherwise use host.name when that field contains it. log.source can also find the line.

Set the time picker to the Splunk window: 10/28/2026 1:00 PM through 10/29/2026 1:43 PM.

Alert query:

fetch logs
| filter contains(k8s.pod.name, "alfrescoacr-batch", caseSensitive:false)
    or contains(host.name, "alfrescoacr-batch", caseSensitive:false)
    or contains(log.source, "alfrescoacr-batch", caseSensitive:false)
| fieldsAdd from_pod = if(contains(k8s.pod.name, "alfrescoacr-batch", caseSensitive:false), k8s.pod.name, else: null)
| fieldsAdd from_host = if(contains(host.name, "alfrescoacr-batch", caseSensitive:false), host.name, else: null)
| fieldsAdd unit = coalesce(from_pod, from_host)
| filter isNotNull(unit)
| summarize Message = countDistinct(unit)
| fieldsAdd host = "Total"
| filter Message != 4
| fields host, Message

0 records means Message is 4.

List the names:

fetch logs
| filter contains(k8s.pod.name, "alfrescoacr-batch", caseSensitive:false)
    or contains(host.name, "alfrescoacr-batch", caseSensitive:false)
    or contains(log.source, "alfrescoacr-batch", caseSensitive:false)
| fieldsAdd from_pod = if(contains(k8s.pod.name, "alfrescoacr-batch", caseSensitive:false), k8s.pod.name, else: null)
| fieldsAdd from_host = if(contains(host.name, "alfrescoacr-batch", caseSensitive:false), host.name, else: null)
| fieldsAdd unit = coalesce(from_pod, from_host)
| filter isNotNull(unit)
| summarize log_count = count(), by: { unit, k8s.pod.name, host.name }
| sort unit asc

log_count is lines per name. The alert ignores it. unit is the name Message counts. When both the pod name and the host name match and they differ, the pod name is the unit.
