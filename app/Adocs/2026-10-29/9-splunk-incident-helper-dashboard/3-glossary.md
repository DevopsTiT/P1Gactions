# Glossary

| Term | What it means |
|---|---|
| Dashboard | A Splunk page made of several searches. |
| Dashboard Studio | The editor that places charts on a grid. |
| Panel | One box. It has a title, a search, and a chart type. |
| Time range input | The control labeled Search by Time. This page uses Last 15 minutes. |
| Auto-refresh | The page runs the searches again on a timer. |
| Single value | A chart that shows one number or one short string. |
| Table | A chart that shows rows, here host and status. |
| stats count | Counts the events the search kept. |
| stats latest | Keeps the newest value. |
| No results found | The search matched zero events in the selected time. |
| EIP_UP | The status text shown for the four hosts on the right-hand tables. |
| ND Mode | The letter printed in the two mode boxes. This screen shows A. |
| DCI Kappa | The pair named in the 10/15 panel: WPLALJ2BC and WPLALJ2BB. |
| DCI English | The pair named in the 12/15 panel: WPLALJ2CO and WPLALJ2BF. |
