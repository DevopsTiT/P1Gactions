# Glossary

| Term | What it means |
|---|---|
| `eip_mg_up_check` | The Splunk sourcetype for this UP check. |
| `EIP UP Check` | Text seen on the events. |
| `WPALJA21BC` | One of the two hosts. Full name `WPALJA21BC.prprivngmt.intraxa`. |
| `WPALJA21B9` | The other host. Full name `WPALJA21B9.prprivngmt.intraxa`. |
| `MG_Result.MG_Status` | The second column of the Splunk table. Its values are not on these screens. |
| `last_seen` | Time of the newest matching event for that host. |
| `from: now()-3m` | Locks the DQL to the last 3 minutes. |
| Table tile | A Dynatrace box that shows rows. |
