# Result

All five prompts ask the assistant to write a note with an expected shape. Primary checks that note before acting.

| Prompt | Expected shape |
|---|---|
| Catch me up | Incident facts, then starter checks. |
| Likely root causes | Angles to verify. The cause stays a draft until evidence confirms it. |
| Draft a status | Internal update. A person sends it. |
| Wrap me up | Timed bridge note, as text. |
| Most P2s in 14 days | One sentence. Only if Insights is enabled. |
