This dialog is the success count next to APIGateway FAILURE.

It counts the data model APIGW1015_Success_count. count(RootObject) is the green number. The search does not split, so the result is one number.

Time Range is Shared Time Picker (searchByTimer), the same clock as the failure panel.

Auto Refresh Delay is 1 minute. Refresh Indicator is a progress bar. Apply saves the panel. The green color is set on the chart, outside this dialog.

The failure model, already opened, keeps:

index=eip1015 sourcetype=eip_mediator_serverlog Status=FAILURE

This success model’s constraint was not opened here. Open Settings → Data models → APIGW1015_Success_count. A sample mediator line contains Status: SUCCESS.

Matching Dynatrace tile:

data record(success_count = 0)
| append [
    fetch logs
    | filter contains(log.source, "apigw5500/server.log", caseSensitive:false)
    | filter contains(content, "Status: SUCCESS", caseSensitive:false)
    | summarize success_count = count()
  ]
| summarize success_count = sum(success_count)

Single value on success_count. Title APIGateway SUCCESS. Color it green. Use the same Last 15 minutes picker and 1 minute refresh as the failure tile.
