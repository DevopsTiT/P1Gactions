# 泉岳寺站

```
看到 岳泉寺站
  东京地铁站名是 泉岳寺站（Sengakuji）
  要去羽田、横滨、品川 → 京急，1 号站台
  要去西马込 → 都营浅草线，2 号站台
  要去押上、天空树、成田方向 → 都营浅草线，3 或 4 号站台
  要换 JR 山手线、京滨东北线 → 步行到高轮 Gateway
```

```
羽田机场、横滨、品川
        |
        v
京急本线 1 号站台
        |
        v
泉岳寺站（地下，A-07）
        |
        +--> 2 号站台 都营浅草线 → 西马込
        +--> 3、4 号站台 都营浅草线 → 押上、天空树方向
        |
        +--> 出站步行
               高轮 Gateway
               JR 山手线、京滨东北线
```
