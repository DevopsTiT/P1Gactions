# 泉岳寺站

```
看到 岳泉寺站
  东京地铁站名是 泉岳寺站（Sengakuji）
  要去羽田、横滨、品川 → 京急，1 号站台
  要去西马込 → 都营浅草线，2 号站台
  要去押上、天空树、成田方向 → 都营浅草线，3 或 4 号站台
  要换 JR 山手线、京滨东北线 → 步行到高轮 Gateway
```

## Summary

泉岳寺站在东京港区高轮，是都营浅草线和京急本线的交会站。去羽田机场、横滨走京急。去浅草线另一头走都营。旁边的泉岳寺因赤穗浪士墓地出名，站名来自这座寺。

## Investigation

| 来源 | 内容 |
|---|---|
| 用户写法 | 岳泉寺站。 |
| 车站正式中文名 | 泉岳寺站。 |
| 东京都交通局 | 浅草线 A-07，地址港区高轮 2-16-34。 |
| 京急 | 本线车站，与都营浅草线直通。开业 1968 年 6 月 21 日。 |
| 中文维基 | 地下站，2 座岛式站台，4 条股道。 |

## Result

| 站台 | 方向 |
|---|---|
| 1 | 京急本线，往品川、横滨、羽田机场。 |
| 2 | 都营浅草线，往西马込。 |
| 3 | 都营浅草线，往押上、京成线、北总线。这侧主要接从西马込来的车。 |
| 4 | 都营浅草线，往押上、京成线、北总线。这侧主要接从京急来的车。 |

西马込、京急方向，和押上方向之间，有同一站台换乘。西马込和京急之间要走联络台阶。

站外步行可到高轮 Gateway，换乘 JR 山手线和京滨东北线。高轮 Gateway 不是泉岳寺站里面的站台。

车站编号只有都营浅草线使用，是 A-07。京急在站内指引里也用这个编号。
