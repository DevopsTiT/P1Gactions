# Glossary

| Word | What it means |
|---|---|
| data | Starts a small table you type yourself. It does not read Grail. |
| record | One row in that handmade table. |
| lookup | Attaches matching rows from a second query. Here, the log summary. |
| log.source | The file path Dynatrace stored on the log line. |
| last_seen | The newest timestamp for that path. Empty means no match. |
| NG | No log for that path in the last 24 hours. |
| OK | At least one log line for that exact path. |
| Scanned bytes | How much log data the inner fetch read. This run read 81.35 GiB. |
