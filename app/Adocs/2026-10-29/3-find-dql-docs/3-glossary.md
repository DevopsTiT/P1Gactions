# Glossary

| Word | What it means |
|---|---|
| DQL | Dynatrace Query Language. The text you write to ask Grail for data. |
| Grail | Dynatrace’s storage for logs, events, spans, and metrics. DQL reads it. |
| Pipe | The `|` character. It sends the table from one command into the next. |
| fetch | The command that loads a kind of data, such as logs. |
| Notebook | The Dynatrace page where you type a DQL query and see the result. |
| Learn DQL | The Hub app with interactive DQL tutorials. |
