# Glossary

| Word | What it means |
|---|---|
| fetch | The command that loads one kind of data. |
| filter | Keeps the rows that match. |
| contains | Looks for text inside a field. caseSensitive:false ignores capital letters. |
| summarize | Collapses many rows into counts or averages. |
| fields | Chooses which columns to show. |
| span | One unit of work in a trace, such as one service call. |
| Davis problem | Dynatrace’s detected problem. The id can look like P-88421. |
| duration | On a span, the elapsed time in nanoseconds. Divide by 1000000 to see milliseconds. |
