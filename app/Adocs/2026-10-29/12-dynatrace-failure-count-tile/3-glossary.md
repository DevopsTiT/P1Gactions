# Glossary

| Term | What it means |
|---|---|
| Tile | One box on a Dynatrace dashboard. It has a query and a picture. |
| DQL | Dynatrace Query Language. The text you paste into the tile. |
| `fetch logs` | Load log lines for the dashboard time range. |
| `log.source` | The log path or logger name Dynatrace stored. |
| `content` | The log line text. |
| `host.name` | The host Dynatrace attached to the log. |
| `summarize count()` | How many lines matched. |
| Single value | The picture that shows one number. |
| Time picker | The dashboard clock. Set it to Last 15 minutes. |
| Auto-refresh | How often the tiles run again. Match Splunk with 1 minute. |
| Threshold | The color rule. On the failure tile, 1 and above is red. |
