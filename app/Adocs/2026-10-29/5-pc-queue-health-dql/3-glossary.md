# Glossary

| Word | What it means |
|---|---|
| timeseries | A DQL command that builds a metric line over time. |
| avg | The average of the metric inside each time bucket. |
| app == "pc" | Keep the series whose app field is pc. In Guidewire, PC usually means PolicyCenter. |
| BC | The chart title on the left. In Guidewire, BC usually means BillingCenter. |
| by | Split the result into one series per queue. |
| arrayLast | The last value in a list of points. |
| fieldsRemove | Drop columns so the table stays small. |
| status | The column this query creates for that last value. |
