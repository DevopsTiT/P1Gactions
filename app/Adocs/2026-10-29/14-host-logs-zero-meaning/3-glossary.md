# Glossary

| Term | What it means |
|---|---|
| Logs 0 | No log line is linked to this host for the selected time. |
| Last 2 hours | The clock on this page. Older lines are outside it. |
| App-only mode | Dynatrace monitors the application from an agent inside the container. Full host monitoring is off. |
| Not analyzed | Dynatrace is not producing the full host analysis. Charts stay empty. |
| `host.name` | The host name stored on a log line in Dynatrace. |
| Services 4 | Four services connected to this one host. |
| Splunk host count 4 | Four different hosts in the index. A different number from Services 4. |
