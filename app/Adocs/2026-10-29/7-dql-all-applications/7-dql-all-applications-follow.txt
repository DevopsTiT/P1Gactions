DQL to monitor all applications on the queue-status metric

Paste into the tile and Run.

timeseries status_series = avg(guidewire.messaging.status),
  by: { app, queue.id, queue.name }
| fieldsAdd status = arrayLast(status_series)
| fieldsRemove status_series, timeframe, interval
| sort app asc, queue.name asc

The PC tile had filter app == "pc". This version removes that filter.
app is added to by, so PolicyCenter and BillingCenter stay on separate rows.

Only the named apps
timeseries status_series = avg(guidewire.messaging.status),
  filter: { app == "pc" or app == "bc" },
  by: { app, queue.id, queue.name }
| fieldsAdd status = arrayLast(status_series)
| fieldsRemove status_series, timeframe, interval
| sort app asc, queue.name asc
