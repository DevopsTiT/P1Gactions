# Glossary

| Term | Meaning |
| --- | --- |
| Problem notification | Dynatrace outbound alert when a Problem changes |
| Alerting profile | Filter controlling which Problems notify |
| Import set | ServiceNow staging table before transform |
| Transform map | Rules that turn import rows into Incidents |
| Affected CI | CMDB item linked to the ticket |
| Service Graph Connector | App that pulls Dynatrace topology into CMDB |
| Closed-loop | Problem close drives Incident resolve |
| ITOM | ServiceNow IT Operations Management (events) |
