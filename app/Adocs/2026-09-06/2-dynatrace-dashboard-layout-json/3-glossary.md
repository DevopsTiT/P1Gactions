# Glossary

| Term | Meaning |
| --- | --- |
| Dashboards (new) | Document-based boards with DQL tiles and variables |
| Dashboards Classic | Older Config API boards (`dashboardMetadata` + `tiles[]`) |
| `$app` | Dashboard CSV variable: All, EIP, API, Payment |
| DQL | Dynatrace Query Language used in new data tiles |
| DATA_EXPLORER | Classic tile type for metric charts |
| OPEN_PROBLEMS | Classic tile listing open Davis problems |
