# Glossary

| Term | Meaning |
| --- | --- |
| PII | Personally identifiable information |
| Blocklist | Keys that must not appear with values in logs |
| Grail | Dynatrace log storage |
| OpenPipeline | Ingest-time mask/drop processors |
| OneAgent masking | Host-side redaction before send |
| matchesPhrase | DQL function to find text in content |
| fieldsRemove | Processor that deletes attributes |
| Sensitive Data Center | Dynatrace workflow to find/clean stored sensitive data |
