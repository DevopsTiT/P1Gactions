# Glossary

| Term | Plain English |
| --- | --- |
| Main dashboard | One board that covers many apps |
| Dashboard variable (`$app`) | Top dropdown that filters every tile |
| All | Show every app on that board |
| EIP filter | Same board, only EIP-related hosts/services/logs |
| Tag `app:eip` | Label on hosts/services so filters stay stable |
| DQL | Dynatrace query language used by dashboard tiles |
| Davis | Dynatrace AI problem / root-cause engine |
| Multi servers | Several hosts for one app shown in one table |
