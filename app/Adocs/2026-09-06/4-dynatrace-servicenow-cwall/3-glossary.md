# Glossary

| Term | Meaning |
| --- | --- |
| Dynatrace Problem | Correlated incident object with Davis root cause |
| ServiceNow Incident | ITSM ticket for restore service |
| CMDB | Inventory of configuration items (servers, apps) |
| CI | One configuration item in the CMDB |
| Service Graph Connector | ServiceNow app to pull Dynatrace entities into CMDB |
| Problem notification | Dynatrace webhook/integration that pushes problems out |
| ITOM Event | ServiceNow event record used by Event Management |
