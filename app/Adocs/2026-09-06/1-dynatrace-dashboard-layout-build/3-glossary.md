# Glossary

| Term | What it means |
| --- | --- |
| Dashboard variable | Dropdown (here `app`) that filters tiles |
| Golden signals | Requests, errors, latency (and often saturation) |
| Davis | Dynatrace AI that suggests problem root cause |
| Service failure rate | Share of failed requests for a service |
| Management zone | Scope wall so STG/prod entities do not mix |
| OneAgent | Agent that sends host/process/service/log signals |
| External services | Outbound dependencies your app calls |
