# Glossary

| Term | What it means |
|---|---|
| `host` | The gateway name taken from `restapi.url`, before the port. |
| `MG_Result.MG_Status` | The status column Splunk shows. On these rows the value is `EIP_UP`. |
| `fields` | Chooses the columns that remain in the result. |
| `takeFirst` | After a newest-first sort, keeps the latest status for each host. |
