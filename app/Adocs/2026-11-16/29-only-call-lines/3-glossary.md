# Glossary

| Word | What it means |
|---|---|
| Call line | A log line that contains `API:` and `API Version`. |
| 100,482 | How many of those lines Dynatrace has from 14:32:26 to 15:32:26. |
| Partner line | `Matching application found for the API:`. This query returned no row for it. |
| Other API text | A line with `API:` and neither sentence above. This query returned no row for it. |
