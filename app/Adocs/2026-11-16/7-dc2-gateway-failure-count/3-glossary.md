# Glossary

| Term | What it means |
|---|---|
| `WPALJA21C0` | The first DC2 API gateway host on this panel. |
| `WPALJA21BF` | The second DC2 API gateway host. `append` stacks it under the first. |
| `ErrorCount` | The FAILURE count for both hosts in the dashboard time range. |
| Red 2 | The count the panel is showing right now. |
| Shared time picker | The dashboard chooses the window. Set the same window in the notebook. |
