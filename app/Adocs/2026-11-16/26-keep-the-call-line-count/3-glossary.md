| Word | What it means |
|---|---|
| Call line | The log line `API: <name> API Version`. This is the line the chart counts. |
| Partner sentence | `Matching application found for the API: <name>`. A second line about the same call. |
| 15,452 | Splunk’s `customer-info-V1` total on this screen. 2,776 + 3,524 + 3,885 + 5,267. |
