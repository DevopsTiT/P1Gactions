# Glossary

| Word | What it means |
|---|---|
| Gap | How far the Splunk total and the Dynatrace total are from each other. |
| `same name` | The parse returned exactly `customer-info-V1`. |
| `other name` | The line contains that text, and the parse returned a different API name. |
| `not parsed` | The line contains that text, and it does not match `API: ` plus ` API Version`. |
| `API Version` | The words the current chart requires after the API name. |
