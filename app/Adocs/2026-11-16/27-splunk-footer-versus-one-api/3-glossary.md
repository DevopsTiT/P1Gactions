# Glossary

| Word | What it means |
|---|---|
| Bottom line | The last numbers on the Splunk grid. They add every API. |
| One API row | One name, such as `policy-management-V1`. |
| 146,964 | 35,089 + 35,427 + 39,119 + 37,329. |
| ALL | The four hosts added for that row, or for the whole grid on the bottom line. |
