This panel counts mediator log events by API and by host. The ALL column is the total for that API.

Set the notebook time picker to the dashboard range.

Count per API and host:

fetch logs
| filter contains(content, "API:", caseSensitive:false)
| parse content, "LD 'API: ' LD:API ' API Version'"
| filter isNotNull(API)
| summarize CountOfAPI = count(), by: { API, host.name }
| sort CountOfAPI desc

Total per API, the ALL column:

fetch logs
| filter contains(content, "API:", caseSensitive:false)
| parse content, "LD 'API: ' LD:API ' API Version'"
| filter isNotNull(API)
| summarize CountOfAPI = count(), by: { API }
| sort CountOfAPI desc

index=* does not add extra logs. The real filter is index eip1015 and sourcetype eip_mediator_serverlog. Splunk keeps 101 host columns. These queries list every pair.
