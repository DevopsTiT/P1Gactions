# Glossary

| Term | What it means |
|---|---|
| `API` | The API name on the mediator log line. The text form is `API: <name> API Version`. |
| `Count of API` | How many events Splunk counted for that API. |
| `ALL` | The total across hosts. Splunk builds it with a fake host value `----`. |
| `limit=101` | Splunk keeps 101 host columns. Extra hosts go into OTHER. |
| `host.name` | The Dynatrace host column used for the split. |
