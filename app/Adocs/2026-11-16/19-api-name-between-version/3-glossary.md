# Glossary

| Word | What it means |
|---|---|
| `API:` | The label in the log line that comes before the API name. |
| `API Version` | The label that comes after the API name. These five rows show version `1.0`. |
| `Count of API` | How many lines in this hour used that API on that host. |
| `ALL` | How many lines in this hour used that API on every host together. |
| `log.source` | The file path. This hour has one path. |
| 470,865 | The number of lines Dynatrace stored for that file from 13:48:52 to 14:48:52. |
