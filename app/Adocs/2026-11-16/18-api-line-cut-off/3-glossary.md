# Glossary

| Word | What it means |
|---|---|
| `apiSnippet` | 120 characters of the log line, starting where `API:` appears. |
| `indexOf` | The character position of a word inside a string. |
| `substring` | A short piece of a string, from one position to another. |
| `YAI.0900.0005I` | The message code at the start of the three sample lines. |
| `log.source` | The Dynatrace field that stores the file path. |
| Paused search | A Splunk job that was stopped before it finished scanning. |
