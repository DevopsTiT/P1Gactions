# Glossary

| Term | What it means |
|---|---|
| `append` | Splunk stacks a second search under the first. Here that second search is the other host. |
| `ErrorCount` | The number of FAILURE rows after both hosts are stacked. |
| `by Status` | Groups the count by the Status value. The filter leaves only FAILURE. |
| Shared time picker | The dashboard chooses the window. Set the same window on the notebook picker. |
| `index` and `sourcetype` | Splunk names for the log bucket and the log type. Grail may store them under other field names. |
