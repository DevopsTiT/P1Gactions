# Glossary

| Term | What it means |
|---|---|
| `sql.activemqmode` | The column that already holds A. |
| `sql.mfsubenv` | The column that holds ND. |
| `sql-monitoring` | The `log.source` value on these mode rows. |
| `limit 1` | Keeps the first row after the sort. With newest-first sort, that row is the latest A. |
