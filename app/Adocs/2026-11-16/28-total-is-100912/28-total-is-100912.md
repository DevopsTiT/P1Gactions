## Summary

The one-row query is consistent. 25,374 + 25,000 + 24,461 + 26,077 = 100,912. The Splunk photo’s bottom line adds to 146,964. This Dynatrace hour is 46,052 lower. The window is 14:30:31 to 15:30:31, and the photo was 15:27, so the clock does not explain 46,000 lines.

## Investigation

Executed at 15:30:52. Scanned 5.84 GiB.

| Column | Count |
|---|---|
| `WPALJA21B9.prprivmgmt.intraxa` | 25,374 |
| `WPALJA21BC.prprivmgmt.intraxa` | 25,000 |
| `WPALJA21BF.prprivmgmt.intraxa` | 24,461 |
| `WPALJA21C0.prprivmgmt.intraxa` | 26,077 |
| ALL | 100,912 |

The Splunk bottom line read from the 15:27 photo was 35,089, 35,427, 39,119, and 37,329. Those four add to 146,964. That photo is angled, so a digit there can be off. The Dynatrace figures are from the notebook and they add up.

Rows we could read on both screens, such as `myasa-V1` at 437 and GetCommission at 190, were already close. The 46,052 gap is spread across the whole hour. It is not one API row.

`customer-info-V1` had 13,562 partner lines in an earlier hour, and Splunk’s row for that API stayed near the call-line count. Adding every partner line would raise this 100,912 total and would also raise that one API well past its Splunk row.

## Result

Paste this split. It counts three kinds of line in the same hour.

```
fetch logs, from: now()-60m
| filter contains(log.source, "/opt/softwareag/log/1015/apigw5590/server.log", caseSensitive:false)
    and contains(content, "API:", caseSensitive:false)
| fieldsAdd lineKind = if(contains(content, "API Version", caseSensitive:false), "call line", else: if(contains(content, "Matching application found for the API:", caseSensitive:false), "partner line", else: "other API text"))
| summarize eventCount = count(), by: { lineKind }
```

| lineKind | What it means |
|---|---|
| `call line` | Contains `API Version`. This is the 100,912 chart. |
| `partner line` | `Matching application found for the API:`. |
| `other API text` | The word `API:` is present, and neither sentence above is present. |

The chart stays on the call line. The split shows whether the missing 46,052 lines are partner lines, other text, or lines that are not in Dynatrace at all.
