# Glossary

| Word | What it means |
|---|---|
| 100,912 | Dynatrace call lines in 14:30:31 to 15:30:31. |
| 146,964 | The four Splunk bottom-line numbers added together. |
| 46,052 | 146,964 minus 100,912. |
| Call line | A line that contains `API Version`. |
| Partner line | `Matching application found for the API:`. |
| Other API text | A line that contains `API:` and is neither of those two sentences. |
