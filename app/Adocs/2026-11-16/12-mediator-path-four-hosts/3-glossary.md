# Glossary

| Term | What it means |
|---|---|
| `apigw5590/server.log` | The only source file on the source popup. |
| `gatewayHost` | The host name taken from the second pair of brackets on the line. |
| `API` | The name between `API:` and `API Version`. The field list shows 41 values. |
| `CountOfAPI` | How many events match that API. |
| `ALL` | The total for one API across the four hosts. That is the second query. |
