# Glossary

| Word | What it means |
|---|---|
| `Count of API` | How many log lines used that API on that one host. |
| `ALL` | How many log lines used that API on every host together. |
| 146 records | The number of API-and-host pairs in the 14:55:46 run. |
| 38 records | The number of different API names in the 14:55:57 run. |
| `customer-info-V2` | The busiest API in this hour. Its ALL value is 26,991. |
| `...` in a cell | The notebook hid the rest of a long API name. The stored value is still the full name. |
