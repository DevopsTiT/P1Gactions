# Glossary

| Term | What it means |
|---|---|
| `append` | Stacks the B9 search under the BC search. The count runs once on the stack. |
| `apigw5500` | The log file path for host WPALJA21BC. |
| `apigw5590` | The log file path for host WPALJA21B9. |
| `ErrorCount` | The number of FAILURE lines from both hosts in the picker window. |
| `Status` | The group label. Every kept line is FAILURE, so the table has one row. |
