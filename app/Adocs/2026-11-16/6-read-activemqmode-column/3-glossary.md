# Glossary

| Term | What it means |
|---|---|
| `sql.query_name` | The field that contains `dc1-nd-mode` on this record. |
| `sql.activemqmode` | The column that holds the letter A. |
| `fields` | The line that chooses which columns appear in the result. |
| `content` | The raw line. It still shows `"ACTIVEMQMODE": "A"` when the column is hidden. |
