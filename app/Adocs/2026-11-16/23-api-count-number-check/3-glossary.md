# Glossary

| Word | What it means |
|---|---|
| ALL cell | The last column on the Splunk row. It should equal the four host counts. |
| Gap | Splunk number minus the Dynatrace number, ignoring the sign. |
| Last 1 hour | The Splunk picker. At 15:07 this is about 14:07 to 15:07. |
| Dynatrace hour | The run at 14:55. That window is 13:55:45 to 14:55:45. |
| Unsafe digit | A cell whose value does not match the other cells on the same row. |
