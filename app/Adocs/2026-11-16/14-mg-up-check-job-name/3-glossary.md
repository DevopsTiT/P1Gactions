# Glossary

| Term | What it means |
|---|---|
| `restapi.job_name` | The check name. The working value is `EIP IS UP check WPALJA21B8`. |
| `restapi-monitoring` | The `log.source` on those rows. |
| `checkStatus` | The status parsed from the JSON. On the B8 rows it is `EIP_UP`. |
| `or` | Joins two comparisons. A bare string on the right side is not a comparison. |
| Last 3 minutes | The Splunk panel window. |
