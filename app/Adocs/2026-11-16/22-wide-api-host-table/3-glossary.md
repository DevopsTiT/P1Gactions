# Glossary

| Word | What it means |
|---|---|
| Wide table | One row per API, and one column per host. |
| `countIf` | Counts a log line only when the host matches that column. |
| `ALL` | The same API counted on every host together. |
| `0` | That host had no line for that API in this hour. |
| `sort API asc` | Lists the API names from A to Z. |
| Pie | The four hosts as four slices. The panel name is `APIGW - Total Counts`. |
