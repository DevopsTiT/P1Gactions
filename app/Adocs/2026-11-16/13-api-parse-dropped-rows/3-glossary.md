# Glossary

| Term | What it means |
|---|---|
| `isNotNull(API)` | Keeps a row only when the API parse found a name. An empty parse deletes the row. |
| `host.name` | Already set to the gateway, for example `WPALJA21BC.prprivmgmt.intraxa`. |
| `content` | The raw line. The API words, if they exist, are somewhere in this text. |
| Last 1 hour | The notebook window. The 5 check rows are inside it. |
