# 3 Glossary

| Term | Plain meaning | Why you care |
|------|---------------|--------------|
| Seq | Integer 1, 2, 3… for each question that calendar day | Keeps order across chats |
| Slug | Short kebab-case name from the question | Makes folders searchable |
| Pic style | Arrow / plain-text decision and data flows | Easy on mobile; no heavy diagrams required |
| Files root | `/Users/k/Work/AIProjects/Files` | Primary local answer store for this workflow |
| Adocs | `app/Adocs` inside P1Gactions | GitHub-mirror copy for cloud review/upload |
| Dual-write | Same artifacts written to Files and Adocs | Desktop, mobile, and cloud see the same pack |
| Investigation | What was checked and what was found | Evidence before the answer |
| Result | What to do / what was produced | Actionable outcome |
| Glossary | Term table shipped with every answer | Beginners and mobile readers decode jargon |
| follow.txt | Plain chat-ready copy of steps | Fast paste on phone |
| `<seq>.sh` | All commands, one per line | No functions/loops/heredocs in the shell file |
| alwaysApply rule | Cursor rule that runs every session | Makes “from now on” stick |
