# 3 Glossary

| Term | Plain meaning | Why you care |
|------|---------------|--------------|
| Agent pack | Answer folder written by a subagent | Deeper file dives outside the main chat turn |
| Collected | Copied into one seq folder | Single place to browse on mobile/cloud |
| extracted/ | Subfolder of copies | Keeps originals grouped without renaming |
| ALL-collected-answers.md | Concatenated main markdowns | One-file read/search |
| Dual-write | Files + Adocs (+ CursorFiles here) | Same content everywhere |
| Transcript excerpt | Snippet from chat jsonl | Trace what agents/chat said |
