Dynatrace DQL error fix — wrong UI + corrected query

THE ERROR
---------
Metric selector parse error: line 1:6 at 'logs'

WHY
---
You pasted a log DQL query into Data explorer.
Data explorer = metrics only (CPU, memory, etc.).
It does NOT understand "fetch logs".

WHERE TO GO INSTEAD
-------------------
Option A (best): Logs and Events → Advanced mode
  1. Left menu → Logs (or Logs and Events)
  2. Switch from Simple to Advanced / DQL
  3. Paste query → Run query (Ctrl/Cmd+Enter)

Option B: Notebooks → + Add cell → DQL
  Good for saved audit notebooks.

Option C: Log viewer → DQL tab (if your tenant shows it)

CORRECTED QUERY (copy-paste into Advanced mode)
-----------------------------------------------
fetch logs, from: now()-24h
| filter in(dt.host_group.id, {
    "C_ALJ_BU_OS_A_INFRA_E_PRD_T_BASE"
  })
| filter matchesRegex(content, "(?i)(insuredPerson|subscriberGender|subscriberDOB|subscriberAddr|subscriberPh|insuredGender|insuredDOB|insuredPersonKanjiName|insuredPersonKanaName|contractPersonKanjiName|contractPersonKanaName|subscriberZipCode|kanaFullAddress|kanjiFullAddress|displayName|loginId|lastName|lastNameKana|\\bdob\\b|telNumberOld)")
| summarize hit_count = count(), by: { host.name, log.source }
| sort hit_count desc
| limit 50

FIXES VS YOUR ORIGINAL
----------------------
1. Wrong screen: Data explorer → Logs and Events → Advanced mode
2. Typo: njiFullAddress → kanjiFullAddress
3. Added missing keys: kanaFullAddress, contractPersonKanjiName, contractPersonKanaName, subscriberZipCode

NO GRAIL / NO DQL FALLBACK
--------------------------
