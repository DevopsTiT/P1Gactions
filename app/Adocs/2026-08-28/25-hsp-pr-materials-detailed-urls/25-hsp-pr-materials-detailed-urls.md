# 高度人才永住详细材料清单

```
准备高才积分永住材料？
  │
  ├─ 1. 确认路径：70分(3年) 或 80分(1年)
  ├─ 2. 下载自检表 + 提出书类チェックシート
  ├─ 3. 按下面表格逐项办理（税/年金/医保最早开始）
  ├─ 4. 填2张积分计算表 + 疎明资料
  └─ 5. 入管局窗口提交（缺件会大幅拖审）
```

## Summary

本文在 seq 24 基础上，为**每一项**材料标注：**份数、如何获取、官方网址、注意事项**。依据出入国在留管理厅「永住许可申请４」系列（令和8年2月ガイドライン改定后仍适用框架）。日本机关出具的证明**原则上发行日起3个月内**；外语材料需**日文翻译**。

**免责声明：** 整理自公开资料，不构成法律意见。チェックシート等附件链接以入管页面最新版为准。

## 七、建议办理顺序（倒推）

| 顺序 | 何时 | 做什么 |
| --- | --- | --- |
| 1 | 提前6个月 | 确认税/年金/医保无欠缴；保留领收书 |
| 2 | 提前3个月 | 申请ねんきん定期便（全期间）；开住民税3年证明 |
| 3 | 提前2个月 | e-Tax 申请納税証明書（その３）；公司开在職証明書 |
| 4 | 提前1个月 | 填2张积分表；收集疎明资料；理由书；找保证人 |
| 5 | 提前2周 | 自检表、照片、确认所有日本证明在3个月内 |
| 6 | 申请日 | 入管局窗口提交 |

## Data flow map

```
确认 70/80 路径 + 官方材料页
  │
  ├─ 下载：自检表 + チェックシート + 申请表 + 积分 Excel
  │
  ├─ 市区町村：住民票 + 住民税证明（3年）
  ├─ e-Tax/税務署：納税証明書その３（五税目）
  ├─ 年金機構：ねんきん定期便 或 ネット打印
  ├─ 公司：在職証明 + 收入见込 + 疎明资料
  │
  ├─ 积分表 ×2 + 疎明 + 身元保証 + 了解书
  └─ 地方入管局提交
```
