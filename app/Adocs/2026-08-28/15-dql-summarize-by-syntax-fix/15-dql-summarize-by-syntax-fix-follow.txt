DQL Master query fix — 'by isn't allowed here' (seq 15)

ROOT CAUSE
Multiple countIf columns + by: { dt.host_group.id } need curly braces around the aggregation block.

Inventory worked because it has only ONE count:
  summarize log_count = count(), by: { dt.host_group.id }

Master failed because it has FOUR counts without braces:
  summarize
    hits_keyword_pii = countIf(...),
    ...
    total_logs = count()
  by: { dt.host_group.id }   ← error here

FIX — add { after summarize and }, before by:

| summarize {
|     hits_keyword_pii = countIf(...),
|     hits_hats_style = countIf(...),
|     hits_rawDataList_jp = countIf(...),
|     total_logs = count()
|   },
|   by: { dt.host_group.id }

NOT the problem:
- Missing summarize (it is there)
- Spaces in by: { dt.host_group.id }
- Multiline and/or inside countIf (OK when parens balanced)

Host group IDs: use C_ALJ prefix (not C_ALI). Your inventory results already show C_ALJ_BU_DATAENGLF_A_CUSTMDMGM_E_PRD_T_APP etc.
