STEP 3 — QUERY A-all (HATS-style per host group)
Counts ProcessNdServiceImpl / HatsProcessResponse / rawDataList across all 44 groups.

fetch logs, from: now()-24h
| filter in(dt.host_group.id, { ... same 44 IDs ... })
| filter matchesPhrase(content, "ProcessNdServiceImpl")
  or matchesPhrase(content, "HatsProcessResponse")
  or matchesPhrase(content, "rawDataList")
| summarize hit_count = count(), by: { dt.host_group.id }
| sort hit_count desc

STEP 4 — QUERY B-all (drill-down host + log source)
Same filters as A-all, add host.name and log.source to summarize.

STEP 5 — QUERY C-all (rawDataList + Japanese = PII signal)
Requires rawDataList AND Unicode Japanese regex.
Fallback: rawDataList + phrase 保険金 / TXID / OPID (see md).

STEP 6 — QUERY E-all (keyword PII — seq 11 Query 1A with 44 IDs)
Insurance + HULFT field regex from seq 7 + seq 10.
Full copy-paste block in 13-dql-pii-all-servers.md

STEP 7 — QUERY D-all (sample, limit 10)
Replace YOUR_HOST_GROUP_ID with a row from Master or A-all where hit_count > 0.

fetch logs, from: now()-24h
| filter matchesValue(dt.host_group.id, "YOUR_HOST_GROUP_ID")
| filter matchesPhrase(content, "ProcessNdServiceImpl")
  or matchesPhrase(content, "HatsProcessResponse")
  or matchesPhrase(content, "rawDataList")
| fields timestamp, dt.host_group.id, dt.security_context, host.name, log.source, content
| sort timestamp desc
| limit 10
