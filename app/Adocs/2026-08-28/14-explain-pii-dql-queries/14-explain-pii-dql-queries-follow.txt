DQL PIPELINE (every query)
──────────────────────────
fetch logs, from: now()-24h   → get log records from Grail
| filter ...                   → keep matching rows only
| summarize count() / countIf() → count without reading PII
| sort ... desc                → worst first
| limit N                      → cap rows (10 for samples)
| fields ...                   → pick columns (content = shows PII)

FIVE MATCH FUNCTIONS
────────────────────
in(field, { "A", "B" })              → field is any value in list (44 host groups)
matchesValue(field, "exact")         → field equals one string (one group, SystemOut)
matchesPhrase(field, "text")         → field contains substring (rawDataList, class names)
matchesRegex(field, "pattern")       → regex match ((?i) = case-insensitive, many field names)
countIf(condition)                   → inside summarize: count matching rows without filtering others out

countIf TRICK (Master query)
────────────────────────────
Normal filter removes non-matching rows — one pattern per query.
countIf keeps ALL rows in the group but counts each pattern in its own column:
  hits_keyword_pii, hits_hats_style, hits_rawDataList_jp, total_logs
One row per dt.host_group.id, multiple count columns side by side.
