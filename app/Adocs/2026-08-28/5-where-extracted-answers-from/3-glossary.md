# 3 Glossary

| Term | Plain meaning | Why you care |
|------|---------------|--------------|
| extracted/ | Folder of copies inside a collect pack | Not the first place the answer was authored |
| Seq 4 (Jul 30) | Question number that day for file-by-file dive | Explains the `4-` filename prefix |
| Seq 4 (Aug 28) | Today’s “collect agent answers” folder | Only the wrapper that copied older packs |
| Pattern md | One markdown per Blueprints pattern | e.g. karpenter, sso-okta |
| Untracked (U) | Git does not track the file yet | Normal until you `git add` Adocs |
| Dual-write copy | Same files under Files and Adocs | Mobile/cloud can open either tree |
