# 高度人才永住申请材料清单

```
准备高度人才积分永住？
  │
  ├─ 先确认路径
  │     80点+ → 最短在留1年（申请时+1年前都要≥80）
  │     70–79点 → 最短在留3年（申请时+3年前都要≥70）
  │
  ├─ 先跑自检（任一 No 风险很高）
  │     永住许可申请セルフチェックシート（就労資格用）
  │
  ├─ 通用材料（所有人都要）
  │     申请表、照片、理由书、住民票、税/年金/医保、身元保証、了解书…
  │
  ├─ 高才专属
  │     积分计算表 + 疎明资料（不必每项都交，够70/80分即可）
  │     80点：2张表（申请时 + 1年前）
  │     70点：2张表（申请时 + 3年前）
  │
  └─ 提交前
        日本证明3个月内 / 外语附日文翻译 / 缺件会大幅拖审
```

| 问题 | 答案 |
| --- | --- |
| 高才永住是什么？ | 用**积分**证明你是「高度人才」，缩短永住所需在留时间 |
| 70分路径 | 申请时≥70分，且**3年前**也≥70分 → 在留满**3年**可申请 |
| 80分路径 | 申请时≥80分，且**1年前**也≥80分 → 在留满**1年**可申请 |
| 必须持有高度専門職签证吗？ | **不一定** — 技人国等签证也可，只要能积分并证明 |
| 官方依据 | 出入国在留管理厅「永住许可申请４」系列页面 |

## Summary

高度人才积分永住 = **普通永住材料** + **积分计算表** + **能凑够分数的疎明资料**。70分走3年路径，80分走1年路径；两种路径都要证明**两个时间点**都达标。税、年金、医保**不能欠缴/迟缴**，否则高才加分也救不了。下面清单按「先准备什么 → 通用材料 → 高才专属 → 按你得分项准备疎明资料」排列，便于逐项打勾。

**免责声明：** 以下为根据出入国在留管理厅公开资料的整理，**不构成法律意见**。个案（家属、自营业、换工作、欠税等）请以入管局最新页面和行政书士为准。

---

## 一、先确认：你属于哪条路径？

| 路径 | 分数要求 | 在留时间 | 两个时间点都要证明 |
| --- | --- | --- | --- |
| **80分（1年）** | 申请时 ≥80 | 连续在留 ≥1年 | **申请当日** + **1年前** 均 ≥80 |
| **70分（3年）** | 申请时 ≥70 | 连续在留 ≥3年 | **申请当日** + **3年前** 均 ≥70 |

| 你的在留资格 | 官方材料页（示例） |
| --- | --- |
| 已是「高度専門職」且80分+ | [永住许可申请４－（１）－ア](https://www.moj.go.jp/isa/applications/procedures/nyuukokukanri07_00130.html) |
| 非高度専門職但80分+（如技人国） | [永住许可申请４－（１）－イ](https://www.moj.go.jp/isa/applications/procedures/nyuukokukanri07_00132.html) |
| 已是「高度専門職」且70–79分 | [永住许可申请４－（２）－ア](https://www.moj.go.jp/isa/applications/procedures/nyuukokukanri07_00133.html) |
| 非高度専門職但70–79分 | [永住许可申请４－（２）－イ](https://www.moj.go.jp/isa/applications/procedures/nyuukokukanri07_00132.html)（入管页面会交叉引用） |

**注意：** 配偶、被扶养子女**不享受**1年/3年缩短；他们走一般永住规则（通常需10年在留等）。

## 二、申请前自检（强烈建议先做）

| 检查项 | 说明 |
| --- | --- |
| 永住许可申请セルフチェックシート（就労資格用） | 入管要求一并提交；**任一项 No → 不许可可能性很高** |
| 提出書類チェックシート（70点/80点 高度専門職） | 按你的分数档下载对应版 |
| 近3年住民税 | 无迟延缴纳（天引き除外需另证） |
| 近2年年金 | 无未纳、无迟纳 |
| 近2年医保 | 同上 |
| 近3年国税 | 五税目「納税証明書（その３）」无未纳 |
| 在留期间 | 无长期离境、无违法在留 |

## 三、通用材料清单（所有高才永住申请）

以下编号对应入管官方「永住许可申请４」系列；**日本机关出具的证明原则上需发行日起3个月内**。

### A. 申请表与身份

| # | 材料 | 份数 | 要点 |
| --- | --- | --- | --- |
| 1 | 永住许可申請書 | 1 | 官网 PDF/Excel 下载，**单面打印** |
| 2 | 照片 | 1 | 4cm×3cm，申请前3个月内；1岁及以上需提交（令和8年6月14日后规则） |
| 3 | 理由書 | 1 | 自由格式说明为何需要永住；外语需日文翻译 |
| 4 | 住民票（世帯全員） | 1 | **マイナンバー可省略**，其余不可省略 |
| 11 | 护照或在留资格证明 | 提示 | 无法提示则交理由书 |
| — | 在留カード | 提示 | 代申请需本人携带；有資格外活動许可一并提示 |
| 15 | 了解書 | 1 | 2021年10月起**必须** |

### B. 工作与收入

| # | 材料 | 份数 | 要点 |
| --- | --- | --- | --- |
| 5 | 职业证明 | 1 | **公司职员：**在職証明書；**自营业：**确定申告控え/法人登記/营业许可等 |
| 6 | 所得与纳税（近3年） | 多套 | 见下节「税务」 |
| 10 | 资产证明 | 适宜 | 通帐复印件、不动产登记等 |

### C. 税务（近3年 — 重点审查）

| 子项 | 材料 | 要点 |
| --- | --- | --- |
| 住民税 | 课税（或非课税）证明书 + 纳税证明书 | 各1通/年，共3年；**总所得+纳税状况** |
| 住民税迟纳 | 通帐/领收书等 | 若非全程工资天引き，需证无迟延 |
| 国税 | 納税証明書（その３） | **源泉/申告所得税、消费税、相続税、贈与税** 五税目各1 |
| 其他所得 | 通帐复印件等 | 适宜 |

### D. 年金与医保（近2年）

| 子项 | 材料 | 适用情况 |
| --- | --- | --- |
| 年金 | ねんきん定期便（全期间）或 ねんきんネット「各月の年金記録」打印 | 厚生年金等 |
| 年金 | 国民年金保险费领收书复印件 | 近2年有国民年金加入期 |
| 医保 | 健康保険被保険者証复印件（世帯全员） | 现加入健保 |
| 医保 | 国民健康保险相关证明/领收 | 近2年有国保期 |
| 医保 | マイナ保険証 / 資格確認書 | 令和6年12月后健康保険证废止后的替代 |
| 事业主 | 社会保険料领收或纳付证明 | 若你是适用事業所事業主 |

**隐私：** 年金番号、保険者番号等需**涂黑至无法复原**。

### E. 身元保証

| # | 材料 | 份数 |
| --- | --- | --- |
| 12-(1) | 身元保証書 | 1 |
| 12-(2) | 保证人身份资料 | 驾照复印件等 |

保证人须为**日本国籍**或**永住者/特别永住者**等（详见身元保証書记载要求）。

### F. 可选加分

| # | 材料 | 说明 |
| --- | --- | --- |
| 13 | 贡献资料 | 表彰、推荐状等 — **有则提交** |

## 四、高度人才专属材料（必交）

| # | 材料 | 70分路径 | 80分路径 |
| --- | --- | --- | --- |
| 8 | 高度専門職ポイント計算表 | 申请时 **1通** | 申请时 **1通** |
| 8 追加 | 过去时点计算表 | **3年前** **1通** | **1年前** **1通** |
| 9 | 各项目疎明资料 | 够70分即可，**不必每项都交** | 够80分即可 |
| — | 資料転用願出書 | 复用以前提交过的资料时 | 同上 |

**计算表类型：** 按活动区分选 **イ（研究）/ ロ（技術·人文）/ ハ（经营·管理）** 对应表格。

**疎明资料原则：** 只交「用来凑满70或80分」的项目证明；计算表背面/官网有基本示例。

---

## 五、按积分项目准备疎明资料（按需勾选）

| 积分项目 | 常见疎明资料 | 备注 |
| --- | --- | --- |
| 学历 | 毕业证、学位证复印件 + 日文翻译 | 海外学历可能需额外说明 |
| 职历 | 在职证明（含过去公司） | 职务、期间、业务内容 |
| 年收（现在） | 雇用契约书、将来收入见込证明书 | 公司出具 |
| 年收（过去） | 住民税课税证明（记载总所得） | 3年前时点用当时收入证明 |
| 年龄 | 护照复印件 | — |
| 日语能力 | JLPT N1/N2 合格通知或证书 | — |
| 日本学位 | 日本大学学位证明 | 额外加分 |
| 研究业绩 | 论文、专利、研究概要 | 研究者路线 |
| 年收入特别加分 | 同上 + 源泉票/课税证明 | 高分常靠年收 |

**80分/70分「过去时点」：** 3年前或1年前的分数要用**当时**的学历、职历、年收资料证明 — 不是只用现在的材料。

若曾收到入管「高度専門職ポイント計算結果通知書」且分数达标，**该时点**的部分疎明可能可省略（以入管说明为准）。

## 六、准备时间线（建议倒推）

| 阶段 | 时间 | 动作 |
| --- | --- | --- |
| T-6个月 | 早 | 确认近3年税/近2年年金医保无欠缴；开始攒领收书 |
| T-3个月 |  | 向市区町村开住民税证明（3年分） |
| T-3个月 |  | 向税務署开納税証明書（その３）五税目 |
| T-2个月 |  | 申请ねんきん定期便（全期间封书，约需2个月）或打印ねんきんネット |
| T-1个月 |  | 填积分计算表（申请时 + 过去时点各1张） |
| T-1个月 |  | 按得分项收集疎明资料；写理由书；找身元保证人 |
| T-2周 |  | 跑自检表；照片；所有日本证明确认在3个月有效期内 |
| 申请日 |  | 入管局窗口或在线（若适用）提交 |

## 七、常见拒签风险（高才也适用）

| 风险 | 说明 |
| --- | --- |
| 税迟纳/未纳 | 住民税、国税任一有问题都极危险 |
| 年金医保欠费 | 近2年有空白或迟纳 |
| 在留期间违法 | 超时打工、签证与实态不符 |
| 分数时点不达标 | 只现在80分，1年前/3年前不够 |
| 材料缺件 | 入管明确说缺件会**大幅延迟**且可能不利益 |
| 身元保证人不合格 | 身份或填写错误 |

## Data flow map

```
确认 70/80 分路径 + 两个时间点分数
  │
  ├─ 通用永住包
  │     申请表 / 照片 / 理由书 / 住民票
  │     在职证明 / 3年税 / 2年年金医保 / 资产
  │     身元保証 / 了解书 / 自检表
  │
  ├─ 高才加分包
  │     积分计算表 ×2（现在 + 1年前或3年前）
  │     疎明资料（仅覆盖得分项）
  │
  └─ 入管局审查 → 许可 / 补件 / 不许可
```
