# Glossary

| Term | What it means |
|---|---|
| ESG | Enterprise service gateway (CoreIT) that Emma BE calls |
| Emma BE | The OpenPaaS backend (myaxa backend) making the calls |
| SocketTimeoutException | Java error raised when a network call waits too long for a reply |
| Splunk append | Adds the results of a second search to the first one |
| DQL or | Keeps a line if either condition is true; used here instead of append |
| Throttle | Splunk setting that mutes repeat alerts for a period |
| alertIdentityFields | Fields that decide which rows belong to the same open problem |
