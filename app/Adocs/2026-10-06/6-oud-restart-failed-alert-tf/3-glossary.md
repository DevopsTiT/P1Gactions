# Glossary

| Term | What it means |
|---|---|
| OUD | Oracle Unified Directory, an LDAP directory server |
| asinst_1 | The OUD instance folder on the server |
| Splunk index ods | The Splunk storage bucket holding OUD logs |
| sourcetype oud_service | The Splunk label for the OUD service log |
| caseSensitive:false | DQL option so "Failed" and "FAILED" also match |
| Records detector | Dynatrace detector that alerts on every row its query returns |
