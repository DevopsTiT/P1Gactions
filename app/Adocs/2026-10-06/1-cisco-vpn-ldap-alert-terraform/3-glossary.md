# Glossary

| Term | What it means |
|---|---|
| Cisco ASA | Cisco firewall that also terminates VPN connections |
| AAA server | Server used for authentication, authorization and accounting |
| LDAP | Directory protocol used here to check Windows usernames and passwords |
| aaa-server group | A set of AAA servers the ASA can use; here Windows_LDAP |
| %ASA-2-113022 | ASA message: an AAA server was marked FAILED; severity 2 is critical |
| Syslog | Standard way network devices send log lines to a collector |
| Static-threshold detector | Dynatrace rule that fires when a value goes above a fixed number |
| dealertingSamples | Quiet minutes needed to close the problem |
| locals | Terraform values defined once and reused in the file |
