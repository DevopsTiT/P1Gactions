# Glossary

| Term | What it means |
|---|---|
| Egress proxy | Proxy that outbound traffic leaves through; its public IP is what outside systems see |
| ESG | The gateway where the public IPs are checked |
| /maam/ | API path in the API gateway logs that this alert watches |
| Absence alert | Alert that fires when expected data stops arriving |
| summarize count() | DQL aggregation; without "by" it always returns one row, even for 0 |
| alertIdentityFields | Fields that decide which rows belong to the same open problem |
