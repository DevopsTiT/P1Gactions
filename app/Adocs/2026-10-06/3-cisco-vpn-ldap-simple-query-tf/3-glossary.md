# Glossary

| Term | What it means |
|---|---|
| contains | True when the text includes the given string |
| matchesValue | True when a field matches a value; `*` is a wildcard |
| makeTimeseries | Turns log lines into a count per time bucket |
| Time series | A list of numbers over time, one per minute here |
| Static-threshold detector | Fires when the count goes above a fixed number |
