# Glossary

| Term | What it means |
|---|---|
| Records data type | Detector mode where each row the query returns is an alert |
| Timeseries data type | Detector mode that checks a per-minute number against a threshold |
| RecordAnomalyDetectionAnalyzer | The Terraform analyzer name for the Records mode |
| alertIdentityFields | Fields that decide which rows belong to the same open problem |
| Default lookback | Records queries without from: read the last 2 hours |
