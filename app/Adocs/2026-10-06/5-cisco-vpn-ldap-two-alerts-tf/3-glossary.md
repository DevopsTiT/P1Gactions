# Glossary

| Term | What it means |
|---|---|
| for_each | Terraform loop that creates one resource per map entry |
| locals | Values defined once in the Terraform file and reused |
| Splunk index | Storage bucket name in Splunk |
| Splunk sourcetype | Label for the log format, such as cisco:asa |
| log.source | Dynatrace field for where a log line came from, usually a file path |
| Records detector | Dynatrace detector that alerts on every row its query returns |
