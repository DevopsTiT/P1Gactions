# Glossary

| Term | What it means |
| --- | --- |
| Scope | Which logs you include before text filters |
| Splunk index | Named bucket of many events/sources |
| aws.log_group | CloudWatch / Lambda log group attribute in Dynatrace |
| content | Main log line text in Dynatrace Grail |
| message | Common Splunk field for the log text |
| DQL | Dynatrace Query Language |
| contains | Substring match (like Splunk *error*) |
| Discover query | Count-by-source query to learn real scope |
