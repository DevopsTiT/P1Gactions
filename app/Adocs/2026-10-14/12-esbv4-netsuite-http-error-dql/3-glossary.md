# Glossary

| Term | What it means |
|---|---|
| ESB | Enterprise Service Bus, a layer that connects systems. |
| NetSuite | Oracle cloud ERP system. |
| RESTlet | Custom REST endpoint inside NetSuite. |
| `index` | Splunk storage area. Not present in Dynatrace. |
| `contains()` | Substring match in DQL. |
| `makeTimeseries` | DQL command that builds a chart over time. |
