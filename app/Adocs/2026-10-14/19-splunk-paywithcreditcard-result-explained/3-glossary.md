# Glossary

| Term | What it means |
|---|---|
| Event | One log record in Splunk. |
| `spath` | Splunk JSON field reader. |
| EXECUTION_COMPLETED | App message type for a finished call. |
| CAUGHT_EXCEPTION_ON_BACKEND | App message type for a failed call. |
| request_id | ID for one API call. |
| PC_CUSTOMER | PolicyCenter customer API, the downstream system. |
| API gateway | Front door that routes portal calls to backends. |
| S3 log forwarder | Path where pod logs are written to S3 before Splunk reads them. |
| `endsWith()` | DQL check that text ends with a value. |
