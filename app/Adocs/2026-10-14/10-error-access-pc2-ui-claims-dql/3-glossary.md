# Glossary

| Term | What it means |
|---|---|
| sourcetype | Splunk label for a log format. Not present in Dynatrace. |
| `log.source` | Dynatrace field for where a log came from. |
| `matchesPhrase()` | Whole-word match that ignores case. |
| `contains()` | Substring match. Case-sensitive by default. |
| `startsWith()` | True when text begins with the given value. |
| `http.response.status_code` | Parsed HTTP status. Exists only if a parse rule adds it. |
| ESB | Enterprise Service Bus, the middle layer the pc2-ui calls for claims data. |
