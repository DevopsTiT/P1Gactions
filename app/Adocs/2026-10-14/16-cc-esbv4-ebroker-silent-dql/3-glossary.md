# Glossary

| Term | What it means |
|---|---|
| Subsearch | Splunk inner search whose results feed the outer search. |
| `lookup` | DQL join of another query's rows onto the current rows. |
| `collectDistinct()` | Unique values as a list. Same as Splunk `values()`. |
| UUID | 36-character unique ID. |
| ebroker | Broker portal app that talks to esbv4. |
| Interceptor | ESB component that runs before or after a call. |
| `metadata type=sourcetypes` | Splunk list of sourcetypes with first and last event time. |
