# Glossary

| Term | What it means |
|---|---|
| Scanned bytes | Data Grail read for the query. |
| Bucket | Grail storage area with its own access rules. |
| ClusterLogForwarder | OpenShift setting that routes namespace logs to outputs. |
| Onboarding | Adding an app's logs to Dynatrace. |
| `dt.entity.host` | Dynatrace list of hosts it monitors. |
| `dt.entity.cloud_application` | Dynatrace list of Kubernetes workloads. |
| S3 log forwarder | Path that writes pod logs to S3 for Splunk. |
