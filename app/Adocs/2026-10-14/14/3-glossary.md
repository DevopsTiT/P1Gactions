# Glossary

| Term | What it means |
|---|---|
| `index` | Splunk storage area. |
| `startsWith()` | Prefix match in DQL. |
| `matchesValue()` | Wildcard match against one or more patterns, case ignored. |
| `matchesPhrase()` | Whole-word match, case ignored. |
| `dedup` | Removes repeated rows. |
| `parse` | Extracts fields from text using a pattern. |
| GMO | Payment gateway. |
| CVS | Convenience store payment. |
| Guidewire | Insurance platform behind bc, pc, and cc apps. |
