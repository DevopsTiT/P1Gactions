# Glossary

| Term | What it means |
|---|---|
| Subsearch | Splunk inner search feeding the outer search. |
| `lookup` | DQL join by a shared field. |
| `load` | DQL command that reads a lookup file stored in Grail. |
| `makeresults` | Splunk command that creates one starting row. |
| Synthetic HTTP monitor | Scheduled URL check in Dynatrace, with optional certificate expiry check. |
| `timestampFromUnixSeconds()` | Turns a Unix seconds number into a timestamp. |
| Quote | Insurance price request. |
