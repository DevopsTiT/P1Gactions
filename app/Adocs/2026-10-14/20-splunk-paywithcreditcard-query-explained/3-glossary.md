# Glossary

| Term | What it means |
|---|---|
| `sourcetype` | Splunk label for a log type. |
| `earliest` | Start of the time range. |
| `_raw` | Full original log line. |
| `eval` | Create or change a field. |
| `replace()` | Regex find and swap. |
| Escaped quote | `\"`, a quote protected by a backslash. |
| `spath` | Splunk JSON parser. |
| Wildcard `*` | Matches any characters. |
