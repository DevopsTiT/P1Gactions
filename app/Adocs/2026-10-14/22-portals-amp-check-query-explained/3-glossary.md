# Glossary

| Term | What it means |
|---|---|
| `fetch logs` | Read logs from Grail. |
| `filter` | Keep matching rows. |
| `contains()` | Text-inside check. |
| `caseSensitive:false` | Ignore case. |
| `summarize` | Group and count (Splunk `stats`). |
| `dt.openpipeline.source` | How the log entered Dynatrace. |
| Scanned bytes | Data read to answer the query. |
