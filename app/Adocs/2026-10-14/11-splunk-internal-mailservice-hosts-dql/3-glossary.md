# Glossary

| Term | What it means |
|---|---|
| `_internal` | Splunk's own logs about itself. |
| `index` | Splunk storage area. Closest Dynatrace field is `dt.system.bucket`. |
| `metadata type=hosts` | Splunk command listing hosts with first and last event time. |
| `makeTimeseries` | DQL chart-over-time command. |
| `arraySum()` | Adds up all numbers in an array. |
| `coalesce()` | Returns the first value that is not empty. |
| `stringLength()` | Character count of a text value. |
| `bin()` | Rounds a timestamp down to a bucket, such as one day. |
| Catalina | The Tomcat server engine. Its startup line shows a restart. |
