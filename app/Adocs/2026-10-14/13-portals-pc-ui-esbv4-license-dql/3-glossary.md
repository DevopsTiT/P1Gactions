# Glossary

| Term | What it means |
|---|---|
| `spath` | Splunk JSON field reader. |
| `parse ..., "JSON:j"` | DQL JSON reader. Puts fields into record `j`. |
| `replaceString()` | DQL text replace. |
| `timeseries` | DQL command for metrics. |
| `countDistinctExact()` | Exact count of unique values. |
| `countIf()` | Counts rows that match a condition. |
| `k8s.workload.name` | Name of the Deployment or DeploymentConfig. |
| CPU limit | Maximum CPU a container may use. |
| Metaspace | Java memory area for class metadata. |
| Alfresco | Document management system. |
