# Glossary

| Term | What it means |
|---|---|
| `ALNUM` | DQL parse matcher for letters and digits. |
| errcode | GMO error code group, such as E01. |
| errinfo | GMO detailed error code, such as E01130002. |
| ExecTran | GMO call that runs a payment. |
| SearchTrade | GMO call that looks up a payment status. |
| Producer | Insurance agent or broker in Guidewire. |
