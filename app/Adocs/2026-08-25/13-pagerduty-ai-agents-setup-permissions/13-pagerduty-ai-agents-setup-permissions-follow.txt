ENGLISH

Verdict
- To TURN ON all 4 product agents (SRE, Scribe, Shift, Insights): need PagerDuty Advance + Account Owner or Global Admin in AI → AI Settings.
- To USE them as on-call: Responder (or higher) + linked Slack/Teams user + membership on a team with Advance access.
- REST API tokens are NOT required for product agent UI setup (that is seq 7 DIY API POC only).

--------------------------------------------------------------------------------
1) PagerDuty roles
--------------------------------------------------------------------------------
| Role              | Connect Slack/Teams for Advance | Enable/disable 4 agents | Use agents after enable      |
|-------------------|---------------------------------|-------------------------|------------------------------|
| Account Owner     | Yes                             | Yes                     | Yes                          |
| Global Admin      | Yes                             | Yes                     | Yes                          |
| Admin             | Yes (initial chat map)          | Prefer Owner/Global Admin for toggles; some agent pages also list Admin | Yes |
| Manager           | Channel maps after workspace linked | No — Request to Admin | Yes if team has Advance      |
| Responder         | No                              | No — Request to Admin   | Yes if team has Advance      |

Path to enable: AI → AI Settings → Assistant and AI Agents Configuration → toggle each agent Enabled.

--------------------------------------------------------------------------------
2) Advance entitlement + team access
--------------------------------------------------------------------------------
- Account must have PagerDuty Advance (add-on / AI Actions / trial) on Professional, Business, or Enterprise.
- AI Settings → Access: toggle teams (default ALL teams on).
- Enforcement = your PagerDuty team membership (web + Slack + Teams + API).
- AI Actions: SRE and Scribe consume credits; Shift and Insights do not (per PD Advance table).

--------------------------------------------------------------------------------
3) Per-agent extras (same enable screen)
--------------------------------------------------------------------------------
- SRE: optional Connectors; Ops Console needs AIOps + Advance; Slack may need reauthorize; Teams Early Access.
- Scribe: meeting platform setup (Zoom captions / Teams lobby / Google Meet); needs AI Actions; any linked user can add to meeting.
- Shift: Slack-preferential; Level-1 escalation schedules; Google Calendar Extension = Admin or Account Owner.
- Insights: often auto-on with Advance; proactive weekly DMs to Owner/Admins/(Team) Managers; link Slack for DMs.

--------------------------------------------------------------------------------
4) Slack (if using Slack)
--------------------------------------------------------------------------------
- Slack workspace Admin/Owner: approve PagerDuty app install/updates.
- PD Admin+: map workspace; AI Settings Slack = Connected.
- If Slack shows "Update required": enable optional Advance scopes (channel history for better summaries).
- Core scopes (examples): app_mentions:read, assistant:write, chat:write, commands, im:history.
- Optional richer Advance: channels:history, groups:history, files:read, reactions:read/write.
- Each responder: link PD ↔ Slack account.

--------------------------------------------------------------------------------
5) Microsoft Teams (if using Teams) — PD-side; Graph detail = seq 10
--------------------------------------------------------------------------------
- PD Admin+: connect Teams in AI Settings; toggle Enabled.
- Microsoft Admin: Graph consent.
- Advance must-have Graph: ChatMessage.Read (delegated) and/or ChatMessage.Read.All (application).
- Full Graph table: Daily Files 2026-08-25/10-pagerduty-teams-only-permissions/
- Teams-only: SRE (EA), Scribe, Insights chat OK; Shift is Slack-first.

--------------------------------------------------------------------------------
6) API tokens
--------------------------------------------------------------------------------
- Product agents UI enable/use: NO REST API token.
- Custom code calling Events/REST (seq 7): YES — routing key + REST token.

--------------------------------------------------------------------------------
CHECKLIST A — Turn on all 4
--------------------------------------------------------------------------------
[ ] Advance entitlement on account
[ ] Logged in as Account Owner or Global Admin
[ ] Slack and/or Teams Connected in AI Settings
[ ] Slack Admin approved app / optional scopes (if Slack)
[ ] MS Admin Graph consent (if Teams) — see seq 10
[ ] Toggle SRE + Scribe + Shift + Insights = Enabled
[ ] Access tab: POC teams enabled; users on those teams
[ ] Extras: Level-1 schedules (Shift), meeting URL platform (Scribe), optional SRE connectors

CHECKLIST B — Use as responder
--------------------------------------------------------------------------------
[ ] Agents already enabled by admin
[ ] On a team with Advance access
[ ] PD ↔ Slack or Teams linked
[ ] Can open incident channel / Ops Console and ask agents
[ ] No REST API token needed for this path

中文

结论
- 要「打开」全部 4 个产品 Agent（SRE / Scribe / Shift / Insights）：需要 PagerDuty Advance，并由 Account Owner 或 Global Admin 在 AI → AI Settings 里开启。
- 要「当值班人使用」：Responder（或更高）+ 已关联 Slack/Teams 账号 + 所在 Team 已开通 Advance。
- 产品 Agent 的 UI 开通不需要 REST API Token（Token 是 seq 7 自定义 API POC 才要）。

--------------------------------------------------------------------------------
1) PagerDuty 角色
--------------------------------------------------------------------------------
| 角色            | 连接 Slack/Teams | 开关 4 个 Agent | 开通后使用 |
|-----------------|------------------|-----------------|------------|
| Account Owner   | 可以             | 可以            | 可以       |
| Global Admin    | 可以             | 可以            | 可以       |
| Admin           | 可以（首次对接） | 官方 Advance「开关 Agent」写的是 Owner/Global Admin；部分 Agent 文档也写 Admin | 可以 |
| Manager         | 工作区连好后可做频道映射 | 不行 → Request to Admin | Team 有 Advance 即可 |
| Responder       | 不行             | 不行 → Request to Admin | Team 有 Advance 即可 |

路径：AI → AI Settings → Assistant and AI Agents Configuration → 把各 Agent 拨到 Enabled。

--------------------------------------------------------------------------------
2) Advance 权益与 Team 访问
--------------------------------------------------------------------------------
- 账号需有 Advance（加购 / AI Actions / 试用）。
- AI Settings → Access：按 Team 开关（默认全部开）。
- 按用户所属 Team 生效（Web / Slack / Teams / API 相同）。
- AI Actions：SRE、Scribe 会消耗；Shift、Insights 不消耗（按官方表）。

--------------------------------------------------------------------------------
3) 各 Agent 额外条件
--------------------------------------------------------------------------------
- SRE：可选 Connectors；Ops Console 还要 AIOps；Slack 可能要重新授权；Teams 为 Early Access。
- Scribe：会议平台设置；需要 AI Actions；关联账号的用户可把 Scribe 拉进会议。
- Shift：偏 Slack；关注 Level-1 值班表；Google Calendar 扩展需 Admin 或 Owner。
- Insights：常随 Advance 自动可用；周报 DM 给 Owner/Admin/(Team) Manager；需关联 Slack。

--------------------------------------------------------------------------------
4) Slack
--------------------------------------------------------------------------------
- Slack 工作区 Admin/Owner 批准应用安装/更新。
- PD Admin+ 映射工作区；AI Settings 显示 Connected。
- 若显示 Update required：打开可选 Advance scopes。
- 每人关联 PD ↔ Slack。

--------------------------------------------------------------------------------
5) Microsoft Teams（Graph 明细见 seq 10）
--------------------------------------------------------------------------------
- PD 侧：Admin+ 在 AI Settings 连接并启用 Teams。
- Microsoft Admin：同意 Graph。
- Advance 关键：ChatMessage.Read / ChatMessage.Read.All。
- 完整表：10-pagerduty-teams-only-permissions。
- Teams-only：SRE(EA)/Scribe/Insights 可用；Shift 以 Slack 为主。

--------------------------------------------------------------------------------
6) API Token
--------------------------------------------------------------------------------
- 产品 Agent UI：不需要 REST Token。
- 自己写代码调 Events/REST（seq 7）：需要。

--------------------------------------------------------------------------------
清单 A — 打开全部 4 个
--------------------------------------------------------------------------------
[ ] 账号有 Advance
[ ] 用 Owner 或 Global Admin 登录
[ ] Slack 和/或 Teams 已 Connected
[ ] Slack Admin 已批准（若用 Slack）
[ ] MS Admin 已同意 Graph（若用 Teams，见 seq 10）
[ ] SRE / Scribe / Shift / Insights 全部 Enabled
[ ] Access：POC Team 打开；人在这些 Team 里
[ ] 额外：Level-1 排班（Shift）、会议链接（Scribe）、可选 SRE Connectors

清单 B — 值班人使用
--------------------------------------------------------------------------------
[ ] Admin 已打开 Agent
[ ] 所在 Team 有 Advance
[ ] 已关联 PD ↔ Slack 或 Teams
[ ] 能在事件频道 / Ops Console 调用 Agent
[ ] 这条路径不需要 REST API Token
