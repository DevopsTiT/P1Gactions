ENGLISH — Teams-only enablement + four-agent POC deltas vs Slack

Verdict
If you only use Microsoft Teams (no Slack), you can still POC:
- SRE Agent (Teams Early Access + web SRE tab)
- Scribe Agent (Teams transcript delivery + Teams/Zoom/Meet bridge)
- Insights Agent conversational Q&A in Teams
You should treat as limited / out of scope without Slack:
- Shift Agent full coverage DM path (docs = Slack notification rules / Slack workspace)
- Insights weekly proactive maturity nudges (docs = Slack app DMs + Slack account link)

Decision tree
- Advance? no → Sales/trial
- yes → AI → AI Settings → Assistant and AI Agents Configuration
- Connect Microsoft Teams → Optional Permissions → Connected → Enabled
- Enable agents → linkUser → test Service only
- SRE / Scribe / Insights chat → Teams-only OK
- Shift full path / Insights weekly DM → Slack-first

POC 1 — SRE Agent (Teams)
================================================================================

Delta vs Slack
- Slack: SRE Agent Triage button + @pagerduty
- Teams: Early Access; type @pagerduty <question>; use Incident details SRE Agent tab as fallback

Setup
1) Enable SRE Agent
2) Confirm Teams Advance Connected + Enabled
3) Optional one real connector (Grafana/Datadog/New Relic/CloudWatch/Confluence/GitHub)
4) Test Service + you-only escalation
5) Map Teams channel / dedicated incident chat
6) Prepare runbook .md/.txt < 100 KB

Demo
1) Create low-urgency test incident
2) In Teams channel: @pagerduty What are some likely root causes?
3) Upload/Update Runbook (Teams nudge or web SRE tab)
4) @pagerduty Analyze past incidents
5) @pagerduty What steps should I take first?
6) Approve/decline remediations manually — no prod auto-run
7) Optional: Incident details → SRE Agent tab
8) Resolve incident so memory can save

Pass
- Grounded reply in Teams or web
- Runbook referenced later
- No remediation without confirm

POC 2 — Scribe Agent (Teams)
================================================================================

Delta vs Slack
- Delivery: Teams Supported (same as Slack Supported)
- Manual add: @PagerDuty advance scribe  (not /pd scribe)
- As of 2026-07-23: can join without chat for internal/PIR; still map Teams channel if humans must SEE transcript
- Teams meetings: no registration/CAPTCHA; lobby bypass optional; “Unverified” label is cosmetic

Setup
1) Enable Scribe Agent
2) Keep Teams Advance on for visible transcripts
3) Meeting path ready (Teams meeting ideal for Teams-only story)
4) Auto-launch OR manual @PagerDuty advance scribe
5) Optional workflow: Add PagerDuty Advance Scribe Agent

Demo
1) Test incident + conference URL (with passcode)
2) Open mapped Teams channel
3) Auto-join OR @PagerDuty advance scribe → Add Scribe Agent to meeting
4) Human joins within 15 minutes
5) Speak 2–3 clear sentences
6) End meeting → confirm live transcript (if delivery on) + post-meeting summary
7) Optional PIR draft includes bridge context

Pass
- Scribe joins meeting
- Teams shows transcript and/or summary
- Keep POC < ~10 minutes to save AI Actions

POC 3 — Shift Agent (Teams LIMITED)
================================================================================

Delta vs Slack
- Docs: activates with Advance + Slack integration by default
- Conflict/coverage notification rules auto-created for Slack workspace when linking Slack
- Coverage candidates contacted via those notification rules
- Teams-only: do NOT claim a full DM coverage POC unless your tenant proves Teams notifications

Honest stance
- Full path (conflict DM → Request coverage → accept → schedule write) = Slack-first today
- Teams-only org: mark Shift out of scope, or only try Advance chat “Do I have a conflict?” as a bonus signal

Partial try (optional)
1) Enable Shift; Level-1 TEST schedule only
2) Google Calendar Extension on
3) Ask in Teams Advance: I am on vacation <date>. Do I have a conflict?
4) If Request coverage appears, watch for Teams candidate notify
5) If no Teams notify → record gap; stop; do not touch prod schedules

Pass (Teams-only)
- Limitation documented
- Test schedule only
- Bonus if conflict Q&A works in Teams chat

4) Sanity-check Analytics UI

- Channel can see the reply
- Weekly path correctly labeled if no Teams DM
