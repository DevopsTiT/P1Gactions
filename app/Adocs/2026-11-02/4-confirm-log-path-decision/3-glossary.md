# Glossary

| Term | What it means |
|---|---|
| Host page | The Dynatrace screen for one machine. Processes and the host group are here. |
| Notebook | The place you run DQL. |
| `log.source` | The file path Dynatrace stored with the log line. |
| Host group | The set of machines a setting applies to. |
| Sensitive data masking | The settings page for rules that hide personal data in logs. |
| `ls -l` | The server command that shows whether a file exists and when it last changed. |
