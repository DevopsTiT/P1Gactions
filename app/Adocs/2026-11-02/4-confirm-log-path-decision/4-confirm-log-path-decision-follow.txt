2. File
In a Notebook, Last 2 hours (widen to 7 days if the known hosts are quiet):

fetch logs
| filter contains(log.source, "/app/ICM_CPW/log/ap/default.log", caseSensitive:false)
| summarize lines = count(), by: { host.name }
| sort host.name asc

Rows for CEAAI016, CEAA9026, and CEAA9027 mean the query works.
No row for CEAA20F7 means Dynatrace is not storing that file for this host. The file can still be on disk.

On CEAA20F7 itself:

ls -l /app/ICM_CPW/log/ap/default.log

No such file, or an old date: stop.
File exists and the date is recent: continue.

fetch dt.entity.host
| filter dt.entity.host_group == "HOST_GROUP-9034BF4FC7D158B2"
| fields entity.name, id
| sort entity.name asc

If any member should not send this file, do not use this group.
