# Glossary

| Term | What it means |
|---|---|
| Purpose | Which hosts you actually need this log from. |
| Host group | The Dynatrace set named in `scope`. A rule there hits every member. |
| Custom log source | Tells the agent to read the file. |
| Log storage | Tells Dynatrace to keep the matched lines. |
| `send_to_storage` | The switch that stores the lines. |
| Mask | The rule that hides personal data before people read the stored log. |
