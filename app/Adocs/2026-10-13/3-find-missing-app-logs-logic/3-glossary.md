# Find Missing App Logs Logic Glossary

| Term | What it means |
|---|---|
| Entity | Something Dynatrace knows exists, such as a host. |
| Ingest path | Route a log line takes into Dynatrace. |
| dt.openpipeline.source | Which door a log came through. |
| log.source | File or sender of a log line. |
| Sibling app | Similar working app used for comparison. |
| Onboarding gap | App not added to an ingest path. |
