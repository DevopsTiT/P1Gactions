# eopt Onboarding Flow Explained Glossary

| Term | What it means |
|---|---|
| Namespace | Folder for one app's pods. |
| OpenShift log forwarder | Cluster setting that copies pod logs to destinations. |
| Pipeline | Forwarder rule mapping namespaces to a destination. |
| /api/v2/logs/ingest | Dynatrace API for log lines. |
| Grail | Dynatrace data store. |
| Onboarding | Adding a namespace to the forwarder pipeline. |
| coalesce | DQL function that returns the first non-empty value. |
