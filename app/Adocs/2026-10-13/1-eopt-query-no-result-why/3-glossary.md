# Why eopt Query Has No Result Glossary

| Term | What it means |
|---|---|
| Host entity | Dynatrace record that a host exists. |
| Log record | One stored log line. `fetch logs` searches only these. |
| App only monitoring | OneAgent mode inside a container. No pod log collection. |
| Log ingest | Sending logs into Dynatrace. |
| Scanned bytes | How much data a query read. |
| Tenant | One Dynatrace environment, such as DT STG or DT PRD. |
| `startsWith` | DQL text check, case sensitive by default. |
