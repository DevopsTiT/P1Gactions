# Cisco VPN LDAP Log Source Glossary

| Term | What it means |
|---|---|
| `log.source` | Dynatrace field holding the file path or source of a log line. |
| Cisco ASA | Cisco firewall and VPN appliance. |
| LDAP | Protocol for checking logins against Windows Active Directory. |
| Syslog collector | Server receiving device logs, here ljcmgt14. |
| Records detector | Dynatrace rule running DQL every minute that opens a problem when rows return. |
| Identity field | Field deciding whether a row belongs to an existing problem. |
