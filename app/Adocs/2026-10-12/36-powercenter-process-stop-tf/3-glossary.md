|---|---|
| PowerCenter | Informatica batch data integration server. |
| ISP_MASTER_ELECT_LOCK | Message when a node tries to take the master election lock. |
| Results greater than 0 | Fire on any matching line. |
| Identity field | Field deciding whether a row joins an existing problem. |
| `host.name` | The server that wrote the log line. |
