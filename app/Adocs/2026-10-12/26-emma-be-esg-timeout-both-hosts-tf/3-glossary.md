# Emma BE ESG Timeout Both Hosts Glossary

| Term | What it means |
|---|---|
| API gateway | Layer7 gateway routing API calls between systems. |
| SSG | The Layer7 gateway process name in the log lines. |
| local4 | A syslog channel; the gateway writes to `local4.log`. |
| Pod | One running copy of an app in Kubernetes. |
| `startsWith` | DQL check that text begins with a value. |
| `countIf` | DQL count of rows matching a condition. |
| Identity field | Field deciding whether a row joins an existing problem. |
