# eopt Backend Hosts Only Glossary

| Term | What it means |
|---|---|
| Backend | The API services, eoptsystemapi and eoptprocessapi. |
| Frontend | The web UI service, eoptfrontend. |
| Pod prefix | Fixed start of a pod name. |
| `parse` | DQL field extraction with a pattern. |
| Identity field | Field deciding whether a row joins an existing problem. |
