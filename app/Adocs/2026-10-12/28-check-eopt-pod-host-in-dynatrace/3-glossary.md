# Check eopt Pod Host Glossary

| Term | What it means |
|---|---|
| Host entity | Dynatrace record of one monitored host, with a HOST- ID. |
| App only monitoring | OneAgent inside the container. Each pod becomes a host. |
| OpenShift | Red Hat Kubernetes platform behind OpenPaaS. |
| `host.name` | Host name on a log line. |
| `dt.entity.host` | Host ID on a log line. |
| `entityName()` | DQL function returning an entity's name from its ID. |
| `loglevel` | Dynatrace field with the detected log level. |
| Notebook | Dynatrace page for running DQL. |
