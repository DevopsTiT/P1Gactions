# OUD Restart Failed Glossary

| Term | What it means |
|---|---|
| OUD | Oracle Unified Directory, an LDAP directory server. |
| `host.name` | Dynatrace field with the server name a log line came from. |
| `log.source` | Dynatrace field with the file path a log line came from. |
| Splunk index | Named storage bucket for logs in Splunk. |
| sourcetype | Splunk label for a log format. |
| Records detector | DQL query run every minute that opens a problem when rows return. |
| Identity field | Field deciding whether a row joins an existing problem. |
