# Control-M Abend Alert V2 Glossary

| Term | What it means |
|---|---|
| Control-M | BMC job scheduler for batch jobs. |
| Abend | Abnormal end. The job failed. |
| Ended not OK | Control-M status text for a failed job. |
| `eval` | Splunk command that creates fields. |
| `fieldsAdd` | DQL command that creates fields. |
| `parse` | DQL command that extracts values from the log text. |
| `substring` | DQL text cut. Counts from 0, end not included. |
| Left join | Add columns from another search, keep rows without a match. |
| Identity field | Field deciding whether a row joins an existing problem. |
