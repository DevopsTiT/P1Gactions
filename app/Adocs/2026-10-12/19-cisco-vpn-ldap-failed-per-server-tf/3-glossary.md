# Cisco VPN LDAP Per Server Glossary

| Term | What it means |
|---|---|
| ASA-2-113022 | Cisco ASA message: AAA server marked as FAILED. Level 2 is critical. |
| aaa-server group | List of login servers the ASA uses, here Windows_LDAP. |
| LDAP | Protocol for checking logins against Windows Active Directory. |
| Syslog collector | Server that receives device logs, here ljcmgt14. |
| `parse` | DQL command that extracts values from text. |
| `NSPACE` | DQL pattern for any run of characters without a space. |
| Identity field | Field deciding whether a row belongs to an existing problem. |
| Ingestion delay | Time before a log line becomes searchable. |
