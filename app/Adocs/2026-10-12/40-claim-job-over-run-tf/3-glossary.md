# Claim Job Over Run Glossary

| Term | What it means |
|---|---|
| Over run | A job running longer than expected. |
| `inputlookup` | Splunk command that reads a lookup table (CSV). |
| ORDERID | Control-M id for one ordered run of a job. |
| RUNNO | Run number, goes up on rerun. |
| daily_ctmag log | Control-M agent daily log with job start and end lines. |
| `min(if(...))` | Smallest value among rows that match the condition. |
| `isNull` | True when a field has no value. |
| Identity field | Field deciding whether a row joins an existing problem. |
