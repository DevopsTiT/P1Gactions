# Emma BE ESG Timeout Glossary

| Term | What it means |
|---|---|
| Emma BE | Emma backend service, running as myaxabackend pods. |
| ESG | Enterprise service gateway in CoreIT that Emma BE calls. |
| OpenPaaS | Kubernetes platform hosting the pods. |
| Pod | One running copy of an app in Kubernetes. |
| `SocketTimeoutException` | Java error when a network call waits too long. |
| `append` | Splunk command adding a second search's results. |
| `startsWith` | DQL check that text begins with a value. |
| `countIf` | DQL count of rows matching a condition. |
| Throttle | Quiet period after an alert fires. |
| Identity field | Field deciding whether a row joins an existing problem. |
