# Claim Job Over Run TF Explained Glossary

| Term | What it means |
|---|---|
| Terraform | Tool that creates settings from text files. |
| Provider | Plugin Terraform uses to talk to a product. |
| Resource | One thing Terraform creates. |
| Davis anomaly detector | Dynatrace alert that runs a query every minute. |
| DQL | Dynatrace Query Language. |
| `parse` | Cuts values out of the log text. |
| `summarize ... by` | Groups rows and computes one row per group. |
| `min(if(...))` | Smallest value among matching rows only. |
| Identity field | Field deciding which rows share one problem. |
| Problem | Open alert in Dynatrace. |
