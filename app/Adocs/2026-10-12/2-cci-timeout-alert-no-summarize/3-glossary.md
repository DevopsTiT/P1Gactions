# Glossary

| Term | What it means | Why you care |
|---|---|---|
| `summarize` | DQL command that groups rows and computes totals. | Removed here; it was only for readability. |
| Records detector | Opens a problem when the query returns rows. | Raw rows are enough. |
| `alertIdentityFields` | Fields that decide which rows belong to one problem. | Keeps one problem per log group. |
| `content` | The text of the log line. | Where you read the timeout message now. |
