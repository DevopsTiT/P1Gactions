# eopt Hosts Exist Logs Missing Glossary

| Term | What it means |
|---|---|
| Host entity | Dynatrace record of a monitored host. |
| Log record | One stored log line in Grail. |
| App only monitoring | OneAgent inside the app process; usually no container log collection. |
| Dynatrace Operator | Kubernetes component that deploys and manages Dynatrace on a cluster. |
| Log module | Operator part that reads container logs on each node. |
| S3 log forwarder | Pipeline copying logs into an S3 bucket. |
| `search` | DQL command that searches text across all fields. |
| Spans | Request records captured by OneAgent. |
| `dt.openpipeline.source` | Field showing which ingest path a log came through. |
