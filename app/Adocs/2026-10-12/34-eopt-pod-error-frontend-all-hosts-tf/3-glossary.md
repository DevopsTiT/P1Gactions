# eopt Frontend All Hosts Glossary

| Term | What it means |
|---|---|
| `spath` | Splunk command reading JSON fields. |
| `rex` | Splunk field extraction with a regular expression. |
| `parse content, "JSON:j"` | DQL turning JSON text into a record. |
| `upper()` | Turns text into capital letters. |
| Identity field | Field deciding whether a row joins an existing problem. |
