# Glossary

| Term | What it means | Why you care |
|---|---|---|
| `for_each` | Terraform loop over a map. | One block creates all nine detectors. |
| `locals` | Named values inside a Terraform file. | Holds the nine titles and queries. |
| REPORT line | Lambda's per-invocation summary with memory and duration. | Source for Alert 2. |
| `LD` | Parse pattern: any text. | Caused Alert 2's bug. |
| `INT` | Parse pattern: whole number. | Fixes Alert 2. |
| SFDC | Salesforce. | Alert 5. |
| Throttle | Silence period after an alert. | 60 seconds here, so no effect. |
