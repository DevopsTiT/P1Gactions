# OUD Restart Failed Host And Source Glossary

| Term | What it means |
|---|---|
| OUD | Oracle Unified Directory, an LDAP directory server. |
| OUD instance | One running copy of OUD, such as asinst_1. |
| access log | Record of every client request, including failed logins. |
| errors log | Record of server problems, startup and shutdown. |
| `log.source` | Dynatrace field with the file path of a log line. |
| `startsWith` | DQL check that text begins with a value. |
| `endsWith` | DQL check that text ends with a value. |
| Identity field | Field deciding whether a row joins an existing problem. |
