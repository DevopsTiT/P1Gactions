# eopt Pod Error Host Name Glossary

| Term | What it means |
|---|---|
| Pod | One running copy of an app in Kubernetes. |
| Prefix | Fixed start of a name that does not change across deploys. |
| `rex` | Splunk field extraction with a regular expression. |
| `parse` | DQL field extraction with a pattern. |
| `NSPACE` | DQL pattern for characters up to the next space. |
| `ALPHA` | DQL pattern for letters only. |
| Identity field | Field deciding whether a row joins an existing problem. |
