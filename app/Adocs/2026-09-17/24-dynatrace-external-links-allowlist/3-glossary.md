# Glossary

| Term | What it means |
| --- | --- |
| External requests | Dynatrace allowlist of outbound hostnames Workflows may call |
| Allowlist / grant | Adding a hostname so HTTPS outbound is permitted |
| Hostname | DNS name only, e.g. `events.pagerduty.com` |
| Connection | Separate object that stores SNOW URL + credentials |
| fetch | JavaScript HTTP call that still must pass the allowlist |
