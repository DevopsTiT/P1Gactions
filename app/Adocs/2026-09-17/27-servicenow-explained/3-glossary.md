# Glossary

| Term | What it means |
| --- | --- |
| ServiceNow | IT platform for tickets, changes, CMDB, and ops processes |
| Incident (INC) | Ticket that tracks restoring service after something breaks |
| ITSM | Service management processes (Incidents, Changes, …) |
| ITOM | Operations events and infrastructure ops signals |
| sys_id | Internal unique id of a ServiceNow record |
| assignment_group | Team queue that owns the ticket |
| correlation_id | External key so automation can find the same INC later |
| Table API | REST API to create/read/update table rows |
| Connector | Dynatrace app that calls Table API using a Connection |
| Resolve | Mark the INC solved with notes and a resolution code |
