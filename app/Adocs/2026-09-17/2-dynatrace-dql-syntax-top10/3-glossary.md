# Glossary

| Term | What it means |
| --- | --- |
| DQL | Dynatrace Query Language |
| fetch | Choose the data source |
| pipe | The `\|` that chains steps |
| filter | Keep matching records |
| parse | Extract fields from text |
| stats | Aggregate counts/sums by group |
| limit | Maximum rows returned |
| content | Common field holding the raw log line |
| aws.log_group | CloudWatch / Lambda log group attribute |
| Notebooks | Dynatrace place to run and save DQL |
