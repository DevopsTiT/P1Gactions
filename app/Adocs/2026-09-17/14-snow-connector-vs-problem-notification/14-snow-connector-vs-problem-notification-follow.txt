TOTAL DIFF: ServiceNow Connection vs Problem notification

NOTIFICATION (Settings → Problem notifications → servicenowstg)
- Auto push when Problem matches alerting profile
- ITSM toggle = classic INC; ITOM toggle = events
- Message template with {ProblemID} placeholders
- No assignMap / L1-L3 / search / resolve / PD cross-link tasks
- Your pic: ITSM OFF, ITOM ON → events only

CONNECTION (Settings → Connections + Workflow tasks)
- Used only when Workflow runs
- snow-create / search / comment / resolve
- Rich fields: caller, biz service, assignment, P3/P4, runbook, L1-L3
- Parallel PD + sync via correlation_id + dedup_key + comment

NOT THE SAME
Cannot use notification name as workflow connectionId

SAFE COMBO
Notification ITOM ON + ITSM OFF
+ Workflow Connection for INC + PD

UNSAFE
Notification ITSM ON + Workflow Create Incident = duplicate INC
