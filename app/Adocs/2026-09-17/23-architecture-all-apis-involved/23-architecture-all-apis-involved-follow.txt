All APIs in Dynatrace SNOW Connector + PD architecture

REQUIRED
  Dynatrace internal: Davis Problem event + Workflow JS runtime
  SNOW create:  POST https://silvastg.service-now.com/api/now/v2/table/incident
  SNOW search:  GET  https://silvastg.service-now.com/api/now/v2/table/incident?sysparm_query=correlation_id=...
  SNOW comment: PUT  https://silvastg.service-now.com/api/now/v2/table/incident/{sys_id}
  SNOW resolve: PUT  https://silvastg.service-now.com/api/now/v2/table/incident/{sys_id}
  PD trigger:   POST https://events.pagerduty.com/v2/enqueue  (event_action=trigger)
  PD resolve:   POST https://events.pagerduty.com/v2/enqueue  (event_action=resolve)

Auth
  SNOW: Connection basic/OAuth
  PD: routing_key in JSON body

OPTIONAL classic notification (ITOM)
  Separate Dynatrace Problem notification → SNOW em_event path
  Keep ITSM OFF to avoid duplicate INC
