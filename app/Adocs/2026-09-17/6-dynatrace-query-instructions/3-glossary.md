# Glossary

| Term | What it means |
| --- | --- |
| DQL | Dynatrace Query Language |
| fetch | Choose data source |
| filter | Keep matching rows |
| parse | Extract fields from text |
| stats | Aggregate counts/groups |
| limit | Max rows returned |
| Logs app | UI place to search logs with DQL |
| Notebook | Saved document with query cells |
| Time range | Window of data the query looks at |
| Log alert | Scheduled query that can fire an alert |
