# Glossary

| Term | What it means |
| --- | --- |
| Workflow | Dynatrace automation with trigger + tasks |
| Trigger | Event or schedule that starts a run |
| Task | One step (JS, HTTP, ServiceNow, …) |
| Predecessor | Task that must finish first |
| filterQuery | Extra condition on the trigger event |
| Connection | Saved credentials for an integration app |
| schemaVersion | Workflow definition version |
| Allowlist | External hosts Dynatrace may call |
| Dedup key | Shared id so open/close hit the same PD alert |
| Execution | One recorded run of a workflow |
