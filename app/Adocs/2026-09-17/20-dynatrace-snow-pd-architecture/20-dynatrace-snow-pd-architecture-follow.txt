Dynatrace + ServiceNow Connector + PagerDuty architecture (detail)

Goal:
  One Dynatrace Problem → one SNOW INC + one PD page, kept in sync.

Layers:
  Apps → Dynatrace detect → Davis Problem
    → OPEN/CLOSE Workflows (brain)
    → ServiceNow INC (Connector) + PagerDuty (Events API)
    → Optional classic notification ITOM only (ITSM OFF)

OPEN:
  prepare-payload
    → snow-create-incident ‖ PD trigger
    → snow-comment (cross-link)

CLOSE:
  prepare-close-ids
    → snow-search → snow-resolve
    → PD resolve (same dedup_key)

Sync key: dt-problem-<problemId>

Do not confuse:
  Connection (workflow snow tasks)
  vs classic Problem notification servicenowstg (not a workflow task)

Avoid: classic ITSM ON + Connector create = duplicate INC
