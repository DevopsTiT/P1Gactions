# Glossary

| Term | What it means |
| --- | --- |
| snow-create-incident | Workflow task that opens a ServiceNow INC |
| snow-comment-on-incident | Adds work note (PD sync) |
| snow-search-incidents | Finds INC by correlation_id |
| snow-resolve-incident | Resolves the INC on Problem close |
| Connection | Saved SNOW credentials for those tasks |
| Classic ITSM OFF | Avoids duplicate INC with workflow create |
