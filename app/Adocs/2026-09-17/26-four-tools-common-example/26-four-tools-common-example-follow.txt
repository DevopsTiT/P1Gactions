Common example using Dynatrace + ServiceNow + PagerDuty + Splunk

Story: checkout (EIP) fails at night

1) Dynatrace opens Problem P-240917001
2) Workflow creates ServiceNow INC0017788 (EIP-Support)
3) Workflow pages PagerDuty (dedup dt-problem-P-240917001)
4) On-call acks PD → checks Dynatrace Problem scope
5) On-call searches Splunk logs (e.g. index=app_eip status>=500)
6) Fix/rollback → Dynatrace Problem closes
7) Workflow resolves SNOW INC + resolves PD

Roles:
  Dynatrace = detect
  ServiceNow = ticket
  PagerDuty = wake human
  Splunk = log proof
