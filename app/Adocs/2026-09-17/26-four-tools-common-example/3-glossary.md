# Glossary

| Term | What it means |
| --- | --- |
| Detect | Dynatrace finds the symptom and opens a Problem |
| Ticket | ServiceNow INC for process and audit |
| Page | PagerDuty alert that wakes on-call |
| Investigate | Use Dynatrace for scope and Splunk for log evidence |
| Sync key | Shared id (`dt-problem-<id>`) tying INC and PD |
