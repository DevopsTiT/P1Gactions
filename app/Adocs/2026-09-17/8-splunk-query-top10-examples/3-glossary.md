# Glossary

| Term | What it means |
| --- | --- |
| SPL | Splunk Search Processing Language |
| head | Return first N results |
| stats | Aggregate counts/groups |
| timechart | Count values over time |
| top | Most common field values |
| rex | Regex extract into fields |
| where | Filter rows after stats/eval |
| _time | Event timestamp |
| _raw | Original event text |
