# Glossary

| Term | What it means |
| --- | --- |
| SPL | Search Processing Language (Splunk queries) |
| Index | Named store of events |
| Sourcetype | Data format/family |
| Event | One indexed record / log line |
| Field | Extracted key such as host or status |
| Pipe `\|` | Pass results to the next command |
| Time picker | UI control for search time window |
| Report | Saved search |
| Alert | Saved search that notifies on condition |
| rex | Extract fields with regex in the search |
| stats | Aggregate counts and groups |
| _time / _raw | Event time and original text |
