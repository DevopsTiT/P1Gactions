# Glossary

| Term | What it means |
| --- | --- |
| Deploy monitoring | Install agents and verify data + tags |
| Triage | Read a Problem and decide next action quickly |
| Automate ticket + page | Workflows that create/resolve SNOW INC and PD alerts |
| Investigate | Use PD, Dynatrace, Splunk, and SNOW each for the right question |
| Execution | One run of a Workflow you can debug in the UI |
