Dynatrace §5 SRE jobs — detailed

A) Deploy monitoring
  Install OneAgent/Operator → verify host/service → tag app/env/team
  Need app:EIP for assignMap

B) Detect and triage
  Problems → card → entities → metrics/traces/logs → decide

C) Automate ticket + page
  Connection + allowlist + OPEN/CLOSE workflows
  Map Connection, PD key, ITSM OFF, test Executions
  Expect: one INC + one PD; close resolves both

D) Investigate with other tools
  PD ack → SNOW INC → DT Problem → Splunk proof → notes → fix
  DT=what broke, PD=who woke, SNOW=ticket, Splunk=log line
