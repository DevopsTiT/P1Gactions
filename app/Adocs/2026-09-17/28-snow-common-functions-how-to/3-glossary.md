# Glossary

| Term | What it means |
| --- | --- |
| Create Incident | Open a new INC record |
| Assign | Set assignment group / assignee |
| Work note | Internal timeline comment on the INC |
| Search | Find INC by filters or correlation_id |
| Resolve | Mark INC fixed with resolution code and notes |
| snow-* actions | Dynatrace Connector functions that perform those INC operations |
