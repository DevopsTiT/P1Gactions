# Glossary

| Term | What it means |
| --- | --- |
| Classic Problem notification | Settings integration that pushes Problems to SNOW |
| Workflow Connection | Separate credential for Workflow SNOW actions |
| ITSM | ServiceNow Incident tickets |
| ITOM | ServiceNow Event Management events |
| OnPremise URL / url | Full SNOW URL field (vs instanceName) |
| PD-only workflow | Automations that call PagerDuty only |
