# Glossary

| Term | What it means |
| --- | --- |
| DQL | Dynatrace Query Language for logs/metrics |
| parse | Extract fields like action from log text |
| fields | Keep only listed columns in the result |
| stats | Aggregate counts (old pic 2 style) |
| NUMBER_OF_RESULTS | Trigger when the query returns any/enough rows |
| cmxDocumentId | Document id parsed from the log line |
