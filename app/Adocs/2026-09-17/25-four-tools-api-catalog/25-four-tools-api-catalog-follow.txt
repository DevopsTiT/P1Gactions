All APIs — Dynatrace / ServiceNow / PagerDuty / Splunk (SRE catalog)

YOUR PACK USES
  Dynatrace: Workflows + Davis Problem events (internal)
  ServiceNow: POST/GET/PUT /api/now/v2/table/incident
  PagerDuty: POST https://events.pagerduty.com/v2/enqueue
  Splunk: not called by current YAML

DYNATRACE (main)
  Base: https://{env}.live.dynatrace.com
  GET  /api/v2/problems
  GET  /api/v2/problems/{id}
  GET  /api/v2/events
  POST /api/v2/events/ingest
  GET  /api/v2/metrics/query
  POST /api/v2/metrics/ingest
  GET  /api/v2/entities
  GET/POST /api/v2/logs/...
  /api/config/v1/... (classic config)
  Auth: Api-Token

SERVICENOW (main)
  Base: https://{instance}.service-now.com
  POST/GET/PUT/PATCH /api/now/v2/table/{table}
  Common tables: incident, sys_user_group, sys_choice, em_event
  Also: attachment, import set, scripted REST
  Auth: basic or OAuth

PAGERDUTY (main)
  Events: POST https://events.pagerduty.com/v2/enqueue
    (trigger | acknowledge | resolve) + routing_key + dedup_key
  REST:  https://api.pagerduty.com/incidents|services|oncalls|...
  Auth Events: routing_key in body
  Auth REST: Token token=<API_TOKEN>

SPLUNK (main)
  REST: https://{host}:8089/services/...
    /services/auth/login
    /services/search/jobs
    /services/search/jobs/{sid}/results
    /services/saved/searches
  HEC:  POST .../services/collector (ingest)
  Auth: session/token; HEC uses Splunk <token>
