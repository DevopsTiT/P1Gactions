# Glossary

| Term | What it means |
| --- | --- |
| Placeholder | String like `__PD_ROUTING_KEY__` you replace before activate |
| sys_id | ServiceNow internal 32-char id for a record (user, group, service) |
| routing_key | PagerDuty Events API integration key for a service |
| correlationId | Value written on INC so close can find it (here Problem id) |
| dedup_key | PagerDuty key that ties trigger and resolve |
| assignMap | Table in prepare-payload mapping app tag → group/biz/L1-L3/runbook |
| Fake data | Example-only values for learning; not production credentials |
