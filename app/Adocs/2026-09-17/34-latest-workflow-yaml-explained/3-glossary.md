# Glossary

| Term | What it means |
| --- | --- |
| Workflow YAML | File that defines trigger + tasks for Dynatrace Workflows |
| predecessor | Task that must finish before another starts |
| parallel tasks | Same predecessor; run side by side |
| Jinja `result()` | Template to pull prior task output into inputs |
| connectionId empty | Placeholder; bind Connection in Dynatrace UI |
| assignMap | JS table mapping app tag to SNOW group/biz/runbook |
| else SKIP | Close resolve skipped when search finds no INC |
