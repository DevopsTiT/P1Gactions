BIG PICTURE
Workflow = when (trigger) → do (tasks) → record (Executions)
Draft ≠ live. Activate = live. Deactivate = pause.

SETUP (A0–A8)
A0 Prep: permissions, External requests allowlist, Connections, secrets
A1 Open Workflows app
A2 Create blank OR Upload YAML
A3 Trigger: Problem open/close OR schedule; categories/tags/filterQuery
A4 Tasks: add action, name stably, fill input
A5 Wire: predecessors, OK conditions, parallel, join
A6 Secrets: Connection dropdown; replace __PD_ROUTING_KEY__
A7 Save Draft → Activate
A8 Test via Executions + PD/SNOW side effects

EACH FUNCTION
List: Create, Upload, Activate, Deactivate, Share, Delete
Trigger: event/schedule/filter/categories/tags
Actions: JS, HTTP, SNOW create/search/resolve/comment, email/slack
Task panel: name, active, predecessors, conditions, input, timeout, retry
Expressions: {{ result("prepare-payload").problemId }}
Connections ≠ classic Problem notifications silvastg
Executions: open first failed task for real error

MANAGE
Edit → Save → Activate → test
Deactivate to pause; Delete only when retired
Open+close pair with same dedup/correlation keys
Troubleshoot: no run vs failed task vs wrong business result

PD RECIPE
Allowlist events.pagerduty.com
Upload open+close YAML → set routing key → Activate → test Problem
