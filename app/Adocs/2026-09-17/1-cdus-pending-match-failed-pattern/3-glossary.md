# Glossary

| Term | What it means |
| --- | --- |
| DQL | Dynatrace Query Language for logs/metrics |
| stats | Aggregate counts (or other calcs) per group |
| cmxDocumentId | Document id parsed from log content |
| Pending | Started upload with no complete and no fail yet |
| dynatrace_log_alert | Terraform resource for a scheduled log alert |
| LAST_15_MINUTES | Each run looks at the last 15 minutes of logs |
| cron */5 | Run every 5 minutes |
