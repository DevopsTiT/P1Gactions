# Glossary

| Term | What it means |
| --- | --- |
| OneAgent | Software installed on hosts/nodes to collect deep telemetry |
| ActiveGate | Proxy/gateway for agent or cloud traffic to Dynatrace |
| Smartscape | Topology map of how entities connect |
| Grail | Modern Dynatrace data platform queried with DQL |
| Davis | AI that detects and groups issues into Problems |
| Problem | Dynatrace incident object (open/closed) |
| Workflow | Automation run on triggers (Problem open/close, schedule, …) |
| Connection | Stored external credentials (e.g. ServiceNow) |
| External requests | Allowlist of outbound hosts Workflows may call |
| Management zone | Visibility/access slice of the environment |
