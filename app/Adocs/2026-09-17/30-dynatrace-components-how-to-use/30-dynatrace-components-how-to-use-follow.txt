Dynatrace — components and how to use

What it is:
  Observability platform: collect signals → Davis Problem → automate response

Layers:
  Collect: OneAgent, code modules, Operator, Extensions, Synthetic, OTel/API
  Transport: ActiveGate (when needed)
  Platform: Smartscape, metrics, traces, logs/Grail, RUM
  Intelligence: Davis → Problems / events
  Act: Workflows, Apps, Connections, notifications, Environment API

How to use (SRE):
  1) Install OneAgent/Operator; tag app:EIP
  2) Watch Problems for outages
  3) Investigate via Problem card → traces/logs/metrics/DQL
  4) Automate with Workflows (your SNOW Connector + PD fetch)
  5) Allowlist silvastg.service-now.com + events.pagerduty.com
  6) Classic ITSM OFF if Connector creates INC

Your pack uses:
  Davis Problem → Workflow OPEN/CLOSE
  → snow-* + PagerDuty /v2/enqueue
