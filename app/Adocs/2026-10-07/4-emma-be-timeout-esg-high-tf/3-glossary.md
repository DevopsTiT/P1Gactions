# Glossary

| Term | What it means |
|---|---|
| Emma BE | The OpenPaaS backend (myaxa backend) |
| ESG | Enterprise service gateway in CoreIT |
| Biz-calendar API | Business calendar service the backend calls through ESG |
| Read timed out | The call waited too long for ESG to answer |
| Duplicate alert | Two alerts with the same logic; migrating both would page twice |
