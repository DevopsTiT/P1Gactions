# Glossary

| Term | What it means |
|---|---|
| PowerCenter | Informatica's ETL (data integration) product |
| Informatica domain | The group of PowerCenter nodes managed together |
| Master gateway node | The node that runs the domain; others take over if it fails |
| ISP_MASTER_ELECT_LOCK | Log message about the lock used to elect a new master node |
| for_each | Terraform loop that creates one resource per map entry |
| Overlapping alerts | Alerts where one always fires when another fires |
