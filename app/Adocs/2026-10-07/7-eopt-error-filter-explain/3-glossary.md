# Glossary

| Term | What it means |
|---|---|
| Anchor (^) | Regex symbol meaning "start of the line" |
| [A-Z]+ | One or more capital letters |
| caseSensitive:false | DQL option that ignores upper and lower case |
| False alert | An alert raised for a line that isn't a real error |
| loglevel | Dynatrace field holding the parsed log level |
