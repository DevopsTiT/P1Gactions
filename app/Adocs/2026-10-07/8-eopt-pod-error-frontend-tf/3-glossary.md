# Glossary

| Term | What it means |
|---|---|
| spath | Splunk command that parses JSON or XML events into fields |
| parse JSON | DQL `parse content, "JSON:j"` turns a JSON line into a record named j |
| j[level] | Reads the level field from that record |
| upper() | Turns text into capitals so the match ignores case |
| Frontend | The web or UI part of eopt, which writes JSON logs |
