# Glossary

| Term | What it means |
|---|---|
| PIS | The claims batch system (pisp2) writing this log |
| ESG120 | Error code the batch logs when its call to OpenPaaS through ESG fails |
| Splunk regex | Command that keeps only events matching a regular expression |
| \s | Regex token for one whitespace character |
| Records detector | Dynatrace detector that alerts on every row its query returns |
| alertIdentityFields | Fields that decide which rows belong to the same open problem |
