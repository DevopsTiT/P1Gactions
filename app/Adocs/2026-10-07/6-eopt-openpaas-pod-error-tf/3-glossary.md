# Glossary

| Term | What it means |
|---|---|
| rex | Splunk command that extracts fields with a regular expression |
| eval upper() | Splunk function that turns text into capital letters |
| ISO timestamp | Date and time like 2026-10-06T00:30:06.693Z; the Z means UTC |
| loglevel | Dynatrace field for the log level when it is already parsed |
| Pod | A running copy of an application in Kubernetes (OpenPaaS) |
| Records detector | Dynatrace detector that alerts on every row its query returns |
