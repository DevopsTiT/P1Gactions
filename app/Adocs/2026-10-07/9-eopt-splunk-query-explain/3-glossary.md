# Glossary

| Term | What it means |
|---|---|
| index | Splunk storage bucket; the search only looks inside it |
| spath | Splunk command that turns JSON keys into fields |
| rex | Splunk command that extracts fields with a regular expression |
| eval | Splunk command that creates or changes a field |
| upper() | Function that turns text into capital letters |
| search (after a pipe) | Filters the results by a field value |
| Pipe (\|) | Passes the results of one command into the next |
