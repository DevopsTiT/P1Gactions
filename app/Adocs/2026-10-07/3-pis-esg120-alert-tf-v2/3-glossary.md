# Glossary

| Term | What it means |
|---|---|
| ESG120 | ESG error code meaning the request could not be routed (Routing failed) |
| Multi-line event | One log entry spread over several lines, such as an HTTP response with a JSON body |
| Pretty-printed JSON | JSON written with line breaks and indentation, one key per line |
| log.source | Dynatrace field holding the log file path |
| Records detector | Dynatrace detector that alerts on every row its query returns |
