# Glossary

| Term | What it means |
|---|---|
| table _time _raw | Splunk command that shows only the time and the raw log text |
| Time range Today | From 00:00 today until the search runs |
| UDM | The downstream data platform that receives the LINE log file |
| Report-style alert | An alert that emails results on a schedule, not only when something breaks |
| Missing-success alert | Alert that fires when an expected success line does not appear |
