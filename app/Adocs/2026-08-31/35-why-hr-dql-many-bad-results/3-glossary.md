# Glossary

| Term | What it means |
| --- | --- |
| False positive | Row matched a keyword but is not useful PII evidence |
| EMPLID | PeopleSoft employee ID — appears in many non-PII ops logs |
| Value = | Pattern that usually means a field value was dumped into the log |
| Short token | Very short search word (dob, mail) that matches too often |
