# Glossary

| Term | What it means |
| --- | --- |
| PII | Personal data that can identify a person (name, address, phone, etc.) |
| Keyword pack | A list of field-name strings searched with contains() |
| False positive | Match on a word that is not real customer PII (e.g. config docs) |
| Category pack | Smaller list for one PII type to reduce noise |
