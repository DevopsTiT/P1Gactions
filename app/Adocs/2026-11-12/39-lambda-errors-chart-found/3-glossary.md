# Glossary

| Term | What it means |
|---|---|
| Spike | A time when the error metric stored a number above the flat line. |
| Flat line | The recent part of the chart. No new errors were stored. |
| Picker | The notebook time range. It only controls the preview. |
| Alert window | The short range the detector judges. It is separate from the picker. |
| Above 0 | The condition that opens a problem when a new error point arrives. |
