# Glossary

| Term | What it means |
|---|---|
| Preview | A look at the query result. It does not send a message. |
| Problem | The item Dynatrace opens when an alert condition is met. |
| Problem notification | The integration that sends that problem to email, a webhook, or PagerDuty. |
| Alerting profile | The filter that decides which problems are allowed to notify. |
| Send test notification | The button that sends a sample message through the integration. |
