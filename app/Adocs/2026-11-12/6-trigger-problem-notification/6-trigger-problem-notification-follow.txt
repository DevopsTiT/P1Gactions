The preview found the CloudWatch test logs. A preview does not send a problem notification.

1. Press Save on the custom alert.
2. Open Problems.
3. If there is no problem, the query is not returning the bad rows, or the timeseries count is not above 0.
4. If a problem is already open, close it. A new matching line updates the open problem and does not send a second notification.
5. Open Settings, Integration, Problem notifications.
6. Open the email, webhook, or PagerDuty integration.
7. Turn it on, and check that its alerting profile includes this problem's severity.
8. Select Send test notification.

The Splunk link answers the request for a link. The notification link is the URL of the row in Problems.
