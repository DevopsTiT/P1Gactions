# Glossary

| Term | What it means |
|---|---|
| CloudWatch alarm | An AWS rule. It notifies an SNS topic. |
| Dynatrace problem | An item Davis opens in the Problems list. |
| Metric poll | Dynatrace reading CloudWatch metric numbers on a schedule. |
| Metric event | A Dynatrace rule that turns one of those numbers into an event. |
| Log line | Text stored from the Lambda. It can be searched. It is not a problem. |
