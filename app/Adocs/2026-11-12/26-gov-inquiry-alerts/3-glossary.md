# Glossary

| Term | What it means |
|---|---|
| Biz file summary | The log line that says a file was summarized. |
| fileCategory | The kind of file, such as MDM_SEARCH_RESULT_FILE. |
| rex and rename | Splunk names for the email table. They do not change the trigger. |
| ALJ_GOV | The shared title prefix for these seven alerts. |
| level:ERROR | The text in the general-error log. |
