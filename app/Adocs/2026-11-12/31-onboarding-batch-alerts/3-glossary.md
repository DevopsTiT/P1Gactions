# Glossary

| Term | What it means |
|---|---|
| :: error | The text in the batch log that marks an error line. |
| ALJ_ONBOARD | The prefix for the four emailed alerts. |
| ALJ_MOBILE | The prefix for the Splunk Mobile alert. It does not match ALJ_ONBOARD. |
| Select | The role box is empty. No person was chosen. |
