# Glossary

| Term | What it means |
|---|---|
| rex | Splunk reads one word from the message and names it loglevel. |
| innorules* | Any Splunk index whose name starts with innorules. |
| ALJ_BRE | The title prefix for this detector and profile. |
| pagerduty.enabled = 1 | The event asks for PagerDuty. The routing key is not in this file. |
