# Glossary

| Term | What it means |
|---|---|
| Log line | Text Dynatrace stored. The Notebook can list it. |
| INFO | A normal severity. INIT_START is this severity. |
| INIT_START | The line Lambda writes when a new runtime starts. |
| Problem | An item Davis opens after a saved alert condition is met. |
| Threshold | The number the count must pass. Here it is above 0 ERROR lines in a minute. |
