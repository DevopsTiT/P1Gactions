# Glossary

| Term | What it means |
|---|---|
| message="*Error*" | Any message that contains Error. |
| Throttle 60 minutes | Splunk will not fire this alert again for 60 minutes. |
| ALJ_CMX | The title prefix for this detector, profile, and email. |
| index | The Splunk index name. It stays in the query so Error does not match every system. |
