# Glossary

| Term | What it means |
|---|---|
| Variable | A name in braces. Davis replaces it with a value from the query row. |
| by | The clause that puts dt.entity.host on the row. |
| dt.source_entity | The problem field that receives {dt.entity.host}. |
| Below 101 | The condition that opens the problem. This host is already under it. |
