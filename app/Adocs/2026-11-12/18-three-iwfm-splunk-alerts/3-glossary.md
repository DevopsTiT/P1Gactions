# Glossary

| Term | What it means |
|---|---|
| Greater than 2 | Three or more matching lines. |
| Greater than 15 | Sixteen or more matching lines. |
| Greater than 0 | Any matching line. |
| transaction | Splunk groups lines before it counts them. |
| Throttle 1 hour | Splunk will not fire this alert again for 1 hour. |
| ALJ_EIP | Prefix for the EIP006 alert only. |
| ALJ_COMPASS | Prefix for the Compass exception alert only. |
| ALJ_IWFM | Prefix for the iWFM Caution and Fatal alert only. |
