# Glossary

| Term | What it means |
|---|---|
| Custom alert | A threshold you create by hand in Settings. |
| Timeseries | One number per time bucket. The alert form requires this shape. |
| makeTimeseries | Turns matching log lines into that one-number-per-minute series. |
| Static threshold | A fixed number. Here the number is 0. |
| loglevel | The severity column. ERROR is the row this alert counts. |
| aws.log.group | The AWS log group name stored on the log line. |
