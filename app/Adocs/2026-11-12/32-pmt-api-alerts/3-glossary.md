# Glossary

| Term | What it means |
|---|---|
| pmt-api | The Splunk index on every search in this batch. |
| ALJ_SFDC | Title prefix for the Salesforce API error. |
| ALJ_PMT | Title prefix for the process-automation mailbox. |
| ALJ_STP | Title prefix for the alerts that also mail Koichi Nagamine. |
| ALJ_MAILSENDER | Title prefix for the Emma-named alert whose To box was collapsed. |
| +Used: | The text in the memory log. The number after it is compared with 480. |
| Throttle 60 seconds | Splunk waits 60 seconds before it can fire that saved search again. |
| Triggered Alerts | A Splunk list of alerts. It is not a PagerDuty page. |
