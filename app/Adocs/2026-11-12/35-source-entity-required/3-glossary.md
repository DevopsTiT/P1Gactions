# Glossary

| Term | What it means |
|---|---|
| dt.source_entity | The Dynatrace object the problem is attached to, such as a host or a service. |
| Custom device | An entity you define yourself when the thing is not a host or a service Dynatrace already knows. |
| Placeholder | A value in braces, such as {dt.entity.custom_device}. Davis fills it from the query result. |
| CUSTOM_ALERT | The event type that lets an alerting profile turn the event into a problem and send mail. |
| Smartscape | Dynatrace's map of entities. dt.smartscape_source.id is the id of one object on that map. |
