# Glossary

| Term | What it means |
|---|---|
| Edit alert | The form. It stores the detector. It does not list the opened problem. |
| Status | The column on All alerts. It says whether Davis is running this detector. |
| Inactive | Saved, and the switch is off. |
| Error | The scheduled query failed. |
| Success | The scheduled query ran. The problem, if opened, is on the Problems page. |
| `{dt.smartscape_source.id}` | A column this query does not have. Remove that property row. |
