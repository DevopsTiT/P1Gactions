# Glossary

| Term | What it means |
|---|---|
| Problem | The item in the Problems list. A preview does not create one. |
| Timeseries | A count per minute. The threshold compares that count. |
| makeTimeseries | The command that builds the count. Without it, a Timeseries alert has no number. |
| Records | Individual log lines. The condition section still has to be complete. |
| Last run | The result of the alert's most recent check, shown on the saved alert. |
