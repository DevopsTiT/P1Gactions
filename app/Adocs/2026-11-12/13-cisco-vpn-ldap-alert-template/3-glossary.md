# Glossary

| Term | What it means |
|---|---|
| Greater than 3 | The query returns a row only after the count passes 3. |
| Once | One problem for the whole count, not one problem per log line. |
| alert_key | The stable identity for that one problem. |
| ALJ_VPN | The title prefix for this profile. It is separate from ALJ_OCP4. |
| pagerduty.enabled = 1 | The event asks for PagerDuty. The happy-future detector used 0. |
