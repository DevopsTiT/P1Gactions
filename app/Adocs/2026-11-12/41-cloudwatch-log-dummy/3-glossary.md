# Glossary

| Term | What it means |
|---|---|
| aws.log_group | The CloudWatch log group field that matched the error metric. |
| Anchor host | A real host id used so the problem has an entity. The log did not come from that host. |
| TESTDUMMY | A title that does not start with ALJ_. |
| alert_key | The stable id that keeps one open problem while logs are still in the window. |
