# Glossary

| Term | What it means |
|---|---|
| 0 records | The query finished and no series matched. |
| Metric point | One stored number. No points means the chart stays empty. |
| Last 2 hours | The time picker window on this run. |
| log.lambda_errors | The metric name in the query. Empty means this name has no stored numbers in the window. |
| fetch logs | A query that reads log lines. It can return rows when the metric is empty. |
