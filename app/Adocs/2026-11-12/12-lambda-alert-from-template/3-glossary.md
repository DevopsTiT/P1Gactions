# Glossary

| Term | What it means |
|---|---|
| Record analyzer | Opens an event when the query returns a row. |
| CUSTOM_ALERT | The event type that becomes a problem. |
| alertIdentityFields | One open problem per value. Here the value is the log group. |
| Alerting profile | The filter that decides which problems may send mail. |
| pagerduty.enabled = 0 | The detector does not turn on the PagerDuty flag. |
