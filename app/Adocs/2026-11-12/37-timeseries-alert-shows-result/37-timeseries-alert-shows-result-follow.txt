The chart is blank because isNotNull(dt.entity.custom_device) drops every point. Lambda log metrics do not have a custom device.

Paste this first:

timeseries errors = sum(log.lambda_errors),
  filter: {aws.log.group == "/aws/lambda/gov-inquiry-system-dev-logFailure"},
  by: {aws.log.group}

If that is empty, try aws.log_group instead of aws.log.group.
If the logs are prod, change dev in the path to prod.
If Dynatrace says the metric does not exist, log.lambda_errors is the wrong name.

A log error metric often has no points when there are no errors. The chart stays blank until an error arrives.

After a line shows, leave the entity filter out of the query.
Set dt.source_entity to the real CUSTOM_DEVICE id in Add details. No braces.
Keep event.type as CUSTOM_ALERT.

Add dt.smartscape_source.id only if the chart still has a line after you add it.
