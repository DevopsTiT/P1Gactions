# Glossary

| Term | What it means |
|---|---|
| timeseries | A query that turns a metric into a line on a chart. |
| log.lambda_errors | The metric name in this alert. It has to exist in this environment. |
| aws.log.group | The log group field used on the earlier Lambda log queries. The name has a dot. |
| aws.log_group | The log group name on this screen. The name has an underscore. |
| isNotNull | Keeps a point only when the field has a value. |
| dt.smartscape_source.id | An entity id Dynatrace can use to connect the event. It is empty when the metric has no entity. |
