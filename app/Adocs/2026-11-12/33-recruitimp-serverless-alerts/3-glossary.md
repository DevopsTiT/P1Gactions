# Glossary

| Term | What it means |
|---|---|
| recruitimp-serverless | The Splunk index on both searches. |
| loglevel | The word the first search reads after a tab. |
| level: | The label the second search reads. The value after it is uppercased. |
| ALJ_ETOOL | The prefix whose profile mails the E-Tool maintenance mailbox only. |
| ALJ_EOPT | The prefix whose profile also mails chungyueh.chiu@axa.co.jp. |
| rex | A Splunk command that pulls a named piece out of a line. |
