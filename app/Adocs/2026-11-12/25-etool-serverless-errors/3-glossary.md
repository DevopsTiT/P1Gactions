# Glossary

| Term | What it means |
|---|---|
| rex | Splunk reads one word out of the message and names it level. |
| level="ERROR" | That extracted word is ERROR. |
| ALJ_ETOOL | Prefix for the 5-minute alert. |
| ALJ_EOPT | Prefix for the daily alert. |
| index | The Splunk index. It stays in the query so ERROR stays in eopt-serverless. |
