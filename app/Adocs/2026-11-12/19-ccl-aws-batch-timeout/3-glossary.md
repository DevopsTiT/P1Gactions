# Glossary

| Term | What it means |
|---|---|
| Task timed out | The batch line this alert is looking for. |
| 10DEBUG: | The visible start of the line Splunk excludes. The rest is cut off. |
| Greater than 0 | Any remaining matching line fires the alert. |
| ALJ_CCL | The title prefix for this detector, profile, and email. |
| pagerduty.enabled = 1 | The event asks for PagerDuty. The routing key is not in this file. |
