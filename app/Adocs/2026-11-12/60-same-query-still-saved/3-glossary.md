# Glossary

| Term | What it means |
|---|---|
| Discard | Closes the form and keeps the old query off this save. |
| 0 records | The metric has no points in the alert window, so the condition stays false. |
| New alert | A second detector. The old CloudWatch one stays as it is. |
| Problems | The Dynatrace page where a fired detector shows up. This test has no email. |
| `{dt.entity.host}` | Copies the host from the query row onto the problem. Keep the braces. |
