# Glossary

| Term | What it means |
|---|---|
| dt.source_entity | The id of the object the problem is attached to. |
| Custom device | An object you create so a log alert has a place to show. It is not a real server. |
| CUSTOM_DEVICE- | The start of a custom device id. |
| Placeholder | A value in braces. Davis copies a query field into it. |
| Affected entities | The section on the problem page that lists the attached object. |
| CUSTOM_ALERT | The event type that opens a problem. |
