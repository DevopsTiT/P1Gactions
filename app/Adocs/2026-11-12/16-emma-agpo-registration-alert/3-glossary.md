# Glossary

| Term | What it means |
|---|---|
| Greater than 1 | Two or more matching lines. One line does not fire. |
| Once | One problem for the count, not one problem per line. |
| ALJ_EMMA | The title prefix for this detector, profile, and email. |
| {errorCode} | The braces in the Splunk phrase. The query matches the exception name so a real code still counts. |
