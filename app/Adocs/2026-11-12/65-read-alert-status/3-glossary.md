# Glossary

| Term | What it means |
|---|---|
| Status | The column on All alerts that reports the last runs. |
| Inactive | The detector is saved and the switch is off. |
| Pending | A run has not finished yet. |
| Error | The query failed. Davis then waits longer before it tries again. |
| Success | The query ran. The next place to look is Problems, with filters cleared. |
| `interval:1m` | One-minute buckets. Davis needs this on the saved query. |
