Timeseries is a count per minute. The alert fires when that count crosses a threshold.
Records is individual log lines. The alert fires when a matching line is in the result.

For the e-signature failure, choose Timeseries.

fetch logs
| filter contains(aws.log.group, "/aws/lambda/light-digital-api-dev-confirm-e-signature", caseSensitive:false)
| filter loglevel == "ERROR"
| makeTimeseries error_count = count(), interval:1m

Static threshold. Alert if the metric is above 0.
A minute with no ERROR line stays quiet.
Several Failed to handle lines in one minute stay inside one problem.

Choose Records only when the query returns just the bad lines.

fetch logs
| filter contains(aws.log.group, "/aws/lambda/light-digital-api-dev-confirm-e-signature", caseSensitive:false)
| filter loglevel == "ERROR"

Keep the identity field aws.log.group.
One problem stays open for that function while an ERROR line is inside the last 2 hours.
The same log group updates that problem. It does not open a second one.

The draft on the screen is Records with no ERROR filter. START and END lines match. Saving it keeps a problem open while the function writes normal logs.
