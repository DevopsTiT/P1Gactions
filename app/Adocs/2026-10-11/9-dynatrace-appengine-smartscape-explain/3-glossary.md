# AppEngine Usage And Smartscape Nodes Glossary

| Term | What it means | Why you care |
|---|---|---|
| AppEngine | Platform for apps and code inside Dynatrace. | Function runs can be billed. |
| Invocation | One run of a function. | Billing unit. |
| Ad hoc function | Code run directly from a notebook or workflow. | One function type. |
| Custom action | Reusable workflow step from an app. | One function type. |
| App function | Backend code of a Dynatrace app. | One function type. |
| scanLimitGBytes | Maximum data a query may read; -1 is no limit. | Cost and speed. |
| takeAny | Picks any one value in a group. | Used to keep one value per record. |
| alias | Names a grouping column. | Gives User and Calling_App. |
| Smartscape | Live map of monitored things and their links. | Read with smartscapeNodes. |
| Node | One thing on the map. | Counted by type. |
| ActiveGate | Dynatrace relay and remote-check server. | Not a node type here. |
| FRONTEND | A Real User Monitoring app, web or mobile. | 14 in this tenant. |
