# Glossary

| Word | What it means |
|---|---|
| Data flow | Which facts move from one system to the next. |
| Red dot | The slide’s mark for personal information. On this use case it means an employee name or a Teams identity. |
| Assignee display name | The on-call person’s name shown on the PagerDuty incident. |
| Teams identity | The work account of the person who types the question. |
| Prompt | The text the assist reads. The paging phone number is not part of it. |
| Runbook | The procedure linked on the PagerDuty service. |
| Scribe | The agent that listens to the bridge and writes a text note. |
| Insights | The agent that answers one question from past incidents. Only if enabled. |
| Shift | The schedule agent. Its data is not on this picture. |
