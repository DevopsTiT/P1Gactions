# Glossary

| Term | What it means | Why you care on this slide |
|---|---|---|
| Acceptance criteria | The checks that must pass before the tool is accepted. | This is the whole of section 8. |
| Test service | A PagerDuty service that alerts only the pilot. | The five checks run here. |
| Linked user | A PagerDuty user mapped to a Microsoft Teams identity. | Check 1. The assist needs that link. |
| Usable reply | The incident id and the open or acknowledged state match PagerDuty. | Check 3. A reviewer decides. |
| Status draft | Text the assist prepares for stakeholders. | Check 4. A person still sends it. |
| Escalation policy | Who gets the next call if the first person does not acknowledge. | Check 5. It keeps running when the assist is down. |
