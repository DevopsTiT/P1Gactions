# Glossary

| Term | What it means | Why you care on this slide |
|---|---|---|
| Input | The data the AI is given for one question. | This whole slide. |
| Incident fields | Id, title, priority, status, service, times, and assignee name. | The core record from PagerDuty. |
| Prompt | The question a person types in Microsoft Teams. | One of the format ticks. |
| Body of knowledge | The runbook or service notes already stored for that service. | Used when a runbook is linked. |
| Scribe | The agent that writes a note from a bridge. | This is why Sound is ticked. |
| Data owner | The team that must agree before its data goes to the AI. | Technology DevOps for the main path. |
| 0570113E | The personal-information manual named on the form. | Check the ticks against it before the meeting. |
| Display name | The work name shown on the incident or in Teams. | Why the name box is ticked. |
| My Number | The Japanese national identifier. | Not an input. Do not paste it. |
