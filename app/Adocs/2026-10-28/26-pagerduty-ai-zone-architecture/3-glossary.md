# Glossary

| Word | What it means |
|---|---|
| Zone | A box that groups systems with the same job. |
| Signal source | A detector that already raises the critical event. |
| PagerDuty cloud | The SaaS account. Incident, paging, and the assistant live here. |
| Entra ID | The company sign-in. It is the identity provider. It is not a PagerDuty component. |
| SAML 2.0 | The sign-in method from Entra ID into PagerDuty. MFA happens at Entra ID. |
| Primary | The on-call employee. The red dot marks this person. |
| causes | The root-cause draft. Primary replaces it with confirmed evidence before the PIR is published. |
| Service region | The PagerDuty region for the account. Confirm it with the account owner. |
