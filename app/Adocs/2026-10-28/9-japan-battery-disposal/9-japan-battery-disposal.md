# Japan Battery Disposal

```
电池要丢哪里？
  普通干电池（5号、7号碱性、锰）
    → 看居住地的垃圾日历
    → 多数是「有害ごみ」或单独的「乾電池」日
  充电电池、充电宝、可拆的锂电池
    → 不要进可燃垃圾
    → 金属端子贴胶带
    → 家电店的 JBRC 回收箱，或自治体指定的有害垃圾
  纽扣电池
    → 店头「ボタン電池」回收箱
    → 端子贴胶带
  汽车电瓶
    → 买新电瓶的店或汽修店
  电池取不下来
    → 不要自己拆
    → 按小型家电或店铺回收
```

| 要点 | 说明 |
|---|---|
| 谁说了算 | 你住的市区町村。同一个东京都里，各区规则也可以不同。 |
| 最危险的一种 | 锂电池和充电宝。放进可燃垃圾有起火的可能。 |
| 丢之前 | 用胶带贴住金属端子，避免短路。 |
| 查法 | 搜「你的区名 + 乾電池 + 分別」，或用 5374 这类垃圾分类查询。 |

## Summary

普通干电池跟居住地的有害垃圾或干电池收集日走。充电电池、充电宝和纽扣电池不要混进可燃垃圾，贴好端子后交给店头回收箱或自治体指定的收集。汽车电瓶退回卖店。

## Investigation

| 来源 | 看到的规则 |
|---|---|
| 自治体垃圾日历 | 家庭垃圾按区市町村分别。干电池常见分类是有害垃圾或单独的干电池。 |
| JBRC 回收箱 | 收小型充电电池：镍镉、镍氢、锂离子，以及小型密封铅酸电池。家电量贩店、部分超市和公共设施有箱子。 |
| 纽扣电池回收箱 | 钟表店、相机店、家电店常见「ボタン電池」箱子。和 JBRC 的充电电池箱不是同一个。 |
| 汽车电瓶 | 不属于家庭可燃垃圾，也不要塞进小型充电电池箱。由销售店回收。 |
| 这次没有查到的 | 没有指定区市町村，所以下面不写某一区的收集星期。 |

## Result

按电池种类处理。

| 电池 | 丢到哪里 | 丢之前 |
|---|---|---|
| 碱性、锰干电池（5号、7号等） | 居住地日历上的「乾電池」或「有害ごみ」。 | 有的区要求装进透明袋。锂一次电池还要贴端子。 |
| 充电电池（镍镉、镍氢、小型锂离子） | 家电店的 JBRC 箱，或日历写明的收集。 | 端子贴胶带。一颗一颗分开。 |
| 充电宝、手机里可取出的锂电池 | 同上。鼓包、破损的不要扔进普通袋。 | 贴住端子。交给店或自治体的危险物收集。 |
| 纽扣电池 | 「ボタン電池」回收箱。 | 贴住正负极。 |
| 汽车电瓶 | 换新电瓶的店、汽修店。 | 不要放在生活垃圾点。 |
| 电池焊死在电器里 | 不要撬开。 | 按小型家电回收，或问卖场。 |

查你所在地时用这句：

`住的区市町村名 乾電池 分別`

收集日以那个页面为准。

## Data flow map

```
电池在手里
    |
    +-- 干电池 → 垃圾日历 → 有害ごみ / 乾電池日
    |
    +-- 充电电池、充电宝 → 贴胶带 → JBRC 箱或有害ごみ
    |
    +-- 纽扣电池 → 贴胶带 → ボタン電池箱
    |
    +-- 汽车电瓶 → 销售店
    |
    +-- 取不下来 → 不拆 → 小型家电或店铺
```
