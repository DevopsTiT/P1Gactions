# Glossary

| Term | What it means | Why you care here |
|---|---|---|
| PagerDuty AI Assistant | The chat that answers in Microsoft Teams during an incident. | The old checks mostly prove this chat. |
| SRE agent | The agent that catches a person up on the incident and suggests checks. | Needs its own pass line. |
| Scribe | The agent that writes a note from a bridge. | Needs a test bridge and a note a reviewer can match. |
| Status draft | A stakeholder update prepared by the assist. | Passes only if a person sends it. |
| Insights | The agent that answers questions about incident patterns. | Optional. One Teams question if it is enabled. |
| Shift | The agent that looks at on-call coverage. | Not a pass item for this Teams pilot. |
| Test service | A PagerDuty service that alerts only the pilot. | Where every check runs. |
