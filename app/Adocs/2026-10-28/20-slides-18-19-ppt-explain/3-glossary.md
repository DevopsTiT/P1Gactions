# Glossary

| Word | What it means on these two slides |
|---|---|
| Zone | A box that groups systems with the same job. Used on slide 19. |
| Hub | The system in the center. On this deck it is PagerDuty. |
| Provider | A detection tool that sends the signal. |
| Consumer | BAM-India consumes the page. The war room consumes the briefing. |
| Red dot | The personal-information mark on slide 18. It means an employee name or a Teams identity. |
| Prompt | The text the assist reads. The paging phone number is not part of it. |
| Notes pane | The speaker text under the slide. Paste the script there. |
