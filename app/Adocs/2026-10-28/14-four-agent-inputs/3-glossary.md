# Glossary

| Term | What it means | Why you care here |
|---|---|---|
| SRE agent | The agent that catches a person up on the open incident. The product name is Paige. | This is the only agent that uses the incident card. |
| Scribe | The agent that listens to a bridge and writes a note. | Its input is audio. |
| Insights | The agent that answers questions about many past incidents. | Its input is history, plus one question. |
| Shift | The agent that reads who is on call. | Its input is the schedule. It is outside this Teams pilot. |
| Sample id | A made-up incident number used to show the shape of the data. | INC-48291 is a sample. |
| Payload | The fields the monitor sent into PagerDuty when it opened the incident. | A Dynatrace problem id is there only if the monitor included it. |
