# Glossary

| Word | What it means on this map |
|---|---|
| Primary | The on-call employee. The red dot marks this person. |
| page | The incident reaches Primary. |
| notify | The Teams channel monitoring-2026-prod receives the incident. |
| prompt | The question Primary sends to PagerDuty AI Assistant. |
| summary | The catch-up text in the reply. |
| causes | The root-cause draft. Primary replaces it with confirmed evidence before publish. |
| status | The status text. A person sends it. |
| Scribe wrap-up | The bridge note. The kept result is text. |
| fact-check | Primary checks the reply, then escalates or resolves in PagerDuty. |
| PIR draft object | The write-up before publish. |
| Final PIR | The PIR after Primary edits the draft. |
