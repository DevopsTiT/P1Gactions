# Glossary

| Word | What it means |
|---|---|
| Zone | A box that groups systems with the same job. |
| Hub | The system in the center. Here it is PagerDuty. |
| Provider | The tool that sends the signal. The detection tools are the providers. |
| Consumer | The person or desk that receives the page or the briefing. |
| Yellow note | The short constraint on the slide. It names the new box and what stays where it is. |
| Line label | The words on an arrow, such as critical event, call / SMS, or text reply. |
| EIP architecture page | The example layout. This slide copies that layout. It does not copy the EIP mediators. |
