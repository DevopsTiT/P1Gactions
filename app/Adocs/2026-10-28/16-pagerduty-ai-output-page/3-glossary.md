# Glossary

| Term | What it means | Why you care on this page |
|---|---|---|
| Generative | The model writes new text. | The tick for this product. |
| Discriminative | The model returns a score, yes/no, or a category. | Not the result of this assist. |
| Boundary | How free the wording is allowed to be. | Here the shape is a briefing, and the sentences vary. |
| Fixed structure | Pulling set fields, such as a name and an address, out of a document. | Not this output. |
| Open content | A free piece of writing, such as a blog post. | Not this output. |
| Status draft | Stakeholder text the assist prepares. | A person still sends it. |
