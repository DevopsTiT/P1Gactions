# Glossary

| Term | What it means | Why you care on this page |
|---|---|---|
| SRE | Agent that reads the open incident and the question. | First sample. |
| Scribe | Agent that listens to the bridge. | Why Sound is now ticked. |
| Insights | Agent that reads many past incidents. | Third sample, only if enabled. |
| Shift | Agent that reads the on-call schedule. | Named, then kept out of the pilot. |
| Body of knowledge | The runbook linked to the service. | SRE only. |
| Sample id | A made-up incident number. | INC-48291 is not a live ticket. |
