# Glossary

| Term | What it means | Why you care on this slide |
|---|---|---|
| Third-party AI | A product bought from a vendor, not built by the team and not taken from the Group AI library. | This whole page is that case. |
| PagerDuty AI | The generative assist on PagerDuty. The account may label it Advance. | Column 1. |
| Advance | The add-on name for PagerDuty AI when the account is not on the Reliability Platform plan. | The cost row has to ask which plan ALJ has. |
| AI Disclosure | PagerDuty’s document that names how the assist was built and which model providers it uses. | Row 4 points here instead of inventing a model name. |
| Dynatrace Assist | The chat inside Dynatrace. It used to be called Davis CoPilot. | Column 2. |
| Dynatrace Intelligence | The broader Dynatrace AI layer Assist sits on. | Use this name if a reviewer knows the old Copilot name. |
| Splunk AI Assistant | The chat inside Splunk that writes and explains searches. | Column 3. |
| PlaaS/Internal PIC | The platform cell printed on the ALJ Splunk row. | Reason the Splunk column is not marked as ordinary public cloud without a check. |
| Entire solution | You buy the vendor’s product, not a raw model. | The tick for columns 1 and 2. |
| Status draft | A stakeholder update written from the incident and the Teams conversation. | A documented PagerDuty AI feature. A person still sends it. |
| Fact-check | Reading the AI reply before you act on production. | PagerDuty’s own guidance. It is a con only if someone skips it. |
