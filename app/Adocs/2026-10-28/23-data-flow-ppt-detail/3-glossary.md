# Glossary

| Word | What it means on these pages |
|---|---|
| Hop | One move of data from one place to the next. |
| Red dot | An employee display name, a Teams identity, or a name spoken on the bridge. |
| Prompt | The text the assist reads. The paging phone number is not part of it. |
| Catch-up | The SRE reply: incident state, then the starter checks from the runbook. |
| Bridge note | The text Scribe keeps after it listens to the bridge. |
