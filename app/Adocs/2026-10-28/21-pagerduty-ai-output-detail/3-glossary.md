# Glossary

| Word | What it means |
|---|---|
| Generative | The product writes the sentences. |
| Discriminative | A score, a yes or no, or a category. That is not the result on this page. |
| Fixed structure | The same fields every time, such as a name and an address taken from a paragraph. |
| Indeterminant specific structure | The reader expects a catch-up, a status draft, or a bridge note. The sentences change with the incident. |
| Open content | A new article with no expected shape. |
| Catch-up | The SRE reply: incident facts, then the starter checks from the runbook. |
| Status draft | Stakeholder wording. A person sends it. |
| Bridge note | The text Scribe keeps after it listens to the bridge. |
| Example id | INC-48291 and P-88421. They illustrate the shape. They are not live tickets. |
