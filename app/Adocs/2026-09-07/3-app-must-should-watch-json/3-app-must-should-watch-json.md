# App Must Should Watch JSON

| Item | Value |
| --- | --- |
| File | `App-Must-Should-Watch-Classic.json` |
| Import | Dynatrace → Dashboards Classic → Upload |
| All apps | Leave dashboard filter empty |
| One app | Filter tag `app:<any-name>` |

Must-watch: Problems, Traffic, Errors, Latency avg/99th, CPU, Memory, Disk.  
Should-watch: Service/Host honeycombs, GC, Database, External failures.
