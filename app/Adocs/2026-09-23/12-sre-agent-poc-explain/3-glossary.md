# Glossary

| Term | What it means |
| --- | --- |
| POC | Proof of Concept — short safe demo before prod |
| SRE Agent | Live triage helper in PagerDuty Advance |
| Test Service | PD Service whose escalation pages only POC users |
| Runbook | Small step file the agent can cite (≤100 KB) |
| Mapped channel | Teams channel linked to that PD Service |
| AI Actions | Usage units; SRE costs 4 per ask |
| Remediation | Suggested fix; human must confirm |
| Resolve | Close incident; can save service memory |
| §0 enablement | Shared Advance + Teams setup done once |
