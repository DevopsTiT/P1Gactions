SRE Agent POC — what it is and how to run it

POC = Proof of Concept
Short safe demo (15–20 min) that SRE Agent helps triage.
NOT production rollout.

GOAL
On TEST Service only: create "Checkout latency high"
→ ask in Teams → upload poc-checkout-latency.md
→ get next steps → confirm/decline remediation → Resolve

PREREQS
Advance On · SRE Enabled · Teams Connected · channel mapped
· linkUser done · EP pages only you · runbook ≤100 KB

STEPS
1. Write poc-checkout-latency.md (5–10 steps)
2. Create TEST incident (UI or Dynatrace test key only)
3. Confirm Teams incident card
4. @pagerduty What are some likely root causes?
5. Upload runbook
6. @pagerduty Analyze past incidents
7. @pagerduty What steps should I take first?
8. READ remediation → approve or decline
9. Optional: PD web SRE Agent tab
10. Resolve

PASS IF
Grounded Teams reply · runbook cited · no silent remediation · Resolve done

COST
4 Actions per ask (~12 for three asks)

FAILS
No Advance → bot idle
Channel not mapped → no card
Prod EP → wakes real on-call (fix EP first)
