# Glossary

| Term | What it means |
| --- | --- |
| PagerDuty Advance | Paid AI platform that powers the four agents |
| AI Actions | Usage units; SRE and Scribe spend them |
| SRE Agent | Live triage / runbook / next-steps helper |
| Scribe Agent | Meeting transcript and wrap-up helper |
| Shift Agent | OOO vs on-call coverage helper |
| Insights Agent | MTTR/MTTA/volume Q&A and maturity tips |
| Event Orchestration (EO) | Optional PD noise routing / grouping before page |
| MTTA | Mean time to acknowledge |
| MTTR | Mean time to resolve |
| PIR | Post-Incident Review |
| linkUser | Teams command to map chat identity to PD user |
| custom_details | PD event field; put Dynatrace problem URL here |
| Path B (Shift) | Teams-only: Google Calendar + PD web override |
| Toil | Repetitive manual work agents are meant to cut |
