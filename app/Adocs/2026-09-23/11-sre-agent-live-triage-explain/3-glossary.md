# Glossary

| Term | What it means |
| --- | --- |
| SRE Agent | PagerDuty Advance helper for live incident triage |
| Live triage | Working the incident in the first minutes after the page |
| custom_details | Extra fields on the PD event; ~first 2k chars analyzed |
| Runbook | Step-by-step doc the agent can cite (≤100 KB) |
| Connector | Optional data source (Grafana, Datadog, etc.) wired to SRE Agent |
| Virtual responder | Workflow/escalation auto-nudge that still costs Actions |
| Remediation | Suggested fix; human must confirm |
| Service memory | Context saved after Resolve for later asks |
| Early Access (EA) | Teams SRE path may still be EA on this deck |
| PII | Personally identifiable information — keep out of channel asks |
| MTTA / MTTR | Time to acknowledge / time to resolve |
