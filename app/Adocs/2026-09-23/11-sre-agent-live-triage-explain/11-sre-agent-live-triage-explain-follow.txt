SRE Agent — Live Triage (slide explain)

WHAT IT IS
Virtual responder for the first minutes after a page.
Reads incident + ~2k chars custom_details + runbook + optional connectors.
Suggests next steps. Human confirms remediations. Memory on Resolve.

WHERE TO USE
- Teams (EA): @pagerduty in mapped channel
- PD web: Incident → SRE Agent tab
- Ops Console: AIOps + Advance → SRE tab
- Virtual responder: Incident Workflow / Escalation (EA)

GOOD FIRST ASKS
- What are some likely root causes?
- Analyze past incidents
- What steps should I take first?

POC STORY
Dynatrace-shaped "Checkout latency high" on TEST Service
→ Teams ask → upload poc-checkout-latency.md
→ past incidents → first steps → READ remediation → Resolve

LIMITS
Runbook ≤100 KB · 25 files/conversation · no customer PII in channel asks

COST
4 AI Actions per ask / nudge / virtual responder trigger

HARD RULES
TEST Service only. Confirm remediations. Put Dynatrace problem URL early in custom_details.
Dynatrace creates the incident; it is usually not the main SRE connector list item.
