# Glossary

| Term | What it means |
| --- | --- |
| Toil | Repetitive manual ops work that does not need deep invention each time |
| Dig docs | Searching runbooks and past incidents under pressure |
| Take notes | Capturing bridge decisions for PIR / tickets |
| Fix coverage | Repairing on-call schedule gaps and overrides |
| Report trends | MTTA/MTTR, noise, maturity reporting |
| Cut toil | Agents draft/suggest so humans decide faster |
