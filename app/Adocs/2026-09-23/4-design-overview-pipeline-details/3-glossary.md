# Glossary

| Term | What it means |
| --- | --- |
| PD Service | PagerDuty service that owns integration key and escalation |
| Event Orchestration | Optional rules to route/suppress/enrich incoming events |
| Page | Notify on-call via PD |
| Triage | First-pass understanding of an active incident |
| Bridge | Live incident meeting (war room) |
| Coverage | Who is scheduled to take pages |
| Analytics | Trends like MTTA/MTTR and noise insights |
