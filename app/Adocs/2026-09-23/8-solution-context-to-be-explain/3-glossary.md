# Glossary

| Term | What it means |
| --- | --- |
| TO-BE | Target operating model with Advance agents |
| Blast radius | How wide impact/risk of the incident or of a fix |
| Suggest and assist | Agents propose; they do not own the decision |
| Confirm remediation | Human approves the fix before/while applying it |
| Own the page | Human is accountable for the PD incident response |
