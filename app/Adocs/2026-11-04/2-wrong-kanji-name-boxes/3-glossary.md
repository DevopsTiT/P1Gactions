# Glossary

| Term | What it means |
|---|---|
| 逵 | Family name. Inside the 辶 radical: 土, 八, 土. |
| 達 | The lookalike on the screen. Inside the 辶 radical: 羊 on top of 土. |
| 树格 | Given name. Two characters. |
| 格 | The second character of the given name. The box currently has only this one. |
| 全角 | The message this site shows when it refuses a character outside the Japanese set. |
