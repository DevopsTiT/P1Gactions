# Glossary

| Term | What it means |
|---|---|
| Model name | The engine name plus a version, such as a numbered GPT or Claude release. |
| PagerDuty AI | The product. The same product can be labeled PagerDuty Advance on the account. |
| Advance AI Disclosure | The file that lists the providers PagerDuty assessed. |
| Assurance Profile | The PagerDuty page where that file is downloaded. |
| Subprocessor | A company PagerDuty may use to run part of the service. |
| Hyperdoc | The company listed for video and audio transcription. |
