## Summary

There is no public PagerDuty model name with a version. The product page says the providers are in the PagerDuty Advance AI Disclosure. The public subprocessor page names four AI companies and does not name a model version. Write that in row 4. Copy a version only after the disclosure file is downloaded.

## Investigation

| Source | What it says |
|---|---|
| The form cell | No single public model name. Providers are listed in the PagerDuty Advance AI Disclosure. |
| PagerDuty docs, PagerDuty AI | The disclosure is downloaded from PagerDuty's Assurance Profile. Search for PagerDuty Advance AI Disclosure and take the latest file. |
| PagerDuty product page | Advance uses assistance from certain LLM providers. The page does not name one model. |
| Subprocessor page, generative AI section | Amazon Web Services, Google, Microsoft, and OpenAI are listed for Artificial Intelligence. Hyperdoc is listed for video and audio transcription. |
| AWS case study about PagerDuty Advance | One public description says a build used Amazon Bedrock, Anthropic Claude, and Amazon Q index. That page does not give a Claude version. |

The subprocessor page was last modified on 2026-07-13. It lists companies. It does not list a string such as a numbered GPT release or a numbered Claude release.

## Result

Put this in row 4:

```
No single public model name. Generative AI features may use Amazon Web Services, Google, Microsoft, and OpenAI. Model versions are in the latest PagerDuty Advance AI Disclosure.
```

Get the version from the disclosure when you need the exact string.

1. Open PagerDuty's Assurance Profile.
2. Search for PagerDuty Advance AI Disclosure.
3. Download the latest file.
4. Copy the model names and versions from that file into row 4.

Row 5 already has Entire solution marked. That matches a product that can call more than one provider. The form note says to leave the model line blank when the model is unknown. The sentence above is the known public answer. A guessed version would be a new claim.
