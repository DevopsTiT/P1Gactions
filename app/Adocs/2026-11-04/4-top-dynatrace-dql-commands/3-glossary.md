# Glossary

| Term | What it means |
|---|---|
| DQL | Dynatrace Query Language. The text you paste into a Notebook. |
| fetch | The first line. It chooses logs, hosts, problems, or spans. |
| filter | Keeps the rows you care about. |
| summarize | Collapses rows into a count. |
| count() | Number of log lines. |
| countDistinct() | Number of different names. |
| log.source | The file path stored with the log line. |
| content | The text of the log line. |
| HOST_GROUP- | The host group id. Terraform scope uses this. |
| duration | Span length in nanoseconds. |
