# Glossary

| Term | What it means |
|---|---|
| 全角 | Full-width Japanese characters. This form also uses that word when a character is outside the Japanese set. |
| 姓 | Family name. |
| 名 | Given name. |
| セイ | Family name in katakana. |
| メイ | Given name in katakana. |
| 逵 | Family name to enter. JIS level 2. |
| 树格 | Given name to enter. 树 is simplified Chinese. 格 is a Japanese jōyō kanji. |
