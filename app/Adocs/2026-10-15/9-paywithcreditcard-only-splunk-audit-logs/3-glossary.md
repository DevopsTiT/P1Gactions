# PayWithCreditCard Only Splunk Audit Logs Glossary

| Term | What it means |
|---|---|
| `log.source` | The file or stream a log line came from. |
| remote_searches.log | Splunk internal log of searches sent to search peers. |
| splunkd_ui_access.log | Splunk internal log of web UI requests. |
| OneAgent | Dynatrace agent installed on a host that ships its logs and metrics. |
| Onboarding | Configuring a service so its logs reach Dynatrace. |
