# BC2 CVS GMO RunLevel Glossary

| Term | What it means |
|---|---|
| bc2 | BillingCenter 2. bc2-ui is the web tier and bc2-batch runs batch jobs. |
| bcsubledger | The billing sub-ledger service. |
| CVS offline payment | A payment made at a convenience store and reported later in a file. |
| GMO | The GMO Payment Gateway, used for card payments. |
| EXECTRAN | The GMO API call that runs a card transaction. |
| SearchTrade | The GMO API call that looks up a transaction's status. |
| Server.RunLevel | The Guidewire server startup state. "ready" means the server can take traffic. |
| `matchesPhrase` | DQL whole-word match, ignoring case. |
| `contains` | DQL substring match. |
