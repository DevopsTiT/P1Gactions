# ESBv4 Quote Timeout 80 Glossary

| Term | What it means |
|---|---|
| esbv4 | Enterprise service bus that forwards partner requests to the policy center. |
| kakakucomauto | Kakaku.com car insurance comparison channel. |
| pc-inssuite | The policy center (Guidewire PolicyCenter) service. |
| Request ID | UUID shared by every log line of one request. |
| Subsearch | Splunk inner search in `[ ]` that runs first. |
| `format` | Splunk command that turns subsearch rows into a search string. |
| `lookup` | DQL join of a second query on a shared field. |
| `dedup` | Removes duplicate values. |
