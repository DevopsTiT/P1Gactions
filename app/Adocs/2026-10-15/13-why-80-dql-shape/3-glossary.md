# Why 80 DQL Shape Glossary

| Term | What it means |
|---|---|
| Subsearch | Splunk inner search pasted into the outer search. |
| `format` | Splunk command that builds an OR search string. |
| `lookup` | DQL join that adds fields from a second query. |
| `prefix` | lookup option that renames joined fields. |
| `summarize` | DQL grouping and counting. |
| `countIf` | Counts rows where a condition is true. |
| Scanned bytes | How much log data a query read. Drives speed and cost. |
