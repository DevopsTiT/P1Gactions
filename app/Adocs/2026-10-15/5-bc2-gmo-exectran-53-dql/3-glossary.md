# BC2 GMO EXECTRAN 53 Glossary

| Term | What it means |
|---|---|
| GMO | GMO Payment Gateway, the card payment provider. |
| EXECTRAN | GMO API call that executes the card transaction. |
| bc2-ui | BillingCenter 2 web tier. |
| bc2-batch | BillingCenter 2 batch tier. |
| bcsubledger | Billing sub-ledger service. |
| `makeTimeseries` | DQL command that counts events per time bucket, like Splunk `timechart`. |
