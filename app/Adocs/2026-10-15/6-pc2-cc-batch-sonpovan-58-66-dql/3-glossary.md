# PC2 CC Batch Sonpovan Glossary

| Term | What it means |
|---|---|
| pc2-batch | PolicyCenter 2 batch tier. |
| cc-ui | ClaimCenter web tier. |
| cc-batch | ClaimCenter batch tier. |
| sonpovan | The non-life insurance network (Sonpo-VAN) integration service. |
| Work item | A unit of work processed by a Guidewire batch work queue. |
| `failed=true` | The work item finished with a failure. |
| `expand` | DQL command that makes one row per array element. |
| `collectArray` | DQL aggregation that builds an array from many rows. |
| `collectDistinct` | DQL aggregation for distinct values, like Splunk `values()`. |
