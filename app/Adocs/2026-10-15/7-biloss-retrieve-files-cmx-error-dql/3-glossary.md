# BILoss Retrieve Files CMX Error Glossary

| Term | What it means |
|---|---|
| BILoss | The loss data batch jobs (retrieve, process and upload files). |
| CMX | The external system the BILoss jobs exchange files with. |
| `regex` | Splunk command that filters by a case-sensitive regular expression. |
| `formatTimestamp` | DQL function that turns a timestamp into text in a chosen time zone. |
| `host.name` | The Dynatrace field for the host or job name. |
