# BILoss Retrieve Files CMX Error Result

| Outcome | What to do |
|---|---|
| Rows returned | Read `content` to see which CMX call failed. |
| 0 rows and host listed in the check | No CMX Error in the last 24 hours. |
| 0 rows and host not listed | BILoss logs are not in Dynatrace, or the host name is different. |
