# Result

| Situation | What to do |
|---|---|
| Form never saved | Leave the page. Nothing was created. |
| Ticket saved | Set Incident State to Resolved, fill Resolution code and Resolution notes, click Update. |
| Form blocks Resolved | Go through In Progress first, or ask a testing 3122 member or SILVA admin. |
| Prefer API | Run the commands in `9.sh` after replacing the password and sys_id. |
| Want Closed now | Usually not possible. SNOW closes Resolved tickets automatically after a few days. |
