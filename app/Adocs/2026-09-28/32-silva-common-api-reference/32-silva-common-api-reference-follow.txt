SILVA Common API Reference (commands in 32.sh, not run; replace __SNOW_PASSWORD__)

APIs
Table API            /api/now/v2/table/<table>            GET list, POST create
Table API one record /api/now/v2/table/<table>/<sys_id>   GET, PATCH (PUT/DELETE: do not use)
Aggregate API        /api/now/stats/<table>               count, group by
CMDB Instance API    /api/now/cmdb/instance/<class>/<id>  CI + relationships
CMDB Meta API        /api/now/cmdb/meta/<class>           class fields
List export (browser) /<table>_list.do?CSV | ?EXCEL | ?XML | ?JSONv2

Key params
sysparm_query (filter), sysparm_fields (columns, dot-walk ok), sysparm_display_value=true,
sysparm_exclude_reference_link=true, sysparm_limit, sysparm_offset, sysparm_no_count,
sysparm_input_display_value (POST/PATCH with names), header X-Total-Count

Query operators (^ = %5E in URL)
=  !=  LIKE  STARTSWITH  ENDSWITH  IN  ISEMPTY  ISNOTEMPTY  INSTANCEOF
^ (AND)  ^OR  ^NQ  ORDERBY  ORDERBYDESC  dot-walk parent.name=...
Tip: build filter in list view -> right-click breadcrumb -> Copy query

32.sh lines
1-4   discovery: sys_db_object, sys_dictionary (offering, service), sys_choice env labels
5-14  host, svc_ci_assoc, cmdb_rel_ci, service, fscd variants, offerings, all env pairs, groups, user
15-17 CMDB instance (server id, server + relations), CMDB meta
18-21 counts: offerings total, by env, by service; hosts per service
22-26 export: row count, host->service CSV, offerings CSV, browser CSV/EXCEL
27-30 incidents: by number, by correlation_id, POST test, PATCH resolved (run only on purpose)

Errors
[] -> no match or ACL hides rows (check in browser)
400 -> bad field name (check sys_dictionary)
401 -> wrong password
403 -> no read access (ask SILVA admin)
429 -> too many calls
