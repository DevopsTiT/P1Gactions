# Glossary

| Term | What it means | Why you care |
|---|---|---|
| Assignment group | The team that owns the ticket. | Now Ops_Middleware_Monitoring_AXAJP. |
| Assigned to (assigned_to) | The person working the ticket. | Now Shuge KUI. It must be a group member. |
| Additional comments (comments) | Notes the customer or end user can see. | CLOSE writes "Resolved" here. |
| Work notes (work_notes) | Internal notes, hidden from the end user. | CLOSE puts the detailed closing block here. |
| Close notes (close_notes) | Resolution notes in the Closure Information tab. | Holds the cause and duration. |
| Short description | The ticket title. | Uses the Dynatrace format again. |
| notFilled | List the POST task returns of fields SNOW left blank. | Shows if the group or person did not match. |
