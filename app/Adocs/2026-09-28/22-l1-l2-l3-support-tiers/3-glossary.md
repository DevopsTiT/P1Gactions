# Glossary

| Term | What it means | Why you care |
|---|---|---|
| L1 | First-line support (service desk, NOC) | Handles simple, known issues. |
| L2 | Second-line support (application or platform team) | Fixes most real incidents. |
| L3 | Third-line support (developers, vendor) | Fixes code and design problems. |
| Escalation | Moving a ticket to a higher tier | Happens when the current tier cannot fix it. |
| Runbook | Step-by-step guide for a known alert | Lets L1 fix issues without experts. |
| NOC | Network operations center, a team watching alerts 24/7 | Often acts as L1. |
| Assignment group | The SILVA team that owns the ticket | The workflow sets the first one. |
