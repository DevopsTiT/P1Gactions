# Glossary

| Term | What it means |
| --- | --- |
| Parallel branch | Two tasks that depend on the same predecessor and run together |
| add-cross-links | Task that links SNOW and PagerDuty after both exist |
| html_url | PagerDuty incident web link |
| PagerDuty note | Comment on a PagerDuty incident (needs From email) |
| Soft miss | Missing INC at close is not an error |
| ANY (condition) | Run whether the predecessor succeeded or failed |
