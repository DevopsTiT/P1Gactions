OPEN And CLOSE Workflow Data Flow

OPEN (problem ACTIVE: CREATED / UPDATED / REOPENED)
Task 1 prepare-payload (no SILVA calls)
 A event: entity_tags "[Ctx]key:value" -> key/value; dt.cost.product etc; affected hosts; security context -> env part
 B getProblem(event.id): title, displayId, severityLevel, impactLevel, rootCauseEntity, evidence, tags, zones
 C root evidence event: properties (sorted), dt.event.description (headline), dt.event.title, metric selector
 D getEntity(root) -> HOST via fromRelationships -> displayName, ipAddress, tags, zones
 E decide (first value wins)
   host: entity displayName > event host > host tag + AGO_DOMAIN > "on host X"
   severity: AVAILABILITY critical 1/1, ERROR error 2/2, CUSTOM/INFO info 4/4, else warning 3/3; then fixed 4/4
   system: SYSTEM_MAP key as whole word in system/app/dt.cost.product tags, sec context, entity names
   env: map > AGO_AXAENVIRONMENTNAME/env/environment tag > sec context > Development
   service: map > service tag > default (then SILVA derives from CI)
   group: TEST override > AGO_AXA_SUPPORTGROUP tag > map L2 > Ops_Middleware_Monitoring_AXAJP
   assigned_to Shuge KUI only for default L2 group
 F short desc "[DYNATRACE JAPAN][host] - headline"; description = headline + Additional Information JSON

Task 2a post-silva: GET cmdb_ci (host) -> POST incident (correlation_id = display_id)
  -> if business service blank: svc_ci_assoc, then defaults -> PATCH blanks -> return stored + notFilled
Task 2b trigger-pagerduty: dedup_key dt-problem-<display_id> (parallel)

CLOSE (CLOSED / RESOLVED)
Task 1 prepare-close-ids: display_id -> correlationId, dedupKey; getProblem -> duration, cause, notes
Task 2a: GET incident correlation_id=display_id limit 1 -> PATCH state 6, Solved (Permanently)
Task 2b: PagerDuty resolve same dedup_key

Risks
- UPDATED in OPEN trigger -> duplicate INCs
- CLOSE limit=1 -> other duplicates stay open
- EIP map env Production beats tag -> EIP test labelled Production
- CLOSE DASHBOARD_URL / PD_SERVICE_URL placeholders appear in notes
- password + routing key hard-coded -> never push
