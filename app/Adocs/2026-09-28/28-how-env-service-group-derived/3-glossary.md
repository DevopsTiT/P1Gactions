# Glossary

| Term | What it means | Why you care |
|---|---|---|
| AGO_AXAENVIRONMENTNAME | AXA tag with the environment name on a host | Source of the SILVA environment. |
| AGO_AXA_SUPPORTGROUP | AXA tag with the support team on a host | Source of the assignment group. |
| Configuration item (CI) | The host record in SILVA's CMDB | SILVA uses it to fill the business service. |
| CMDB | SILVA database of hosts, services and their links | Holds the host-to-service link. |
| svc_ci_assoc | SILVA table linking hosts to services | Backup when SILVA does not fill the service. |
| Default | Value used when no source gives one | Keeps the ticket valid. |
