# Glossary

| Term | What it means |
| --- | --- |
| Mandatory (*) | Field required on the form |
| UI Policy | Browser-side form rule; not applied to API |
| Data Policy | Server-side rule; can force mandatory for API too |
| Display value | Human label, like "JP DBA" |
| sysparm_input_display_value | Lets the API accept labels instead of sys_ids |
| sys_choice | Table with dropdown choices |
| dependent_value | Category that a subcategory belongs to |
| service_offering | Specific offering under a business service |
| business_service | Business service record |
| Enrichment gap | A field that used a default value |
| sys_dictionary | Table describing every column |
