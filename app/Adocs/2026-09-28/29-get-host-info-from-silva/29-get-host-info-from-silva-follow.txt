How to get info from SILVA (host -> service -> offering -> group)

UI (login https://silvastg.service-now.com, type in the left filter navigator):
1. cmdb_ci_server.list -> Name contains ts12 -> open -> Name, FQDN, Install status, Support group
   (nothing? try cmdb_ci.list)
2. On the CI: related list "Business Services", or svc_ci_assoc.list with Configuration item = ts12.hk.intraxa
   -> Service column = business service
3. Open the business service -> Support group, Managed by group
4. service_offering.list -> Parent = that business service -> offering Name + Environment
5. sys_user_group.list -> Name = InfraSupport_Dist-WindowsHK_L2_ASIA -> Active true?
6. Environment labels: Environment dropdown on any incident
7. Existing ticket: incident.list -> Number = INC30339746

API (29.sh, replace __SNOW_PASSWORD__):
line 1 host in cmdb_ci
line 2 host -> business service (svc_ci_assoc)
line 3 business service details / support group
line 4 offerings of the service
line 5 group exists
line 6 environment labels
line 7 incident fields

Empty API result but UI shows it -> ask SILVA admin for read access for Tech_DynatraceJP_WS.
401 = wrong password, 403 = table blocked.

All groups / all services as CSV: see 18-silva-export-groups-business-services.
