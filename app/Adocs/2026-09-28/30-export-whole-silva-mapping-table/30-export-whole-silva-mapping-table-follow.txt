Export The Whole SILVA Mapping Table

No single SILVA table has everything. Backbone = svc_ci_assoc (one row per host + business service).
Export it with dot-walked columns, export service_offering, then join.

BROWSER (easiest)
1. https://silvastg.service-now.com -> type svc_ci_assoc.list
2. Gear icon -> Personalize List Columns
   Configuration item -> Name, FQDN, Class, Install Status, Support group
   Service -> Name, Support group, Operational status
3. Right-click a column header -> Export -> CSV -> save as silva_ci_service.csv
4. service_offering.list -> columns Name, Parent, Environment, Support group, Company -> Export CSV -> silva_service_offerings.csv
5. Row limit hit? Split with a filter (A-M, N-Z) or use the API.
6. List empty? Use cmdb_rel_ci.list filtered on Parent.Class = Business Service.

API (30.sh, not run, replace __SNOW_PASSWORD__)
line 1  count rows (X-Total-Count)
line 2  page 0 host->service with dot-walked columns
line 3  page 1 (offset 10000); add more if needed
line 4  combine pages -> silva_ci_service.csv
line 5  offerings -> silva_service_offerings.csv
line 6  fallback cmdb_rel_ci
line 7  groups
line 8  environment labels
line 9  python3 30-join-silva-tables.py -> silva_whole_table.csv

Final columns: host, host_fqdn, host_class, host_status, host_support_group,
business_service, service_support_group, service_status,
offering, offering_environment, offering_support_group, company

Use in workflow: business_service + offering -> SYSTEM_MAP; service_support_group -> l2Group;
offering_environment -> ENVIRONMENT / SILVA_ENVIRONMENTS.
