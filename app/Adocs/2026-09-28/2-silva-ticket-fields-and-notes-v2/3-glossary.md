# Glossary

| Term | What it means |
| --- | --- |
| sys_user_group | SNOW table of groups (teams) |
| Additional comments | Customer-visible journal field (`comments`) |
| Work notes | Internal journal field (`work_notes`) |
| Display value | Label shown on the form |
| html_url | PagerDuty incident web link |
| incident_key | PagerDuty REST name for dedup_key |
| Events API | PagerDuty API to trigger and resolve alerts |
| REST API | PagerDuty API to read incidents, needs API key |
| Dashboard tag | Dynatrace entity tag holding the dashboard URL |
