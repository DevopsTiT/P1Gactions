# Glossary

| Term | What it means |
| --- | --- |
| close_code | Standard resolution reason |
| close_notes | Text explaining the fix |
| Resolution Type | SILVA custom field for how it was resolved |
| State 6 / 7 / 8 | Resolved / Closed / Canceled |
| Soft miss | Not found is expected, not an error |
| event_action resolve | PagerDuty Events API close call |
| RESOLVE_MODE | auto resolve or comment only |
