# Glossary

| Term | What it means |
| --- | --- |
| Enrichment | Adding context to a ticket |
| PATCH | Update only the fields you send |
| work_notes | Internal journal on the ticket |
| Signature | Short text that summarizes facts; used to detect change |
| retry (workflow) | Re-run a failed task after a delay |
| Problem comment | Note on a Dynatrace problem |
| State 6 / 7 / 8 | Resolved / Closed / Canceled |
| sys_journal_field | Table that stores work notes |
