# Glossary

| Term | What it means |
| --- | --- |
| ITSM | IT Service Management: processes for serving people |
| ITOM | IT Operations Management: seeing and controlling infrastructure |
| ITIL | Best-practice framework behind ITSM terms |
| CMDB | Inventory of CIs and relationships |
| CI | Configuration item |
| Discovery | Scanning to find CIs |
| Service Mapping | Linking CIs into business services |
| em_event | Raw event table |
| em_alert | Deduplicated alert table |
| message_key | Dedup key for events |
| RITM | Requested item in a catalog request |
| CAB | Change Advisory Board |
| Known Error | Problem with known cause and workaround |
| MTTA | Mean time to acknowledge |
| MTTR | Mean time to resolve |
| MID Server | SNOW agent inside the private network |
