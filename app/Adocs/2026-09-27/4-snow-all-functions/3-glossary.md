# Glossary

| Term | What it means |
| --- | --- |
| Now Platform | The base SNOW platform all products run on |
| ITSM | IT Service Management |
| ITOM | IT Operations Management |
| CMDB | Inventory of configuration items |
| CI | One item in the CMDB |
| MID Server | Agent inside your network for SNOW |
| Flow Designer | No-code workflow builder |
| IntegrationHub | Connectors (spokes) to other systems |
| Business Rule | Server script on record events |
| Client Script | Browser script on form events |
| UI Policy | No-code form field rules |
| ACL | Access rule for table or field |
| Update Set | Package of config changes |
| GlideRecord | Server API to query and write tables |
| g_form | Browser API for the current form |
| RESTMessageV2 | Server API to call external REST |
| em_event / em_alert | ITOM raw event and correlated alert tables |
| SLA | Time target for response or resolution |
