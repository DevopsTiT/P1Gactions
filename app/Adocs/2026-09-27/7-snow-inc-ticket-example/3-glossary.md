# Glossary

| Term | What it means |
| --- | --- |
| Work notes | Internal journal entries |
| Additional comments | Journal entries visible to the caller |
| Activity stream | Timeline of changes and notes on a record |
| Resolution code | Standard reason the incident ended |
| caused_by | Change that caused the incident |
| problem_id | Linked problem record |
| sys_journal_field | Table storing work notes and comments |
| task_sla | Table storing SLA timers per ticket |
| Display value | Human label instead of raw code |
