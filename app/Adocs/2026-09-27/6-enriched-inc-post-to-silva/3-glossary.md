# Glossary

| Term | What it means |
| --- | --- |
| Enrichment | Adding context to an alert before it reaches people |
| Problems API | Dynatrace API returning full problem details |
| Entity tag | key:value label on a Dynatrace entity |
| DQL | Dynatrace Query Language |
| Credential vault | Dynatrace secret store |
| cmdb_ci | SNOW base CI table |
| install_status 7 | Retired CI |
| support_group | Team that owns the CI |
| business_service | Business service the CI belongs to |
| work_notes | Internal time-stamped journal on a ticket |
| sysparm_input_display_value | Lets you send names instead of sys_ids |
| u_ field | Custom field added by your company |
