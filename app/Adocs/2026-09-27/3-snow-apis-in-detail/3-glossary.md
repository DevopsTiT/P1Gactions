# Glossary

| Term | What it means |
| --- | --- |
| REST API | Web interface using HTTP verbs and JSON |
| Table API | SNOW API to read and write any table |
| sys_id | Unique 32 character id of a record |
| Encoded query | SNOW filter string like `a=1^b=2` |
| sysparm_* | Query parameters that control the Table API |
| Basic auth | Username and password header |
| OAuth | Token-based login |
| Scripted REST API | Custom endpoint coded inside SNOW |
| Import Set | Staging table plus transform map |
| ACL | Access Control List; who can read or write a table |
| Rate limit | Max calls allowed per time window |
