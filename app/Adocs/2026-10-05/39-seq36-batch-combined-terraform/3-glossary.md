# Glossary

| Term | What it means |
|---|---|
| Detector | Dynatrace Davis anomaly detector that opens a problem when a query crosses a rule |
| for_each | One Terraform block that creates one object per map entry |
| Lookup | A table uploaded to Grail under `/lookups/` and joined in DQL |
| arrayMovingSum | DQL function that adds up the last N points of a series |
| Consecutive NG | Two failed runs with no OK run between them |
| app.name | Event property used to route problems that have no host |
| pagerduty.enabled | Event property telling the standard flow whether to page |
| Terraform state | Terraform's record of which real objects it created |
