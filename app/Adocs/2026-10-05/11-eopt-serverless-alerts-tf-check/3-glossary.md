# Glossary

| Term | What it means |
|---|---|
| `loglevel` | Dynatrace field with the detected log level (ERROR, WARN, INFO) |
| Request id | The id AWS gives each Lambda invocation; a UUID with four hyphens |
| `LD '-'` | Skip characters up to and including the next hyphen |
| `SPACE` | One or more whitespace characters |
| `WORD:level` | Capture the next word into a field called `level` |
| Daily digest | One email a day summarising the last 24 hours |
| `replace()` | Terraform function used here to add a time range to the shared query |
