# Glossary

| Term | What it means |
|---|---|
| DQL | Dynatrace Query Language |
| Grail | Dynatrace data store for logs, metrics, events |
| Pipeline | Commands chained with `\|`, each working on the previous result |
| Record | One row (for logs, one log line) |
| Field | One column, such as `content` or `host.name` |
| Time series | A list of values, one per time slot |
| Lookup | A table uploaded under `/lookups/` and joined into a query |
| Notebook | Dynatrace app for running and saving queries |
| SPL | Splunk Search Processing Language |
