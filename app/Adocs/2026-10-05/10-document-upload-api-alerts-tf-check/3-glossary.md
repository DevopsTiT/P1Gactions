# Glossary

| Term | What it means |
|---|---|
| Pending upload | An upload that started but never logged completed or failed |
| `parse` | DQL command that pulls fields out of text using a pattern |
| `LD` | Pattern part that skips any characters up to the next literal |
| `WORD` | Pattern part for letters, digits and underscore; stops at a hyphen |
| `NSPACE` | Pattern part for any run of characters without spaces |
| `SPACE?` | An optional space |
| `countIf` | Counts rows that meet a condition inside `summarize` |
| `for_each` | Terraform loop that creates one resource per map entry |
| Routing key | PagerDuty Events v2 key that picks which service gets the page |
| Credential vault | Dynatrace store for secrets that workflows can read |
| `createEvent` | SDK call that sends a Davis event, which can open a problem |
