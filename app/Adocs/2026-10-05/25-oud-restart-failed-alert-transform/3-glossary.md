# Glossary

| Term | What it means |
|---|---|
| OUD | Oracle Unified Directory, an LDAP directory server |
| `matchesPhrase` | DQL word match that ignores case; closest to a Splunk term search |
| `dt.entity.host` | The Dynatrace host entity that sent the log line |
| `dt.source_entity` | Event property that attaches a problem to an entity |
| `{dims:...}` | Placeholder in a detector event that is filled with the series dimension value |
| OneAgent log monitoring | OneAgent feature that ships log files from a host to Dynatrace |
