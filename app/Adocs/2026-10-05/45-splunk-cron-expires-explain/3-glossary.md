# Glossary

| Term | What it means |
|---|---|
| Cron expression | Five fields (minute, hour, day of month, month, day of week) that define a schedule |
| `*` | Every value for that field |
| `*/5` | Every 5 units |
| `2-6` | A range, for example Tuesday to Saturday in the weekday field |
| Time Range | The period of data a Splunk search reads |
| Expires | How long Splunk keeps a triggered alert and its results |
| Throttle | Suppresses repeat alerts for a set time |
| Triggered Alerts | Splunk page listing alerts that fired |
| Search head | The Splunk server that runs scheduled searches |
| time_zone | Dynatrace workflow setting that fixes which clock the cron uses |
