# WeChat Photo Location Glossary

| Term | What it means | Why you care |
|---|---|---|
| File Transfer | WeChat chat with yourself to move files between phone and Mac | Where the photos came from |
| Container | macOS sandbox folder for an app under `~/Library/Containers` | WeChat keeps its data there |
| `.dat` | WeChat's encrypted image cache format | Cannot be opened as a picture directly |
| Cursor assets | Folder where Cursor saves images pasted into chat | Has normal PNG copies |
