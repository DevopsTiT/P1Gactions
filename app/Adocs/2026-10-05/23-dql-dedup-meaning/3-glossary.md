# Glossary

| Term | What it means |
|---|---|
| Dedup | Short for de-duplicate: keep one record per unique value set |
| Duplicate record | Two records with identical values in the chosen fields |
| `countDistinct` | Counts unique values instead of all records |
| Syslog path | The route a firewall log takes to the collector; two routes can deliver the same line twice |
| `sort:` (in dedup) | Decides which record is kept when several match |
