# Glossary

| Term | What it means |
|---|---|
| REPORT line | Line Lambda writes after each invocation with duration and memory used |
| Max Memory Used | Peak memory of one invocation, in MB |
| Anchor text | Fixed text in a parse pattern that pins where the value is |
| `INT` | DPL matcher for a whole number |
| SFDC | Salesforce |
| Duplicate alert | Two alerts on the same condition, giving two notifications per event |
| Recipient group | Set of email addresses that share the same alerts |
