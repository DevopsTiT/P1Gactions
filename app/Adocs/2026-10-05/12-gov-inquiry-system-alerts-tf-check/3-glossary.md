# Glossary

| Term | What it means |
|---|---|
| Business notice | An email that reports normal activity, such as a file processed with counts |
| Biz file summary | The log line the gov-inquiry Lambdas write after processing a file |
| ND / answer / request / MDM file | The file types in the government inquiry flow |
| pipitLINQ | External system that sends error files |
| Kyoto GW | Gateway that sends system error files |
| `NSPACE` | Parse pattern for any run of characters without spaces |
| `INT` | Parse pattern for a whole number |
| `concat()` | DQL function that joins text values |
| `coalesce()` | Returns the first non-empty value, used to print "-" for missing counts |
| `for_each` | Terraform loop creating one resource per map entry |
