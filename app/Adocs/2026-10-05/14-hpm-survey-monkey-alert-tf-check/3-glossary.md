# Glossary

| Term | What it means |
|---|---|
| SurveyMonkey | Online survey service the Lambda pulls files from |
| `status` (logs) | Dynatrace field with the detected log status |
| Dealerting samples | Clean minutes needed before the problem closes |
| Throttle | Splunk pause on repeat alerts |
| `_Normal` | Non-urgent alert: email, no page |
| `for_each` | Terraform loop to create several similar resources from one block |
