# Glossary

| Term | What it means |
|---|---|
| OpenPaaS | The company's OpenShift container platform |
| ESG | The API gateway (CoreIT) that OpenPaaS apps call |
| Egress proxy | Outbound proxy; its public IPs are what external services see |
| Absence alert | Fires when expected traffic is missing |
| `alertCondition = BELOW` | Detector fires when the value drops under the threshold |
| `append` (Splunk) | Adds the results of a second search to the first |
| `spath` (Splunk) | Extracts fields from JSON; DQL equivalent is `parse content, "JSON:j"` |
| `ISO8601` (DPL) | Matcher for timestamps like 2026-10-05T10:00:00.123Z |
