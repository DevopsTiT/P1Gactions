# Glossary

| Term | What it means |
|---|---|
| Duplicate resource | Terraform error when two `.tf` files in one folder define the same type and name |
| Terraform folder | Terraform reads every `.tf` file in the folder it runs in, as one configuration |
| for_each | One block that creates one object per map entry |
| Auto-adaptive detector | Dynatrace detector that learns the normal baseline itself |
| arrayMovingMax | DQL function: the max of the last N points for each point |
| Placeholder | Text like `{dims:application}` that Dynatrace fills in when a problem opens |
| Lookup | A Grail table under `/lookups/` joined in DQL |
