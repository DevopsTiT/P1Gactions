# Glossary

| Term | What it means |
|---|---|
| Cisco ASA | Cisco firewall that also terminates the VPN |
| ASA-2-113022 | ASA message: an AAA server (here LDAP) was marked FAILED |
| Windows_LDAP | Name of the AAA server group pointing at Active Directory |
| Sourcetype | Splunk label for the log format; Dynatrace has no direct equivalent |
| `dedup` | DQL command that keeps one record per unique value set |
| AGO tags | Entity tags the standard workflow uses to find the SILVA support group |
| `dt.source_entity` | Event property that links a custom event to a Dynatrace entity |
