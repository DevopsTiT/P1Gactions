# Glossary

| Term | What it means |
|---|---|
| AGPO | AG Portal, the agency portal application |
| Auth0 | Identity service used for login and password changes |
| EIP | Enterprise integration platform that talks to MQ |
| MQ | Message queue middleware (IBM MQ) |
| Throttle | Splunk setting that suppresses repeat alerts for a time |
| For each result | Splunk sends one action per result row |
| arrayMovingSum | DQL function adding up the last N points, used for "count in 5 minutes" |
| Static-threshold detector | Dynatrace rule that fires when a value crosses a fixed number |
| dealertingSamples | How many good minutes close the problem |
| pagerduty.enabled | Event property telling the standard flow whether to page |
