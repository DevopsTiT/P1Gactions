# Glossary

| Term | What it means |
|---|---|
| Case-sensitive | "Error" and "ERROR" count as different text |
| `caseSensitive: false` | DQL option that makes `contains` ignore upper and lower case |
| Throttle | Splunk setting that stops repeat alerts for a set time |
| Dealerting samples | Number of clean minutes before Dynatrace closes the problem |
| CMX | The source system the Lambda copies files from |
| SharePoint | Microsoft document storage the files are copied to |
| `_Normal` suffix | Team naming for a non-urgent alert (email, no page) |
| `substring` | DQL function that cuts part of a text field |
