# Glossary

| Term | What it means |
|---|---|
| `from:` | Start of the time window a `fetch` reads |
| Timeframe picker | Time selector at the top of a Notebook or dashboard |
| Default timeframe | Window used when the query has no `from:` |
| `event.start` | When the problem opened |
| `toTimestamp()` | Turns text into a timestamp DQL can compare |
