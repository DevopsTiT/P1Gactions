# Glossary

| Term | What it means |
|---|---|
| Scheduled workflow | Dynatrace automation that runs on a cron schedule |
| execute-dql-query | Workflow action that runs a DQL query |
| send-email | Workflow action that sends an email |
| conditions custom | Jinja expression deciding if a task runs |
| else SKIP | Skip the task when the condition is false |
| formatTimestamp | DQL function that prints a time in a chosen format and time zone |
| `@d` | DQL day alignment; aligns to midnight UTC, not JST |
