# Glossary

| Term | What it means |
|---|---|
| Scheduled search | Splunk search that runs on a cron schedule; every Splunk alert is one |
| Expires | How long Splunk keeps a fired alert and its results |
| Detector | Dynatrace alert that checks a query every minute |
| Workflow | Dynatrace automation that can run on a cron schedule |
| dealertingSamples | Quiet minutes needed to close a detector problem |
| Problem history | Dynatrace keeps closed problems for later review |
