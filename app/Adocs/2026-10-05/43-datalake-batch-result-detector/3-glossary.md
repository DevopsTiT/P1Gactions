# Glossary

| Term | What it means |
|---|---|
| Detector | Dynatrace Davis anomaly detector; runs every minute and opens a problem when a rule is broken |
| Static threshold | Fixed number the value must go above |
| violatingSamples | Bad minutes needed to open the problem |
| dealertingSamples | Good minutes needed to close the problem |
| Problem | Dynatrace incident record that drives notifications |
| Standard flow | The tenant workflow that sends problems to SILVA, email and PagerDuty |
