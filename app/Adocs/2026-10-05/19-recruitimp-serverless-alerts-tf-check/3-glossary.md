# Glossary

| Term | What it means |
|---|---|
| `WORD` | DPL matcher for letters, digits and underscore only; stops at spaces and dashes |
| `NSPACE` | DPL matcher for any characters except whitespace; good for IDs with dashes |
| `SPACE` | DPL matcher for whitespace; needed between fields |
| `LD` | DPL matcher for "any characters"; needs fixed text after it to be reliable |
| Scheduled workflow | Workflow that runs on a cron schedule instead of on a problem |
| `\t` | Tab character; Lambda separates fields in its log lines with tabs |
