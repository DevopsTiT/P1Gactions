# Glossary

| Term | What it means |
|---|---|
| `status` (logs) | Dynatrace field with the detected log status: ERROR, WARN, INFO or NONE |
| Daily digest | One email per day summarising the last 24 hours |
| Throttle | Splunk setting that pauses repeat alerts; pointless when the search runs once a day |
| `_Normal` | Team naming for a non-urgent alert: email, no page |
| S3 | AWS object storage the Lambda copies files to and from |
| SharePoint | Microsoft document storage on the other side of the transfer |
