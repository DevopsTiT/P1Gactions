# Glossary

| Term | What it means |
|---|---|
| SPL | Splunk Search Processing Language |
| index | A Splunk data store, like a table |
| _raw | The original log line |
| _time | The event timestamp |
| stats | Groups and aggregates |
| timechart | Aggregates per time slot for charts |
| rex | Extracts fields with a regular expression |
| eval | Creates or changes a field |
| dedup | Keeps the first event per value |
| lookup | Adds fields from a CSV table |
| earliest | Start of the search time range, for example `-1h` |
