# Glossary

| Term | What it means |
| --- | --- |
| Allowlist | Domains Dynatrace may call outbound |
| External requests | Settings page that manages that list |
| Blocked request | Dynatrace refused HTTPS to a host not on the list |
| silvastg | Your ServiceNow staging hostname |
| Category / Subcategory | SNOW incident classification fields loaded from SNOW |
