# Glossary

| Term | What it means |
| --- | --- |
| YAML | Text format using indentation for structure |
| JSON | Text format using braces, brackets, and quotes |
| Twin | Same workflow written in the other format |
| metadata | YAML wrapper for apps/inputs at import time |
| schemaVersion | Which workflow definition version Dynatrace expects |
| filterQuery | Extra condition on when the trigger fires |
| action | Built-in step type (e.g. run-javascript) |
| Settings API | Dynatrace API for environment settings objects |
| Monaco | Dynatrace Monitoring as Code tool |
| Placeholder | Token like __PD_ROUTING_KEY__ you must replace |
