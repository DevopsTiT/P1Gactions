# Glossary

| Term | What it means |
| --- | --- |
| Problem notification | Classic Dynatrace push to SNOW/Slack/etc when Problems change |
| Workflow Connection | Separate credential object used by Automations SNOW actions |
| ITOM event | ServiceNow Event Management record (not an INC ticket) |
| ITSM incident | ServiceNow Incident (INC…) ticket |
| instanceName | First part of `*.service-now.com` (here: silvastg) |
| Monaco | Dynatrace Monitoring as Code tool for Settings |
