How to set the workflow in Dynatrace UI (classic silvastg + PD)

A) ServiceNow (not in Workflows)
Settings → Integration → Problem notifications → silvastg
Confirm instance=silvastg, user set, ITOM ON, ITSM OFF (unless you want INC)
Save

B) Allowlist
Settings → External requests
Add silvastg.service-now.com
Add events.pagerduty.com
Save

C) OPEN workflow
Workflows → Upload/Import
File: ago-problem-to-pagerduty-only.workflow-template.yaml
Open create-pagerduty-incident task
Replace __PD_ROUTING_KEY__ with real PD routing key
Save

D) CLOSE workflow
Upload ago-problem-closed-resolve-pagerduty-only.workflow-template.yaml
Same routing key in resolve task
Save

E) Activate both workflows (leave Draft)

F) Test
Open a test Problem → check Workflow Executions + PagerDuty + SNOW ITOM event
Close Problem → PD resolve + SNOW update via classic notification

Do NOT add ServiceNow Connection Create Incident if classic silvastg owns SNOW.
