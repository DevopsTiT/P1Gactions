# Glossary

| Term | What it means |
| --- | --- |
| Workflow | Automation that runs tasks when a Problem opens or closes |
| Draft | Saved but not yet live |
| Activate / Publish | Turns the draft into a live automation |
| Routing key | PagerDuty Events API key that chooses which PD service gets the alert |
| Dedup key | Same ID for open and close so PD resolves the right alert |
| Classic notification | Settings integration that pushes Problems to ServiceNow |
| Execution | One run of a workflow you can inspect in history |
