# Glossary

| Term | What it means |
| --- | --- |
| Connection | Stored link from Dynatrace to ServiceNow with credentials |
| Basic Authentication | Username + password login style |
| OAuth client credentials | Client id + secret instead of user password |
| `app-settings:objects:read` | Permission so Workflows can read Connections |
| Instance URL | ServiceNow base URL like https://acme.service-now.com |
| Connector | Dynatrace app that provides ServiceNow workflow actions |
