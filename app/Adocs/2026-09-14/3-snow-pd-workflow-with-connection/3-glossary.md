# Glossary

| Term | What it means |
| --- | --- |
| Connection | Dynatrace-stored ServiceNow URL + credentials |
| `connectionId` | Task field that selects which Connection to use |
| `snow-create-incident` | Connector action to create an INC |
| `snow-comment-on-incident` | Connector action to add a work comment |
| `snow-search-incidents` | Connector action to find INCs |
| `snow-resolve-incident` | Connector action to resolve an INC |
| Basic auth in JS | Old pattern with `__SNOW_USER__` / `__SNOW_PASSWORD__` in script |
