# Glossary

| Term | What it means |
| --- | --- |
| Whitelist / allowlist | Domains Dynatrace may call outbound |
| External requests | Dynatrace settings page for that list |
| Access permission | Who can edit/view Connection and workflow |
| One Account | ServiceNow / company SSO login for humans |
| OAuth Connection | Machine credentials for the workflow |
| Draft workflow | Unpublished workflow still being edited |
