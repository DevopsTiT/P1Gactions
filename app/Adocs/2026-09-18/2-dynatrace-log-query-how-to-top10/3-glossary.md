# Glossary

| Term | What it means |
| --- | --- |
| DQL | Dynatrace Query Language |
| fetch logs | DQL command to read the logs table |
| content | Field holding the raw log message |
| filter | Keep only matching log records |
| summarize | Aggregate counts / groups |
| makeTimeseries | Build a time chart from log events |
| Grail | Dynatrace platform that stores queryable logs |
