# Glossary

| Term | What it means |
| --- | --- |
| YAML | Indentation-based data serialization format |
| Scalar | Single value (string, number, bool) |
| Map / object | Nested key-value structure |
| List / sequence | Ordered items marked with `-` |
| Literal block `\|` | Multi-line string keeping newlines |
| Folded block `>` | Multi-line string joined with spaces |
| Jinja expression | `{{ ... }}` template evaluated at workflow runtime |
| Task key | Identifier under `tasks:` used by predecessors and result() |
| schemaVersion | Dynatrace workflow format version number |
