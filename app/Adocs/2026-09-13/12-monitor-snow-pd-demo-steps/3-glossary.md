# Glossary

| Term | What it means |
| --- | --- |
| Demo | Controlled open+close of one Problem to prove the workflows |
| Execution | One run of a workflow; shows each task OK or failed |
| Active workflow | Workflow is enabled so Problem events can start it |
| correlation_id | ServiceNow field holding Dynatrace Problem ID |
| dedup_key | PagerDuty key linking trigger and resolve |
| Cross-link | Work note on INC that stores the PD key |
| Non-prod | Safer environment so a demo does not page real on-call |
| Davis Problem | Dynatrace issue that opens and closes |
