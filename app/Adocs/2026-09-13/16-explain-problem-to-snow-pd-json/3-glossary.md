# Glossary

| Term | What it means |
| --- | --- |
| Workflow JSON | Uploadable Dynatrace workflow definition |
| davis-problem | Trigger type for Dynatrace Problems |
| onProblemClose false | Run on open, not close |
| run-javascript | Task that runs JS (can call fetch APIs) |
| predecessors | Tasks that must finish before this one |
| assignMap | App → group/biz/L1–L3/runbook table in prepare |
| correlation_id | SNOW field storing Problem ID |
| dedup_key | PD key for trigger (and later resolve in other WF) |
| Placeholder | `__NAME__` string to replace with real values |
| INC | ServiceNow Incident ticket |
