# Glossary

| Term | What it means |
| --- | --- |
| Connection | Dynatrace-stored link to ServiceNow with credentials |
| Connector action | Built-in workflow task (Create Incident, etc.) using a Connection |
| Secret / credential store | Place to keep PD key outside Git |
| Hardcoded placeholder | `__TOKEN__` replaced with real secret inside the file |
| Config vs secret | Maps/sys_ids = config; passwords/keys = secrets |
