Better ways than hardcoding placeholders

Yes. Best practice:

1) ServiceNow
   - Create Dynatrace Connection (URL + user/password or OAuth)
   - After upload, replace JS SNOW tasks with connector:
     Create Incident / Comment / Resolve
   - Then you do NOT need __SNOW_INSTANCE_URL__, __SNOW_USER__, __SNOW_PASSWORD__ in the file

2) PagerDuty routing key
   - Do not commit real key to git
   - Store as secret/setting if your tenant supports it, OR
   - Leave placeholder, upload, paste real key only in Dynatrace UI

3) OK to keep in prepare/Git (not secrets)
   - __SNOW_*_SYS_ID__ / assignMap
   - L1/L2/L3, runbook URLs, severity→P3/P4 rules

4) Upload template → bind Connection in wizard → edit PD key in UI

Rank:
1 Connection for SNOW (best)
2 Secret/UI for PD key
3 Direct __ replace (lab only)

Current seq-4 pack = lab/v1 with placeholders.
Harden = Connection + no secrets in Git.
