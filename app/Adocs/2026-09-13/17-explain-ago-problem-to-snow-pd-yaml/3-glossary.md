# Glossary

| Term | What it means |
| --- | --- |
| Workflow template YAML | Import format with `version` / `dependencies` / `workflow` wrapper |
| `script: \|` | Multi-line YAML string (easy to edit JS) |
| dynatrace.automations | App that runs workflow JS actions |
| davis-problem | Problem event trigger |
| onProblemClose false | Open path only |
| assignMap | App → group/biz/L1–L3/runbook table |
| Placeholder | `__NAME__` to replace before import |
| INC | ServiceNow Incident ticket |
| Twin JSON | Same create workflow in `.workflow.json` form |
