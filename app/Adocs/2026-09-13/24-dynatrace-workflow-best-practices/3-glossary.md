# Glossary

| Term | What it means |
| --- | --- |
| Best practise | Agreed safe/reliable way to build and run workflows |
| Connection | Dynatrace-stored ServiceNow credentials |
| Correlation key | Shared ID linking Problem ↔ INC ↔ PD |
| Trigger filter | Rules that limit which Problems start the workflow |
| Execution | One run of a workflow |
| Least privilege | Only the permissions needed — no more |
| Anti-pattern | Common approach that causes pain later |
