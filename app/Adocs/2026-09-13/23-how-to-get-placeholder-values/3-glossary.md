# Glossary

| Term | What it means |
| --- | --- |
| Instance URL | Base ServiceNow web address |
| Integration user | Service account for API/workflow calls |
| sys_id | ServiceNow internal 32-char record ID |
| Assignment group | Team queue for Incidents |
| Business service | Service CI linked on the Incident |
| Events API v2 | PagerDuty API used to trigger/resolve alerts |
| Integration Key | Same as routing key for Events API v2 |
| Caller | User field on the Incident (“who reported”) |
