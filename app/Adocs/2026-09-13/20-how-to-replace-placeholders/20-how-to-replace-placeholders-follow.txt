How to replace the 11 placeholders

1) Collect values in a private note (not git):
   __SNOW_INSTANCE_URL__ = https://YOUR.service-now.com
   __SNOW_USER__ / __SNOW_PASSWORD__
   __PD_ROUTING_KEY__ = PD Events API v2 key
   __SNOW_CALLER_SYS_ID__ and GROUP/BIZ sys_ids from SNOW records (URL has sys_id=...)

2) Open create YAML:
   ago-problem-to-snow-pagerduty.workflow-template.yaml

3) Find and Replace (Cmd+F / Replace):
   Find: __SNOW_INSTANCE_URL__
   Replace: https://YOUR.service-now.com
   Replace All
   Repeat for every token (all 11).
   Keep the quotes around the value.

4) Open close YAML:
   ago-problem-closed-resolve-snow-pd.workflow-template.yaml
   Replace only the same 4: URL, USER, PASSWORD, PD_ROUTING_KEY

5) Verify: search for __SNOW_ and __PD_ — should be gone.
   Optionally replace confluence.example runbook URLs.

Do not commit passwords. Prefer Dynatrace Connection later for SNOW.
