# Glossary

| Term | What it means |
| --- | --- |
| Find and Replace | Editor feature that swaps every match of a string |
| sys_id | ServiceNow internal 32-char record ID |
| Integration key | PagerDuty Events API v2 routing key |
| Replace All | Change every occurrence of one token in the file |
| Connection | Dynatrace stored credential (better than password in script long-term) |
