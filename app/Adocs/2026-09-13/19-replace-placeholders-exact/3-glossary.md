# Glossary

| Term | What it means |
| --- | --- |
| Placeholder | `__NAME__` token to replace with a real value |
| sys_id | ServiceNow internal UUID for a user/group/service |
| routing_key | PagerDuty Events API v2 integration key |
| assignMap | App → group/biz/L1–L3/runbook table in prepare |
| Instance URL | ServiceNow base URL like https://xxx.service-now.com |
