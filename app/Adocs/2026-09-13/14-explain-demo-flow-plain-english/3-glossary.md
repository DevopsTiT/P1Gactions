# Glossary

| Term | Plain meaning |
| --- | --- |
| Problem | Dynatrace record that something is broken |
| Workflow | Automation robot with steps |
| Execution | One run of that robot |
| prepare | Build data for later steps |
| ServiceNow INC | IT ticket |
| PagerDuty alert | On-call page |
| correlation_id | Problem ID stored on the ticket |
| dedup_key | Problem-based key for PD trigger/resolve |
| cross-link | Note on ticket pointing to PD key |
| resolve | Close ticket or stop page |
