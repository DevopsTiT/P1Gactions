# Glossary

| Term | What it means |
| --- | --- |
| INC | Short for Incident; also the ticket number prefix |
| Incident | Unplanned service issue tracked in ServiceNow |
| ITSM | IT Service Management (how IT tracks work) |
| correlation_id | Field linking the INC to Dynatrace Problem ID |
| sys_id | Internal ServiceNow record ID |
| Problem (Dynatrace) | Monitoring issue object — different from ITIL Problem (PRB) |
