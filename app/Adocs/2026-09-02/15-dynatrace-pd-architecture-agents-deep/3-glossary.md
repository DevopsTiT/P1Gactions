# Glossary

| Term | What it means |
| --- | --- |
| Problem | Dynatrace alert object when Davis AI detects an issue |
| Incident | PagerDuty record that tracks paging, status, and response |
| PagerDuty Advance | Paid AI layer with AI Actions budget and the four agents |
| AI Actions | Credits consumed by SRE asks and Scribe meetings |
| SRE Agent | Virtual responder for live triage, runbooks, past incidents |
| Scribe Agent | Meeting bot for bridge transcripts and summaries |
| Shift Agent | Schedule assistant for OOO vs Level-1 on-call conflicts |
| Insights Agent | Analytics Q&A over MTTR, MTTA, incident volume |
| Event Orchestration | PagerDuty rules to route, group, or pause alerts before page |
| custom_details | PD incident field; first ~2000 chars read by SRE Agent |
| linkUser | Maps PagerDuty user to Teams/Slack identity |
| Level-1 schedule | First escalation tier; Shift Agent watches this tier only |
| MTTA | Mean time to acknowledge — how fast someone opens the incident |
| MTTR | Mean time to resolve — how fast the incident is closed |
| Path B (Shift) | Teams-only POC using Calendar + PD web manual override |
| SRE memory | Learnings saved when you Resolve an incident on a Service |
