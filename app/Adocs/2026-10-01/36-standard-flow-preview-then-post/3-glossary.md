# Glossary

| Term | What it means |
|---|---|
| Standard flow | The fixed task layout every new version starts from. |
| Draft | A saved-but-not-deployed workflow. Its trigger does not fire. |
| Preview gate | The send task reads its preview result and skips if the preview is not ready. |
| Predecessor | The task that must finish before this task starts. |
| dedup_key | PagerDuty key tying trigger and resolve events for one problem. |
