# Glossary

| Term | What it means | Why you care |
|---|---|---|
| Preview | Build the request but do not send it | Safe check of prepared data |
| field_check | One row per SILVA form field | Shows which value is missing or wrong |
| open_v7_would | What OPEN v7 would do with this problem | Predicts create or skip |
| duplicate_check | GET for an open incident with the same correlation_id | Predicts "already open" |
| Routing key hidden | PD key not shown | The preview never needs it |
