# Glossary

| Term | What it means |
|---|---|
| Direct workflow | Sends right away, no preview task in between. |
| PATCH | Changes only the fields sent on an existing SILVA record. |
| sys_choice | SILVA table of allowed dropdown values. |
| active=true | Incident still open. |
| event_action resolve | PagerDuty action that closes the alert with that dedup_key. |
| onProblemClose | Trigger option to start when a problem closes. |
