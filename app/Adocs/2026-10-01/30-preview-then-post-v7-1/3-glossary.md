# Glossary

| Term | What it means |
|---|---|
| Branch | A chain of tasks that runs on its own path in the workflow graph. |
| Preview gate | The send task reads its preview result and skips if the preview is not ready. |
| predecessors | Tasks that must finish before a task starts. |
| conditions.states | The predecessor state required to start, here OK. |
| DRY_RUN | Build and log only, never send. |
