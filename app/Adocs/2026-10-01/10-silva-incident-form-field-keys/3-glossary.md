# Glossary

| Term | What it means | Why you care |
|---|---|---|
| Field key (element) | The column name the API uses | The payload must use this, not the label |
| Column label | The text shown on the form | Can be renamed (Summary = description) |
| `u_` prefix | A custom field added by the company | Not standard, so names must be confirmed |
| sys_dictionary | Table that lists every field of every table | Gives element and label pairs |
| task table | Parent of incident | Many incident fields are defined on task |
| Calculated field | Filled by SILVA rules (priority) | Do not send it |
