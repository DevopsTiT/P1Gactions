# Glossary

| Term | What it means | Why you care |
|---|---|---|
| CUSTOM_ALERT | Dynatrace event category for custom alerts, such as log event rules. | Type of this problem. |
| Process group instance | One running process (for example a Windows service) on a host. | The affected entity here. |
| impact_level Infrastructure | Davis says the impact is on infrastructure. | Sets PD severity to error. |
| AGO_AXA_SUPPORTGROUP | AXA tag naming the support team. | Becomes the assignment group. |
| AGO_AXAENVIRONMENTNAME | AXA tag naming the environment. | Wins the environment choice. |
| AGO_DOMAIN | AXA tag with the DNS domain. | Turns ts12 into ts12.hk.intraxa. |
| AGO_AXAOPCOTRIGRAM | Three-letter OpCo code (ATK). | PD component and search hint. |
| Tag without value | Tag like AGO_ALERTING_ACC with no `:value`. | Ignored by the workflow. |
| Incident history | Last 20 tickets on the same server. | Source of the offering. |
