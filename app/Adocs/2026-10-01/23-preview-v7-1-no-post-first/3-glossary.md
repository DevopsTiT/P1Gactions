# Glossary

| Term | What it means |
|---|---|
| PREVIEW workflow | A workflow that prepares the data but never sends it. |
| ready | Task 4a result: true when every required SILVA field is filled correctly. |
| open_v7_would | What OPEN v7 would do with this problem: create or skip, with the reason. |
| field_check | Row-by-row list of SILVA form fields with OK, MISSING, WRONG or EMPTY. |
| predecessors | Tasks that must finish before a task starts. The same predecessor means parallel. |
| Tag key normalization | Treating "-" and "_" in tag keys as the same when matching. |
