# Glossary

| Term | What it means |
|---|---|
| Score 5 | Search points for a business service. 5 is the minimum to accept, so it is a weak match. |
| Environment NOT matched | No offering of the service has the incident environment, so the first one was used. |
| Duplicate CI | A second CMDB record for the same host. Old copies are often renamed with a date suffix. |
| install_status | CMDB field: Installed, Retired and so on. Tickets should point at Installed CIs. |
| Maintenance tag | AGO_Maintenance:True on the entity. Blocks tickets when USE_MAINTENANCE_TAG is true. |
