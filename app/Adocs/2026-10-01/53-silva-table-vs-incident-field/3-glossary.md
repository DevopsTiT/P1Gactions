# Glossary

| Term | What it means | Why you care |
|---|---|---|
| Table | A list of records in SILVA, like one spreadsheet. | Left column. |
| Incident field | A box on the ticket. | Right column. |
| sys_id | The id of one row. | What most boxes store. |
| Reference field | A box that points to a row in another table. | Every row except environment. |
| Choice list | A fixed set of dropdown words. | Environment uses it. |
| `u_` prefix | Box added by AXA. | Not standard ServiceNow. |
