# Glossary

| Term | What it means |
|---|---|
| Davis problem | A Dynatrace problem grouped by its AI engine (Davis). |
| display_id | Short problem number like P-261090. |
| correlation_id | SILVA incident field storing the display id. |
| dedup_key | PagerDuty key grouping trigger and resolve for one problem. |
| Business service | `u_business_service`, the service the incident is about. |
| Service offering | `cmdb_ci` on the SILVA incident, a flavor of the business service. |
| Host CI | `u_configuration_item`, the server. |
| GROUP_ORDER | Order of sources for the assignment group. |
| Preview gate | Send task skips if its preview is not ready. |
| PATCH | Change some fields of an existing record. |
| sys_choice | SILVA table of allowed dropdown values. |
