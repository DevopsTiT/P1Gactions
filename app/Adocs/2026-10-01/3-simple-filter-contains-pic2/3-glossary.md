# Glossary

| Term | What it means | Why you care |
|---|---|---|
| `contains(a, b, caseSensitive: false)` | Text `a` includes text `b`, ignoring case | The check for each pic2 item |
| `or` | True if any condition is true | Joins the 23 checks |
| `countIf(condition)` | Counts rows where the condition is true | Gives the pic2 log count in Q2 |
| `countDistinct(...)` | Counts unique values | Number of distinct pic2 files |
| `log.source` | File path or log name | The field compared |
| Host group | Set of hosts sharing OneAgent config | Scope of the check |
