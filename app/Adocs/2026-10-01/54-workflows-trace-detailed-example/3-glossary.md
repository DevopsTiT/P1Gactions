# Glossary

| Term | What it means | Why you care |
|---|---|---|
| Trace | Ordered list of calls in one run. | This whole document. |
| Gate | A check that can stop a send task. | Decision, preview, sample, duplicate, DRY_RUN. |
| Technical service | A service with no offering (for example infrastructure services). | Forces the history step. |
| Incident history | The last 20 tickets on the same server. | Source of offering cfbf255f. |
| 200, 201, 202 | HTTP OK, Created, Accepted. | Success codes for GET or PATCH, POST, PagerDuty. |
| `steps` | Task 2 log of SILVA calls. | Compare with section A2. |
| `attempts` | CLOSE 2a log of PATCH calls. | Compare with section B2. |
