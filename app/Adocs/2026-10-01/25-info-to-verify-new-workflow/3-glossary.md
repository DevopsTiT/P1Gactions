# Glossary

| Term | What it means |
|---|---|
| Scenario | One kind of problem used to test one branch of the logic. |
| Pass rule | The value a task output must have for the task to count as correct. |
| Execution graph | The Dynatrace view showing each task's status and timing for one run. |
| steps | Task 2 list of every SILVA call with HTTP status and match count. |
| field_check | Task 4a list of the 16 SILVA form fields with OK, MISSING, WRONG or EMPTY. |
| open_v7_would | What OPEN v7 would do for the same problem. |
