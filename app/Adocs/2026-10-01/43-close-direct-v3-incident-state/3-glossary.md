# Glossary

| Term | What it means |
|---|---|
| incident_state | SILVA's incident state field (form "Incident State"); this is what resolves the ticket. |
| state | Generic task state field; sent too, but SILVA follows incident_state. |
| Resolved by | User SILVA records as resolver; set automatically to the API user. |
| Resolver Group | Group SILVA records as resolver; taken from the assignment group. |
| close_notes | Resolution notes; logged in activities each time it is set. |
