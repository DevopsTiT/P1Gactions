# Glossary

| Term | What it means |
|---|---|
| Stats API | `/api/now/stats/<table>`: counts rows grouped by fields, e.g. offerings per host. |
| Non-Operational | Offering status meaning it is not marked live. Tickets can still reference it. |
| Technical Services | CMDB class for platform or OS services. They have no offerings. |
| History step | Task 2 fallback that copies the offering from recent tickets on the same host CI. |
