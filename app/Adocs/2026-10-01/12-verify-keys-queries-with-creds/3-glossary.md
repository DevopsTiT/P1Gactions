# Glossary

| Term | What it means | Why you care |
|---|---|---|
| `-u user:password` | HTTP basic auth in curl | Logs in to SILVA |
| Single quotes | Shell keeps the text exactly | The password has special characters |
| `/api/now/v2/table` | Version 2 of the Table API | Same results as `/api/now/table` |
| `jq` | JSON filter tool | Shows only the columns you need |
| `--data-urlencode` | Encodes spaces and `^` safely | Labels like "Reported on" have spaces |
