# Glossary

| Term | What it means |
|---|---|
| AGO_DEFAULT_ASSIGNMENT_GROUP | Fallback tag that names the SILVA team when no more specific group tag exists. |
| AGO_ORACLE_ASSIGNMENT_GROUP | Specific tag for Oracle databases that names the SILVA team. |
| group_candidates | Ordered list of group names the workflow found in tags. |
| GROUP_ORDER | Order of sources for the final group: tag, enrichment, enrichment_support, ci, default. |
| sys_user_group | SILVA table of teams (assignment groups). |
| Dedup | Removing a candidate whose value is already in the list. |
