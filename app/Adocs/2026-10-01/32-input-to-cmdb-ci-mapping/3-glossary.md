# Glossary

| Term | What it means |
|---|---|
| Entity tag | A key:value label on the Dynatrace entity, e.g. host:ts12. |
| Security context | Dynatrace access label on the event. Not a SILVA service. |
| support_group | CMDB field naming the team that supports a CI or offering. |
| assignment_group | CMDB field naming the team that gets tickets for a CI or offering. |
| Incident history | Earlier SILVA incidents on the same host CI. |
