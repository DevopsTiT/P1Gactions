# Glossary

| Term | What it means | Why you care |
|---|---|---|
| Default set | A fixed group of values used together when nothing is found | Keeps mandatory fields filled and gives the ticket an owner |
| Single-field fallback | A default for one field only | Used when only one value is missing |
| default_set_used | Output flag in snow_required | Shows the ticket was not matched to a real service |
| STARTSWITH | SNOW query operator "name begins with" | Finds the offering even though its full name is longer |
| PoC / VoA / Demo | A SNOW environment choice | Marks the ticket as non-production triage |
