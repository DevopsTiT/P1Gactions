V4 workflow flow logic

TASK 1 extract-event-tags (event only)
1. Read the trigger event, or the sample event on manual Run.
2. Try the Problems API (fails until scope environment-api:problems:read is added).
3. Split every tag at the first ":" into key and value.
4. Group candidates: AGO_AXA_SUPPORTGROUP, then specific *_ASSIGNMENT_GROUP, then AGO_DEFAULT_ASSIGNMENT_GROUP.
5. Service tag: none in your input.
6. Environment: real env tag, then patch env tag (ACCEPTANCE), then security context, then default.
7. Maintenance: event field, then AGO_Maintenance tag.
8. Search inputs: host deaa310b, DB DEA10B01, ORACLE, ALJ, AP-SOUTHEAST-1.

TASK 2 resolve-snow-values (GET to SILVA)
Group: GROUP_MAP, then tag checked in sys_user_group, then tag name even if unchecked, then service group, CI group, default.
Service:
A. SERVICE_MAP or service tag, exact name.
B. Host or DB CI, then CI field, svc_ci_assoc, cmdb_rel_ci.
C. Five searches (group sys_id, Oracle+ACCEPTANCE, Oracle+AP-SOUTHEAST, ALJ, technical), scored. Pick only if score >= 5 and clearly best.
Offering: the offering of the service that matches the environment label.

TASK 3 display-result (no network)
ready_for_snow needs a group name plus a service or CI.
Maintenance on means create_incident false.
Builds the SNOW and PagerDuty bodies as previews only.
